创世书房 · 一层一层 · 计算机学习系列 · 第一本

地基程序员眼中的一台计算机

第一部 · 位

一台电脑里只有一样东西：开和关。这本书从一个开关讲起：数、字、图片和声音怎样变成一串开关，开关怎样搭成会算数的电路、会执行指令的处理器，一行 C 代码怎样变成内存里跑着的程序，操作系统怎样管着它，网络怎样把它和世界连起来。

它是“一层一层”系列的第一本，后面的数据结构、计算机组成、操作系统、计算机网络都站在它上面。写给两种读者：小学高年级起步的初学者（学过图形化编程、会一点 Python 就够了），和想把基础重新打牢的计算机专业学生。

每一节都分三层

同一个题目，从浅到深写三遍。页眉右边的“层 一 二 三”决定默认读到哪一层，没展开的层也能单独点开看一眼。先选一下你是谁（记在这台电脑的浏览器里，随时能改）：

  • 第一层：不需要前置知识，句子短，例子都能在 Mac 上马上试。用到别的学科（电、数学、逻辑）的地方，先用一个“过渡”框讲个大概，再接着讲。
  • 第二层：本科专业课的深度，对照考研 408 考纲和常见面试题，配原创的典型题和讲解。
  • 第三层：原理的来历、真实系统怎样做、出过哪些事故、去哪里读原文。
  • 读完一层就停，完全可以。整本书的第一层自成一体，读完就有一张完整的地图；以后回来读第二层，不需要把第一层从头再读一遍。

所有操作都在 Apple Silicon 的 Mac（M1 及以后）上写成、能照着做；要用 Windows 或 Linux 的地方单独标出来，需要 Linux 时给出在 Mac 上开一台 Linux 的办法。

读法：两条路线

同一本书，小学生和大学生走的路不一样。挑一条，照着走；走不动了，换一条也行。

小学生路线 · 只读第一层

写给四年级前后、有大人陪着的读者。页眉的“层”选一。

先打底（读过就跳过）：《一块一块》的

  • 第二部《电》：红石、逻辑门、二进制加法、锁存器、时钟。这本书的第二部，你会在那里先搭过一遍。
  • 第五部《手》：Mac 的键盘、访达、路径、终端。这本书天天要用终端。
  • 第十部《程》的前五章和第八十、八十一章：变量、判断、循环、函数、列表、递归、捉虫。
  • 第八部《数》的负数和乘方两章（第六十、六十一章）。

再读《地基》，从第零章往下，每章只读第一层：

灰框的章，第一层多了一些要动脑的东西，最好有大人一起读；黄虚线框的三章（编译和链接、加载、虚拟内存），第一层只讲个大概，小学生可以先跳过，初中以后再回来。

每一章这样读：读第一层 → 做“在 Mac 上试”和任务 → 做第一层末尾的闯关 → 做本章末尾的“主线”。一次三四十分钟，一周两三章就很好。要输入电脑密码、要删东西的地方，叫大人。

大学生路线 · 从第二层读起

写给学过一点编程、要考试、复试、面试，或者想重打基础的读者。页眉的“层”选二，第一层会自动收起。

第一层怎么办：多数章扫一眼小节标题，闯关全对就跳过。下面灰框的章，第二层开头有一个“入门版”（原来写给初学者的第一层），先读它，再往下读：

第二层：对照 408 考纲和常见面试题，每章都有原创的典型题，做完再看讲解。

第三层什么时候值得细看：

  • 准备系统方向的面试或项目：缓存（第十六章）、函数调用约定（第二十章）、分配器（第二十一章）、链接和加载（第二十二、二十三章）、整个第四部。
  • 第二层的题会做了，但说不清“为什么这样设计”。
  • 要读源码、做科研，或者想知道真实的系统怎样做。

可以只扫一眼：历史小故事和事故、具体芯片的参数、和你眼下的目标关系不大的那一章的第三层。第三层读多少都行，不读也不影响后面。

主线：每步的“第二层”那一行是给你的：加测试、用 git 记录，从第十七章起用 C 把小机再写一遍。

主线：搭一台小机

光看书容易忘，手上有活儿就记得住。这本书有一条主线：用 Python 一步一步搭一台玩具电脑，叫小机。每章末尾有一个“主线 · 第 N 步”框，说这一章给小机装上哪个零件、怎么做、运行以后应该看到什么。

第一部给它数字、文字和一块 8×8 的屏幕；第二部用与非门搭出加法器、寄存器、内存，装上会取指、译码、执行的“大脑”和汇编器；第三部让它会用指针、栈、堆，会链接、装载、调试；第四部给它内核、进程、页表、文件系统和锁，最后接上电线，装好一个能敲命令的小外壳，和另一台小机互发消息。

每一步都有现成的完整代码，可以下载运行，所以哪一步卡住了都不怕：下载那一步的文件，接着往下走。下面是装配图，点一格跳到那一章；在章末点了“我装好了”，这里就会亮。

全部代码在网站的 base/main/ 文件夹里：s00.py—s32.py 是到每一步为止的完整文件。下一本《链与树》会接着用小机的那块屏幕，做一个方格小游戏。
