电是怎样流的

电压、电流、电阻

把电路想成水管。电池像一个水泵，把水从低处抽到高处，高低之差就是电压（单位伏特，V）。水从高处往低处流，每秒流过多少就是电流（单位安培，A）。管子细、弯多，水就流得慢，这种“阻碍”叫电阻（单位欧姆，Ω）。三者的关系：电压 = 电流 × 电阻，叫欧姆定律，初中物理会学。

最简单的电路：电池、开关、小灯泡连成一个圈。开关合上，圈通了，电流流过灯泡，灯亮；开关断开，圈断了，灯灭。电路里电压高的一头记作 1，接地（0 伏）的一头记作 0。

用电控制电

普通的开关要用手按。电脑需要的是一种能被电按下的开关：一根线上有没有电，决定另一根线通不通。这样，一个开关的输出就能去控制下一个开关，一级一级接下去，不需要人。

最早的办法是继电器：一个线圈通电就变成磁铁，把一片金属吸过来，接通另一条电路。二十世纪三四十年代的早期计算机，就是用成千上万个继电器搭的，咔哒咔哒响，每秒只能切换几十次。后来换成电子管（像小灯泡，没有零件动，快得多，但又大又烫又爱坏），再后来是晶体管。

晶体管用硅做成，没有任何会动的零件。最常用的一种叫 MOS 管，有三个脚：两头是“源”和“漏”，电流从这里过；中间是“栅”，像一道闸门。分两种：

  • N 型：栅极给高电压（1），闸门打开，两头接通；给 0，断开。
  • P 型：正好相反，栅极给 0 才接通，给 1 断开。

它们很小很小，今天一个指甲盖大小的芯片里能放下几百亿个，开关一次只要几十亿分之一秒。这就是一楼：几百亿个开关。

串联是与，并联是或

拿两个开关 A、B 和一盏灯：

  • 两个开关一前一后串在一根线上：只有 A 和 B 都合上，灯才亮。这就是“与”。
  • 两个开关并排接成两条路：A 或 B 合上一个，电就能从那条路过去，灯就亮。这就是“或”。

“非”稍微巧一点：输入是 1 时要让输出变成 0。用一个 P 管和一个 N 管叠起来：P 管接在电源（1）和输出之间，N 管接在输出和地（0）之间，两个管子的栅极接在一起当输入。输入是 0：P 管通、N 管断，输出被连到电源，是 1。输入是 1：P 管断、N 管通，输出被连到地，是 0。总有一个通、一个断，所以这种搭法叫 CMOS（互补的 MOS）：它几乎不费电，只有在切换的一瞬间才有电流。

同样的思路：两个 N 管串联接地、两个 P 管并联接电源，就是与非门（先“与”再“非”）；反过来，N 管并联、P 管串联，就是或非门。在 CMOS 里，与非和或非比与、或更“天然”，要得到“与”，就在与非后面再接一个非门。

选一种门，点 A、B 切换输入。绿色的管子是接通的，灰色是断开的；橙色的线说明输出被连到了电源（1）还是地（0）。右边的真值表标出现在这一行。

与非是万能的

只要有足够多的与非门，就能搭出任何一种逻辑：

  • 非：把与非门的两个输入接在一起，NAND(A, A) = 非 A。
  • 与：与非后面再接一个“非”。
  • 或：先把 A、B 各自“非”一下，再与非：NAND(非 A, 非 B) = A 或 B（第七章的德摩根定律）。
只用与非，造出其余的门15 分钟

在 ~/base 里新建 gates.py（可以用 nano gates.py，或者用 Mac 自带的“文本编辑”，记得存成纯文本）：

def NAND(a, b):
    return 1 - (a & b)

def NOT(a):    return NAND(a, a)
def AND(a, b): return NOT(NAND(a, b))
def OR(a, b):  return NAND(NOT(a), NOT(b))

for a in (0, 1):
    for b in (0, 1):
        print(a, b, "与", AND(a, b), "或", OR(a, b), "与非", NAND(a, b))
% python3 gates.py

打出来的四行就是三种门的真值表。试着自己加一个 XOR(a, b)（异或），只许用上面已有的函数。提示：异或 =（A 或 B）且 非（A 且 B）。

用四个与非门搭异或

上面的提示用了好几个门。其实只用 4 个与非门就能搭出异或：先算 n = NAND(A, B)，再算 NAND(A, n) 和 NAND(B, n)，最后把这两个结果再与非一次。在 gates.py 里写出来，用四种输入验证。

逻辑代数

写法约定：A·B（或 AB）表示与，A + B 表示或，A′（或 Ā）表示非。基本定律：

名称与的形式或的形式
0—1 律A·0 = 0，A·1 = AA + 1 = 1，A + 0 = A
重叠律A·A = AA + A = A
互补律A·A′ = 0A + A′ = 1
交换、结合同普通代数
分配律A(B + C) = AB + ACA + BC = (A + B)(A + C)　← 普通代数里没有
吸收律A(A + B) = AA + AB = A；A + A′B = A + B
德摩根(AB)′ = A′ + B′(A + B)′ = A′B′

任何逻辑函数都可以从真值表直接写出“最小项之和”：把输出为 1 的每一行写成一个所有变量都出现的与项（变量为 0 的取非），再全部或起来。例如异或：输出为 1 的行是 (0,1) 和 (1,0)，所以 A ⊕ B = A′B + AB′。这样写出来往往不是最简的，需要化简（下一章的卡诺图更直观）。

完备性

{与, 或, 非} 能表示任何函数（因为任何函数都能写成最小项之和）。而与和或都能用与非加非表示，非又能用与非表示，所以 {与非} 单独就是完备的；同理 {或非} 也是。芯片设计里大量使用与非、或非，因为在 CMOS 里它们比与、或少两个管子、更快。

门延迟和扇出

输入变了，输出不会立刻变：管子要充放电，需要一点时间，叫传播延迟（今天约几十皮秒，1 皮秒 = 10−12 秒）。一条信号路径经过几级门，延迟就大约叠几倍；电路里最慢的那条路径叫关键路径，它决定了时钟最快能多快（第十一章）。一个门的输出能接多少个门的输入叫扇出，接得越多，要充的电越多，越慢。

功耗和功耗墙

CMOS 的功耗主要来自每次切换时给导线和管子的电容充放电：动态功耗 P ≈ α·C·V2·f（α 是平均每个时钟周期有多大比例的电路在切换，C 是电容，V 是电压，f 是频率）。几十年里，晶体管越做越小，C 和 V 跟着下降，频率就能一路提高而功耗不涨（登纳德缩放）。大约 2005 年前后，电压降不下去了（再低管子就关不严，漏电太大），而功耗和 V 的平方成正比，频率一高芯片就热得受不了。这就是“功耗墙”：处理器的主频从此停在几 GHz，厂商转而往一块芯片里放更多的核、更多专用电路。

典型题 · 原创

（1）化简 F = AB + AB′ + A′B。（2）只用与非门实现 F = AB + CD，最少要几个门？（3）一块芯片电压从 1.0 V 降到 0.8 V，频率不变，动态功耗变为原来的多少？

看解答

（1）AB + AB′ = A(B + B′) = A；A + A′B = A + B（吸收律）。F = A + B。

（2）AB + CD = ((AB)′·(CD)′)′（德摩根两次），正好是三个与非门：两个分别算 (AB)′、(CD)′，第三个把它们与非。这种“与或”结构直接换成“与非-与非”结构是常用技巧。

（3）P ∝ V2，0.82 = 0.64，变为原来的 64%。这就是降低电压能大幅省电的原因。

为什么 CPU 的主频十几年没怎么涨，性能却还在涨？

看要点

登纳德缩放失效后，功耗 ∝ CV2f 让高主频的发热无法承受（功耗墙）。性能提升转向：每个时钟周期做更多事（更宽的超标量、乱序执行、更大的缓存、更好的分支预测，第十五、十六章），更多的核（并行），专用加速器（GPU、神经网络引擎、视频编解码器），以及更好的工艺带来的更低功耗。代价是：软件要会利用并行，才能吃到这些好处。

硅怎样变成开关

纯硅导电很差。往里面掺一点点磷，多出自由电子，成为 N 型半导体；掺硼，多出“空穴”，成为 P 型。一个 N 型 MOS 管是在 P 型的硅片上做两块 N 型区（源和漏），中间上方隔一层极薄的绝缘层放一块导体（栅）。栅极加正电压，把下面的电子吸上来，在源和漏之间形成一条薄薄的导电“沟道”，管子导通；电压撤掉，沟道消失。让沟道形成的最小电压叫阈值电压。

管子越小，绝缘层越薄、沟道越短，“关”的时候也越关不严，总有一点电流漏过去，这就是静态功耗（漏电）。为了把闸门管得更严，2011 年起英特尔量产 FinFET：把沟道立起来做成一片“鳍”，栅极从三面包住它；更新的工艺用全环绕栅极（GAA），栅极把沟道四面包住。

摩尔定律和登纳德缩放

1965 年，戈登·摩尔在一篇四页的文章里注意到，芯片上能经济地集成的元件数大约每年翻一番，并预测会持续十年；1975 年他把速度修正为大约每两年翻一番。这不是物理定律，而是一个行业愿意花多少钱、能多快改进工艺的经验规律，后来变成了行业互相约定的节奏。1974 年罗伯特·登纳德等人指出：晶体管尺寸缩小 k 倍时，若电压也缩小 k 倍，单位面积的功耗不变而速度变快。第二层讲了它在 2005 年前后的失效。

工艺名字里的“7 纳米”“5 纳米”“3 纳米”，早已不对应晶体管上任何一个真实的尺寸，而是一代一代沿用下来的“代号”，表示密度大约相当于按老办法缩到那个尺寸。真实的栅极间距仍是几十纳米。比较两家的工艺，要看每平方毫米能放多少晶体管、性能和功耗，而不是看名字。

光刻

芯片是“印”出来的：在硅片上涂感光胶，用光透过掩膜照射，再刻蚀、掺杂、沉积，一层一层重复几十到上百次。图案越细，光的波长就要越短。最先进的芯片用 13.5 纳米波长的极紫外光（EUV），这种光刻机目前全世界只有荷兰的 ASML 一家能造，一台的价格以亿美元计。

想看这些技术的历史：书房里的《计算机创世记》上卷有专门讲芯片和“墙”的两章。
