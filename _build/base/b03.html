绕回来的线

组合电路的线都是从输入流向输出，一去不回。现在做一件奇怪的事：拿两个或非门，把每个门的输出接到另一个门的一个输入上，它们就互相管着了。剩下的两个输入叫 S（设置，set）和 R（复位，reset），两个输出叫 Q 和 Q̄（读作“Q 非”）。

  • 按一下 S（S 变成 1 再回到 0）：Q 变成 1，而且松手以后还保持 1。
  • 按一下 R：Q 变成 0，松手以后保持 0。
  • S 和 R 都是 0：什么也不变，它“记得”上一次是被设置还是被复位。

为什么能记住？Q 是 1 时，它让下面的门输出 Q̄ = 0，Q̄ = 0 又让上面的门继续输出 Q = 1，两个门互相撑着，稳稳地停在这个状态，直到有人按 R。这个小电路叫 SR 锁存器，它记住了一个比特。

时钟和触发器

电脑里有几十亿个比特要记，如果每个都随时可能被改，就乱套了：加法器的结果还没算完、还在抖，就被记下来了。办法是请一个“指挥”：时钟。时钟是一根不停地 0、1、0、1 跳的线，像乐队指挥的手一下一下打拍子。约定：大家只在时钟从 0 跳到 1 的那一瞬间，才把输入记下来，其余时间输入怎么变都不管。

按这个约定工作的存储单元叫 D 触发器：它有一个数据输入 D 和一个时钟输入；每当时钟“往上跳”，它就把 D 此刻的值抄到输出 Q，然后一直保持到下一次往上跳。第零章说 M1 芯片的主频是 3.2 GHz 左右，意思就是这个“指挥”每秒打三十多亿下拍子。

  • 把 8 个 D 触发器并排，共用一个时钟，就能一下记住一个字节，这叫寄存器。处理器里最快的存储就是寄存器。
  • 把一个寄存器的输出接到加法器上加 1，结果再接回寄存器的输入，每来一下时钟它就加一：这是计数器。处理器里记“下一条指令在哪儿”的程序计数器，就是这样一个会自动加一的寄存器（第十三章）。

时钟和计数器

上面是时钟的波形。一个 4 位计数器（4 个 D 触发器 + 一个加一电路），每当时钟往上跳就加一。可以一下一下手动打拍子，也可以让它自己跑。

用 Python 模拟锁存器10 分钟
def NOR(a, b): return 1 - (a | b)

q, qn = 0, 1                       # 现在记着 0
def step(s, r):
    global q, qn
    for _ in range(4):             # 线绕回来，多算几轮直到稳定
        q, qn = NOR(r, qn), NOR(s, q)
    return q

print(step(1, 0), step(0, 0))      # 按一下 S，再松开：1 1
print(step(0, 1), step(0, 0))      # 按一下 R，再松开：0 0

“多算几轮直到稳定”正是绕回来的线在做的事。试试 step(1, 1) 之后再 step(0, 0)，把循环里每一轮的 q、qn 打出来，看看会不会来回跳。

锁存器和触发器

  • 或非门 SR 锁存器的 S = R = 1 是禁止状态：Q 和 Q̄ 都被拉成 0（不再互补）；如果两者再同时变回 0，谁先变取决于哪个门稍快一点，结果不确定，甚至会来回振荡一阵。第一层装置里“同时松开”演示的就是这个。
  • D 锁存器：在 SR 锁存器前面加两个门，令 S = D·E、R = D′·E，E（使能）为 1 时 Q 跟着 D 变（“透明”），E 为 0 时保持。它是电平触发的，E 为 1 的整段时间都在变，容易让信号穿过好几级。
  • D 触发器：两个 D 锁存器串联（主从结构），一个在时钟为 0 时透明，一个在时钟为 1 时透明，合起来只在时钟上升沿那一刻采样，叫边沿触发。同步电路几乎都用边沿触发的触发器。
  • 其他触发器（JK、T）都能用 D 触发器加组合逻辑搭出来；T 触发器每来一个时钟翻转一次，可以用来分频。

时钟能多快

触发器在采样的那一刻，要求 D 在时钟沿之前至少 tsetup（建立时间）就稳定，在之后至少 thold（保持时间）内不变。时钟沿到来后，Q 要经过 tpcq（触发器的时钟到输出延迟）才变成新值。数据从一个触发器出发，经过组合逻辑（最长 tpd）到达下一个触发器，必须赶在下一个时钟沿之前满足建立时间：

Tc ≥ tpcq + tpd + tsetup，最高频率 f = 1 / Tc

这就是为什么第十章说“关键路径决定时钟”。要提高频率，就把一大段组合逻辑切成几小段，中间插寄存器，这就是第十五章的流水线。

有限状态机

寄存器记住“现在的状态”，组合逻辑根据现在的状态和输入算出“下一个状态”（和输出），时钟一到就更新：这种结构叫有限状态机（FSM）。输出只看状态的叫摩尔型，输出还看当前输入的叫米利型。设计步骤：画状态图 → 列状态转换表 → 给状态编码（k 个状态要 ⌈log2k⌉ 个触发器）→ 写出次态和输出的逻辑表达式 → 化简画电路。自动售货机、红绿灯、串口收发、处理器的控制器都是状态机。

找出 101

一个摩尔型状态机，盯着一串一位一位送进来的比特，每当最近三位是 1、0、1 时输出 1（允许重叠，比如 10101 里有两个）。点 0 或 1 送一位进去，看状态怎样跳。

典型题 · 原创

（1）某同步电路中，触发器的 tpcq = 50 ps、tsetup = 30 ps，两级触发器之间组合逻辑的最长延迟为 420 ps，最高时钟频率是多少？如果把组合逻辑平均切成两段、中间加一级同样的触发器呢？（2）设计一个检测输入序列“11”（不重叠）的摩尔型状态机，最少要几个状态、几个触发器？

看解答

（1）Tc ≥ 50 + 420 + 30 = 500 ps，f = 2 GHz。切成两段：每段 210 ps，Tc ≥ 50 + 210 + 30 = 290 ps，f ≈ 3.45 GHz。频率没有翻倍，因为触发器本身的开销 80 ps 没有变少，切得越细，这部分占比越大（第十五章）。

（2）三个状态：S0（还没看到 1）、S1（刚看到一个 1）、S2（看到 11，输出 1）。S2 收到下一位时：不重叠，所以收到 1 回 S1、收到 0 回 S0。三个状态要 ⌈log23⌉ = 2 个触发器。

亚稳态

如果 D 恰好在时钟沿附近变化（违反建立或保持时间），触发器可能停在 0 和 1 之间的“半空中”，过一段不确定的时间才倒向某一边，这叫亚稳态。它无法彻底消除，只能让它出现的概率小到可以忽略。凡是来自外部、和本电路时钟无关的信号（按键、另一个芯片、另一个时钟域），都要先经过一个同步器：两个串联的触发器，第一个可能进入亚稳态，但它有整整一个时钟周期去“倒下来”，第二个采样时几乎总是稳定的。平均多久出一次错（MTBF）随等待时间指数增长，两级通常就够了，要求极高的场合用三级。

时钟本身也难

几十亿个触发器要在“同一瞬间”收到时钟沿，可电信号走过芯片要时间，不同位置收到的时间差叫时钟偏斜。芯片里专门有一棵时钟树把时钟均匀地送到各处，它本身就要消耗相当可观的功率。省电的办法之一是门控时钟：某一块电路暂时不用，就把它的时钟关掉，它的触发器就不再翻转、不再耗电。手机和 Mac 芯片里大量使用这种办法，还会按负载动态调整电压和频率。

也有人研究完全不用全局时钟的异步电路：每一级做完了就用“握手”信号通知下一级。它省电、没有时钟偏斜问题，但设计和验证困难，至今主要用在局部。

在 Verilog 里写一个触发器

module counter4(input clk, reset, output reg [3:0] q);
  always @(posedge clk)          // 只在时钟上升沿发生
    if (reset) q <= 4'b0000;
    else       q <= q + 1;       // 加一电路 + 4 个 D 触发器
endmodule

posedge clk 就是“时钟往上跳”，<= 是“非阻塞赋值”，表示所有触发器在同一个沿上同时更新。可以用第十章装好的 Icarus Verilog 写个测试来仿真它。
