是和不是

讲什么
一根火把就是“非”；两个开关拼出“与”和“或”；一个鞋匠的儿子把想事情写成算式；一个美国学生用一篇论文把它们接到电线上
本章装置
逻辑门
周六上午WORLD · 小格的家创造模式
小格的房子有前门和后门，他想做一盏“报警灯”：随便哪扇门被打开，灯就亮。
格我把两扇门的线接到一起了，好像成了！
舅成了。你刚才做的叫“或”：这个开或者那个开，灯就亮。再来一个难的：做一个只有你和豆子都站在压力板上，宝箱的门才会开的机关。
格两根线接到一起……不对，那样一个人站上去也开了。
舅对。要用到一个反着来的东西。你发现没有：红石火把插在方块上，平时一直亮着，可要是给它下面那块方块通上信号，它就灭了。
格它为什么要反着来？
舅因为“反着来”是电脑最重要的本事之一。今天我们就来做电脑的第一块零件。

只有两种答案

红石线只有两种样子：有信号，没信号。灯只有两种样子：亮，灭。拉杆也是：开，关。这种只有两种答案的事情，在生活里到处都是：今天下没下雨？作业写没写完？门锁没锁？

我们可以把“有、是、开、亮”记作 1，把“没有、不是、关、灭”记作 0。下一章你会看到，光靠 0 和 1，就能数数、算加法，甚至写字、画画。可是在那之前，先要学会让 0 和 1 互相“商量”。负责商量的小电路，叫逻辑门。

三个最基本的门

  • 非：把答案反过来。进去 1，出来 0；进去 0，出来 1。红石火把就是一个“非”：它脚下的方块有信号，它就灭；没信号，它就亮。
  • 或：两个输入，只要有一个是 1，出来就是 1。红石里最简单：把两根线接到一起就行。小格的报警灯就是“或”。
  • 与：两个输入，两个都是 1，出来才是 1。红石里的常见做法要用三根火把：先把两个输入各“非”一次，接到一根线上，再“非”一次。绕了一圈，正好变成“与”。

你也许觉得“与”的做法太绕了。来想一想：两个人都站上去，两根火把就都灭了，中间那根线没信号，最后那根火把就亮了；只要有一个人没站，就有一根火把亮着，中间那根线就有信号，最后那根火把就灭了。用纸画一画，很快就能想通。

把“与”的最后一根火把拿掉，就得到“与非”：两个都是 1，出来才是 0。别小看它：光用“与非”这一种门，就能拼出所有别的门，也就能拼出一整台电脑。

装置 · 第十章

逻辑门

先选一种门，再点电路里的拉杆把它拨开或者关上，看右边的灯。下面的表格叫真值表，把所有可能都列了出来，黄色的那一行是你现在拨出来的样子。电路用的是封面那块电路板的简化规则：火把只听它左边（画小三角的那一边）。

真值表是一个很好的习惯：不管电路多复杂，只要把每一种输入都试一遍、写下来，就知道它对不对。程序员检查自己的程序，也常常这样一种一种地试。

鞋匠的儿子1847—1854

把“是”和“不是”变成算式，是一个英国人想出来的，他叫乔治·布尔。布尔的爸爸是个鞋匠，家里没钱供他上大学，他就自己读书，学拉丁文、希腊文、数学，十几岁就去学校当老师养家。

1847 年和 1854 年，布尔写了两本书。他的想法是：人想事情的时候用的“并且”“或者”“不”，可以像加减乘除一样写成算式来算。比如“下雨并且没带伞，就会淋湿”，可以写成一个式子，代进去 1 和 0，就能算出答案。后来人们把这种算法叫作布尔代数。

布尔活着的时候，大多数人觉得这只是数学家的游戏，没什么用。他想不到，八十多年后，它会变成每一台电脑的地基。

一篇硕士论文

1937 年，美国麻省理工学院有一个二十一岁的学生，叫克劳德·香农。他在学校里帮忙照看一台巨大的计算机器，机器里有许许多多继电器（上一章讲过，一种用电来控制的开关）。

香农看着这些乱七八糟的开关，忽然想起大学时学过的布尔代数：开关只有开和关，不就是 1 和 0 吗？两个开关串在一起，两个都合上电才通，这是“与”；并在一起，合上一个电就通，这是“或”。

他把这个想法写成了硕士论文，1937 年写成，第二年发表。从此以后，设计电路的人不用再一个一个地试，可以先在纸上用布尔代数算好。后来有一位参与过早期电脑的数学家说，这可能是历史上最重要的一篇硕士论文。

从火把到芯片

真正的电脑里，逻辑门一开始是用继电器做的，咔哒咔哒响，又慢又大；后来换成了像小灯泡一样的电子管，快了，可是很热、很容易坏；再后来换成了晶体管，一种小得看不见的开关。今天一块指甲盖大小的芯片里，挤着几十亿、上百亿个晶体管。2020 年苹果的 M1 芯片里，大约有一百六十亿个。

不管是继电器、电子管、晶体管，还是游戏里的红石火把，它们干的是同一件事：当一个开关，让一个信号去控制另一个信号。这就是为什么红石能造电脑：电脑在乎的不是用什么做的，而是这些开关是怎样连起来的。

豆子的电路为什么不灵了

豆子在平板上（基岩版）做了一个活塞门，照着一模一样的样子在小格的电脑上（Java 版）搭了一遍，门却不开了。这不是谁搭错了：第六章讲过，这两个版本其实是两套不同的程序，红石的一些细小规则不一样。比如有的活塞在 Java 版里，会被它“头顶上方”的信号莫名其妙地打开，在基岩版里就不会。玩家看教程的时候，要先看看那是哪个版本的。

试一试
游戏里
  1. 做一个“非”：一个拉杆接到一块方块上，方块另一面插一根红石火把，火把旁边放一盏灯。拉一拉，看灯是不是反着来。
  2. 做一个“或”：两个拉杆，两根线接到一起，通到一盏灯。
  3. 做一个“与”：两扇门前各一块压力板，只有两个人都站上去，宝箱的门才开（照着上面装置里“与”的样子，三根火把）。
  4. 做完以后，把四种情况都试一遍，填一张真值表。
游戏外
  1. 玩“反着做”游戏：一个人说“站”，另一个人就坐下；说“举手”，就把手放下。你就是一根“非”火把。
  2. 和家里人约定：周末要出去玩，“爸爸同意并且妈妈同意”才行，还是“爸爸或者妈妈同意”就行？哪一种更容易成？用 0 和 1 画一张小表格。
  3. 找一找家里的“与”：有些洗衣机要门关好并且按了开始，才会转。还能找到别的吗？
继电器电脑

二十世纪三四十年代，好几台最早的计算机器都是用继电器拼成的，有的有几千个继电器，算一道乘法要好几秒，运行起来满屋子“咔哒咔哒”。电子管和晶体管来了以后，继电器电脑很快就被淘汰了。今天在一些老式电梯、交通灯的控制箱里，还能见到继电器。

Java 版红石的怪规矩，是故意设计的半真

上面说的“活塞被头顶上方的信号打开”，玩家叫它“准连接”。据玩家社区流传的说法，它最早是写程序时留下的一个小毛病，并不是故意的。

可是后来，很多玩家利用这个毛病做出了又小又巧的机器。要是修好它，成千上万台已经造好的机器就会坏掉。于是做游戏的人决定不修了，把它当成 Java 版的“特色”留了下来。一个错误，被大家用着用着，就成了规矩。

联系

你早就会用逻辑门了

“吃完饭并且写完作业才能玩”“周六或者周日去公园”“不许在床上跳”：大人定的规矩里，全是与、或、非。布尔做的事，只是把大家每天嘴里说的这几个词，变成了能算的式子。

这一章的新词
逻辑门根据输入的 0 和 1，决定输出是 0 还是 1 的小电路。
与、或、非三种最基本的门：都是才是、有一个就是、反过来。
真值表把一个电路所有可能的输入和输出都列出来的表格。
晶体管芯片里用来当开关的小零件，小到肉眼看不见。
给大人

布尔《逻辑的数学分析》（1847）和《思维规律的研究》（1854）；香农硕士论文《继电器与开关电路的符号分析》1937 年在麻省理工完成，1938 年发表；“可能是最重要的硕士论文”的评价出自赫尔曼·戈德斯坦等人，是评价而非公认排名。M1 约 160 亿个晶体管据苹果 2020 年发布会。准连接（quasi-connectivity）只存在于 Java 版的活塞、发射器、投掷器，基岩版没有；它的来历在社区中流传的是“沿用门的代码而产生”，未见官方正式说明，书中写作“据说”。

真值表是这一章最值得带走的工具。可以和孩子一起把“周末出去玩”的家庭规则写成真值表，他会发现规则说得不清楚时，表格是填不满的。书房里的《计算机创世记》卷三和卷五讲了香农和继电器电脑的完整故事，适合大人读了再讲给孩子。

游戏里带走一样红石火把是“非”，接在一起的线是“或”，三根火把能拼出“与”。光用“与非”一种门，就能拼出一整台电脑。
游戏外带走一样把一件事所有可能的情况都列出来、一种一种地试，就不会漏掉。规矩说得清不清楚，填一张表就知道。
