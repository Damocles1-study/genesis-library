会记事的电路

周六下午WORLD · 小格的家创造模式
小格在床头装了一个按钮和一盏灯。按一下，灯亮了；一秒钟以后，灯又灭了。
格这个按钮坏了！它自己弹回去了。
舅没坏，按钮本来就是这样。你家门铃也是，按着才响，松手就不响。换成拉杆不就行了？
格可我就想用按钮。按一下亮，再按一下关，像我房间的台灯那样。
舅那你要的不是一根线，是一个会记事的电路：它得记住你刚才按过。
格电路还会记事？
舅会。而且你的电脑里，有几百亿个这样会记事的小格子。

到目前为止，电路都是“健忘”的

回头看前三章做过的东西：一根线、一个“非”、一个“与”、一台加法器。它们有一个共同点：输入一变，输出马上跟着变。拉杆拨开，灯亮；拉杆拨回去，灯灭。你一松手，它就什么都不记得了。

这样的电路能算题，可是不能记住答案。想象一下，一台计算器算出了 7 + 5 = 12，可是你手一离开按键，屏幕上的 12 就没了，那还怎么接着算“再乘以 3”？电脑必须能记住。

两根火把，互相管着

办法出奇地简单：把两个“非”首尾接起来，让第一个的输出送进第二个，第二个的输出又送回第一个。

想一想会发生什么。如果第一根火把亮着，它就让第二根火把灭；第二根灭了，就不会去管第一根，第一根就一直亮着。反过来，如果第二根亮着，第一根就一直灭着。两种样子都能自己一直保持下去，谁也不肯先变。

这时候，只要在旁边加两个按钮：一个去“推”第一根火把，让它灭；一个去“推”第二根火把，让它灭。按一下，电路就翻到另一种样子，而且松手以后还待在那里。它记住了你最后按的是哪一个。这种电路叫锁存器，像一把锁，把一个 0 或 1 锁住。

游戏里玩家最常做的一种，就是用两根红石火把交叉连起来，叫“RS 锁存器”：R 是“清掉”，S 是“设上”。还有一种更像台灯开关的：按一下开、再按一下关，叫“T 触发器”。

装置 · 第十二章（一）

让灯记住你按过

用“手”点一下标着“记”的按钮，再点一下标着“忘”的按钮。按钮只会亮一秒钟，看看灯是不是在你松手以后还记得。点“慢放”，可以看清两根火把是怎样一个亮、一个灭的。

在这块电路板上，“记”按钮让左边的火把灭掉，右边的火把就亮了，灯跟着亮；右边的火把又通过下面那根绕回来的线，一直“按住”左边的火把。所以松手以后，灯还亮着。

1918 年的两只电子管

1918 年，英国有两位科学家，威廉·埃克尔斯和 F. W. 乔丹，用两只电子管做了一个电路：两只管子互相控制，一只导通，另一只就截止；给它一个小小的“推”，两只就交换过来，然后一直保持。他们为这个电路申请了专利。

它就是后来所有电脑“记忆”的老祖宗，英文叫 flip-flop，意思是“翻过来、翻过去”，中文叫触发器。他们做它的时候，世界上还没有电脑。二十多年后，造第一批电子计算机的人才发现：这正是他们要的东西。

一个格子记一个 0 或 1

一个锁存器只能记住一个 0 或 1，叫一位。上一章说过，八位是一个字节，能记住一个英文字母；三个字节大约能记住一个汉字。想记住一张照片、一首歌，就需要几百万、几千万个这样的格子。

电脑里专门放这些格子的地方，叫内存。小格那台电脑的内存是 8 GB，大约是六百八十多亿个格子。每一个格子都用几个晶体管做成，小到肉眼完全看不见，全部挤在几块小芯片上。

游戏里也有人用红石做过内存。一个红石锁存器至少要几格到十几格方块，想记住一点点东西，就要铺满一大片地。下面这个装置帮你算一算。

选一样想记住的东西，再拖动滑块，设一个红石“记忆格子”要用多少块方块（看设计不同，大约几块到几十块）。看看要铺多大一片地。

每格用几块

这里的数字都是粗算：照片、歌、电影的大小差别很大，红石记忆格子的大小也看怎么设计。一个足球场约按 7140 平方米、故宫约按 72 万平方米算。

内存会忘，硬盘不会

内存里的锁存器有一个缺点：要一直通着电才能记住。电脑一关机，电没了，两根“火把”都灭了，里面记的东西就全没了。所以电脑里还有另一种地方，专门把东西长久地存起来，关机也不会丢，叫硬盘（小格那台电脑里的硬盘，其实是一种叫“固态硬盘”的芯片）。

你在游戏里点“保存并退出”，游戏就把整个世界从内存里抄到硬盘上：每一格放的什么方块、你箱子里有什么、红石锁存器现在是亮是灭，全都变成 0 和 1 写下来。下次打开，再从硬盘抄回内存。

这就是为什么玩到一半突然断电，最后那一会儿盖的东西可能会没了：它们还在内存里，没来得及抄到硬盘上。

游戏外
  1. 和一个朋友玩“锁存器”：规则是“你举手，我就放下；你放下，我就举手”。谁也不许自己先变。再请第三个人轻轻按一下其中一个人的手，看看会怎样。
  2. 拿八枚硬币排成一排，正面是 1、反面是 0，摆出一个字节。你能摆出 65（大写字母 A）吗？提示：64 + 1。
  3. 想一想：你的脑子里，哪些事是“内存”（一会儿就忘），哪些是“硬盘”（一直记得）？
一针一线织出来的内存

二十世纪五十年代到七十年代，很多电脑的内存是用许许多多比芝麻还小的磁环做的，叫“磁芯存储器”。一个磁环记一位，几根细铜线从磁环中间穿过去。这种活机器做不了，要工人戴着放大镜，一个一个用手穿。后来芯片做的内存又小又便宜，磁芯存储器就退场了。

电脑一关机，就把所有东西都忘光了半真

内存里的东西确实会忘光。可是存到硬盘里的照片、作业、游戏存档，关机以后都还在。

所以真正要说的是：没保存的东西会丢。写作业、画画、做游戏地图的时候，记得常常保存。

生活

两个人互相管着，就不会忘

一根火把记不住事，两根互相管着就能记住。人也是这样：一个人说“我要每天读书”，常常三天就忘了；两个好朋友约好互相提醒，就容易坚持下去。锁存器的秘密，是把自己的结果，再送回来管住自己。

给大人

埃克尔斯与乔丹 1918 年申请英国专利，1919 年发表论文，描述双稳态电子管“触发”电路。磁芯存储器在二十世纪五十年代到七十年代广泛使用，多由女工手工穿线。8 GB 按 8×230 字节计约 687 亿位。游戏内的 RS 锁存器、T 触发器有多种实现，Java 版与基岩版的做法略有不同。

“断电会丢没保存的东西”是一个很实用的习惯话题，可以顺便和孩子约定：编程课的作品、做好的地图，要定期保存、备份。书房里的《计算机创世记》间章“死物怎么动起来”第二步“让线掉头”讲的就是这一章的原理。

游戏里带走一样两根红石火把交叉连起来，就能记住一个 0 或 1，叫锁存器。电脑的内存，就是几百亿个这样的小格子。
游戏外带走一样内存会忘，硬盘不会；没保存的东西会丢。重要的东西，记得常常保存。
