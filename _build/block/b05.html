小格在海边盖了一座灯塔，塔顶放了一盏红石灯。
格真的灯塔是一闪一闪的。我想让它自己闪，不用我一直按。
舅那要做一个“时钟”。不是看几点的钟，是会自己一开一关、一开一关的电路。
格上次那个火把，它的线绕回来管自己，就一直闪个不停。是那个吗？
舅就是它！不过它闪得太快了，像在发抖。我们用中继器让它慢下来。
过了一会儿，灯塔一亮一灭，一亮一灭。远处，豆子的平板上弹出一行字：“小格，你的灯塔把我的电脑都弄卡了。”
舅哈哈，这一章正好也讲“卡”。

游戏里的时间是一下一下跳的

你也许觉得游戏里的时间和真的时间一样，是连续流过去的。其实不是。游戏在背后像一个打拍子的人：一秒钟打 20 下拍子，每一下叫一个“游戏刻”。每打一下拍子，游戏就把整个世界检查一遍：庄稼该不该长一点、怪物该往哪儿走一步、水该往哪儿流一格、红石信号该传到哪儿。

红石用的拍子更慢一点：两个游戏刻算一个“红石刻”，也就是 0.1 秒。第九章说中继器最少让信号晚 0.1 秒，就是晚一个红石刻；红石火把从亮变灭，也要一个红石刻。

第一部说过，游戏里一天是 20 分钟。算一算：20 分钟是 1200 秒，乘以每秒 20 刻，一天正好是 24000 刻。玩家用命令改时间时，写的就是这个数。

会自己闪的电路

上一章的锁存器，是两个“非”首尾相接，结果两种样子都很稳定。要是只用一个“非”，把它的输出直接接回自己的输入呢？

它亮着，就把信号送回自己，于是它灭了；它一灭，信号没了，于是它又亮了……它永远停不下来。这就是最简单的时钟电路。它的“一下”有多快，取决于信号绕一圈要花多久。在线里多加几个中继器，每个都让信号晚一点，时钟就变慢了。玩家常用这个办法做闪烁的灯塔、定时的投喂机、自动收庄稼的农场。

不过，在 Java 版里，如果一根红石火把闪得太快（一小会儿里亮灭了好多次），它会“烧坏”，熄灭一阵子才恢复。据说这是做游戏的人故意加的，免得太快的时钟把游戏拖慢。

每秒二十刻

《我的世界》Java 版的游戏世界，正常情况下每秒更新 20 次。几乎所有会动、会变的东西，都跟着这个拍子走。玩家说服务器“卡”，常常就是指它一秒钟打不满 20 下拍子了。

电脑的心跳

真的电脑里也有一个时钟，而且是电脑最重要的零件之一。它不停地发出“滴、滴、滴”的信号，电脑里所有的门、加法器、锁存器，都跟着这个拍子一起干活：拍子一响，大家一起往前走一步，算好的结果锁进锁存器，再算下一步。

为什么不能让它们各算各的？想象一个班的同学一起搬桌子，要是没有人喊“一、二、三，起！”，有的先抬、有的后抬，桌子就翻了。电路也一样：信号走过不同的路，到得有早有晚，时钟让大家等齐了再走。

这个拍子一秒钟打多少下，叫电脑的主频。1946 年的 ENIAC，主频大约是十万下，一秒钟能做大约五千次加法，当时已经快得吓人。小格那台电脑里的 M1 芯片，一秒钟最多能打大约三十二亿下。

游戏里的红石电脑呢？它们的拍子要等红石信号一格一格地传，大型的红石处理器常常一秒钟只能走一步，甚至几秒钟一步。

装置 · 第十三章

一秒钟能做几件事

上半部分是一个红石时钟，五盏灯排成一排，一闪一闪地往前“跑”。拖动滑块，改变它多久闪一次（游戏里，就是改中继器的多少和快慢）。下半部分比一比：一样多的“拍子”，交给不同的机器要做多久。

多久闪一次
一秒钟打多少拍（长度按“位数”画：每长一格，多一个零）
M1 一秒钟的拍子，交给谁来打？

ENIAC 的数字按“每秒约五千次加法”算，M1 按约 3.2 吉赫兹算，红石电脑按每秒一步算，都是粗略的比较。两个红石刻是这个时钟最快的一下：亮一个红石刻，灭一个红石刻。

卡了，会怎样

回到豆子的抱怨。小格的灯塔时钟、豆子的大农场、几十只动物……世界里要算的东西太多，电脑一秒钟算不完 20 遍，游戏就只好放慢拍子：可能一秒钟只打 15 下、10 下。这时候，你会觉得动物走路一顿一顿的，庄稼长得慢了，红石电路也跟着变慢。

所以玩红石的人有一个好习惯：不用的时钟要关掉。在时钟的线上接一个拉杆，不用的时候把它停下来。一座闪个不停、谁也不看的灯塔，也在悄悄占用电脑的力气。

试一试
游戏里
  1. 做一座闪烁的灯塔：找一个“中继器时钟”的教程，用几个中继器围成一个圈，接一盏红石灯。
  2. 把中继器的旋钮拨快拨慢，数一数灯十秒钟闪几次。
  3. 给时钟加一个拉杆开关，不用的时候关掉它。
游戏外
  1. 摸着手腕或者脖子，数一数你的心一分钟跳多少下。除以 60，一秒钟跳几下？和红石时钟比一比。
  2. 和三个同学一起拍手：一次没有人喊口令，一次有人喊“一、二、三”。哪一次拍得更齐？喊口令的那个人，就是“时钟”。
  3. 想一想：学校里的铃声、红绿灯、广播体操的音乐，哪一个也是在当“时钟”？
一座会自己闪的灯塔★

  2. 把中继器的旋钮拨快拨慢，数一数灯十秒钟闪几次。

十吉赫兹的梦

二十多年前，造芯片的公司比赛谁的主频高，有的公司说要做到一秒钟一百亿下（十吉赫兹）。结果拍子越快，芯片越热，热得没办法散掉，这个计划就放弃了。后来大家改成在一块芯片里放好几个“核”一起干活。小格那台电脑的 M1 芯片里就有八个核。书房里的《计算机创世记》上卷卷十二“墙”讲了这堵“热的墙”。

游戏一卡，红石电路就会算错半真

大多数时候，游戏卡了只是让一切变慢：红石电路按原来的顺序一步一步走，只是走得慢，答案还是对的。

可是有些机器要和别的东西“比快慢”，比如靠怪物走路的速度、靠玩家按按钮的时间来工作的机关，一卡就可能出错。还有些机器在区块没加载（玩家离得太远）时会停住，回来的时候停在半路。所以说它“会算错”，只说对了一半。

押韵

钟摆、晶体、红石火把

几百年前，钟表匠用一个来回摆动的钟摆，让钟表一下一下地走（书房里的《几点了》第五章讲过）；今天的电脑用一小片会振动的晶体打拍子；游戏里的玩家用一根火把绕回来管自己。三样东西，干的都是同一件事：做一个会自己一下一下重复的东西，让别的东西跟着它走。

游戏一秒钟打多少下拍子（游戏刻）？（填一个数）

每秒 20 下。每一下，游戏都把整个世界检查一遍。

一个“红石刻”是多久？

  1. 1 分钟
  2. 1 秒
  3. 0.1 秒

两个游戏刻算一个红石刻，就是 0.1 秒。中继器最少让信号晚一个红石刻。

游戏里一天是多少刻？（填一个数）

20 分钟 = 1200 秒，乘以每秒 20 刻，正好 24000 刻。

最简单的时钟电路是怎样做的？

  1. 一个“非”，把它的输出接回自己的输入
  2. 一个拉杆连一盏灯
  3. 两个“非”首尾相接

它亮了就让自己灭，灭了又让自己亮，永远停不下来。两个“非”首尾相接是锁存器，会停住。

电脑的时钟一秒钟打多少下拍子，叫什么？

  1. 主频
  2. 内存
  3. 字节

ENIAC 的主频大约十万下，小格电脑里的 M1 最多大约三十二亿下。

  1. 不用的时钟要关掉
  2. 时钟越多越好
  3. 从来不保存

给大人

Java 版每秒 20 个游戏刻、一个红石刻为 2 个游戏刻、一天 24000 刻，据官方与社区维基。红石火把“烧毁”机制据社区维基为 Java 版行为（短时间内反复切换会暂时熄灭），设计意图属于玩家社区说法。ENIAC 的基础时钟约 100 千赫，每秒约五千次加法；M1 性能核心最高约 3.2 吉赫兹、共八核（四个性能核加四个能效核）。十吉赫兹的计划指二十一世纪初英特尔的设想，后因功耗与散热放弃。

“不用的时钟要关掉”是很好的公共意识教育：在多人世界里，一个人做的机器会拖慢所有人。可以借机聊聊，在共享的地方做事，要想到别人。

游戏里带走一样游戏一秒钟打 20 下拍子；一个“非”接回自己，就成了会自己闪的时钟，用中继器能让它变慢。不用的时钟要关掉。
游戏外带走一样大家一起干活，要有人打拍子，让大家等齐了再走。电脑的“心跳”叫主频。
