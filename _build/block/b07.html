斜杠后面的一行字

在游戏里按 T 或者 / 键，会打开一个聊天框。如果打的第一个字是斜杠“/”，游戏就不会把它当聊天，而是当成一条命令去执行。比如：

  • /time set day：把时间改成白天。
  • /weather clear：让雨停下来。
  • /give @p diamond 3：给离你最近的玩家（@p）三颗钻石。
  • /fill：用一种方块，一下子填满一大块地方。

命令很强大，所以不是随便就能用的：要在创建世界时打开“允许作弊”（或者叫“允许使用命令”）。在生存模式里用了命令，一些成就就不能再拿了。

命令还有一个特点：一个字母都不能错。人和人说话，说错一个字别人也能猜到你的意思；电脑不会猜，/tiem set day 它就看不懂。这是你和电脑打交道时学到的第一课。

x、y、z：说清楚一个地方

很多命令要告诉游戏“在哪儿”，用的是三个数，叫坐标。x 是东西方向，z 是南北方向，y 是上下方向，也就是高度。第一部讲过，现在的世界从 y = −64 一直到 y = 320。

在 Java 版里按 F3（Mac 上常常要按 fn 加 F3），屏幕上会出现一大堆白字，其中有一行就是你站的坐标；基岩版可以在设置里打开“显示坐标”。有了坐标，你就能告诉朋友：“我的房子在 x = 120、z = −35。”他不管在哪儿，都能找过来。

这和数学课上的“坐标”、地图上的经度纬度，是同一个想法：用几个数，说清楚一个地方。

一行命令

这是一块十乘十的小地（x 和 z 从 0 到 9，高度 y 从 0 到 7）。在下面的黑框里打一行命令，按回车或者点“执行”。不会写？点上面的按钮，从“铺草地”开始一步一步来，看看每一行命令长什么样。这个小玩具只认识五种命令：/setblock、/fill、/time set、/weather、/say，方块名可以写英文（如 stone、oak_planks、glass、air），也可以写中文。

    写法照着游戏里的命令简化而来：/fill x1 y1 z1 x2 y2 z2 方块 会把两个角之间的整个“盒子”填满，填 air（空气）就是挖空。游戏里的命令还能用 ~ 表示“我站的地方”，能加很多别的设置，这个小玩具都省掉了。

    命令方块2012

    2012 年秋天，游戏里加了一种新方块：命令方块。它的样子像一块带花纹的铁块，你可以在里面写一行命令。平时它不动，一收到红石信号，就执行一次。

    这一下，红石和命令接上了。压力板、按钮、拉杆、时钟……所有第九到十三章学过的东西，都能用来“按”命令方块。小格的跳跳乐地图就可以这样做：岩浆底下铺一排压力板（或者让岩浆换成别的东西），连到一个命令方块，里面写一行“把踩到压力板的玩家传送到起点”。

    命令方块在生存模式里找不到，也合成不了，只能在允许作弊的世界里，用 /give @p command_block 拿到。它是专门给做地图的人准备的。2016 年，又多了两种：一种会一直不停地执行，一种会接着前一个执行，一串命令方块就能排成一个小程序。

    别人做好的小游戏

    有了命令方块，玩家开始做各种各样的“地图”：有故事、有机关的冒险地图，跳跳乐，解谜，捉迷藏，打怪闯关……有的地图会记分、计时、发奖品，玩起来像一个全新的游戏，可是它里面没有一个新方块，全是用命令和红石搭出来的。

    后来，地图越做越大，命令方块多得放不下。2017 年，游戏加了“函数”：把几十、几百行命令写进一个文本文件，一条命令就能把它们全部执行一遍。2018 年又有了“数据包”：把函数和别的设置打包成一个文件夹，放进世界的存档里，就能改变这个世界的规则，比如加新的合成方法、新的成就。

    写函数、做数据包，已经非常像写程序了：要起好名字，要分好文件夹，要一行一行检查哪里写错。很多人做地图做着做着，就学会了编程。

    试一试
    游戏里
    1. 请大人帮你新建一个“允许作弊”的创造模式世界（别在你辛苦盖的老世界里试）。
    2. 按 F3（或者打开“显示坐标”），找到你站的坐标，写在纸上。
    3. 用 /fill 铺一块 5×5 的石头地板。提示：两个角的 y 一样。
    4. 拿一个命令方块，里面写 /time set day，旁边放一个按钮。以后天黑了，按一下就天亮。
    游戏外
    1. 玩“机器人”游戏：一个人当机器人，蒙上眼睛（找个安全的地方）；另一个人只能用“向前走两步”“向左转”这样的命令，让他走到门口。命令说得不清楚会怎样？
    2. 在方格纸上画一个坐标图，横着写 x、竖着写 y，标出你家、学校、公园的位置，用两个数告诉同学它们在哪儿。
    用数字叫方块的名字

    很早以前，游戏里的每种方块都有一个编号：石头是 1，草方块是 2，泥土是 3……老玩家写命令时，常常直接写数字。2018 年的 1.13 版本把命令大改了一遍，从此只能用名字，比如 stone、grass_block。很多老地图里的命令一下子都不能用了，作者们只好一行一行地改。名字比数字好记，也不容易弄错，可是改规则的那一年，大家都很头疼。

    用命令就是作弊半真

    游戏里的那个开关，名字就叫“允许作弊”；在生存模式里用命令给自己变出钻石，也确实没有自己挖来得有意思，有些成就也因此拿不到。

    可是对做地图、做小游戏的人来说，命令是他们的工具，就像木匠手里的锯子。同一样东西，拿来偷懒是作弊，拿来创造就是本事。和朋友一起玩的时候，先说好规则就行。

    联系

    电脑不会猜你想说什么

    菜谱上写“盐少许”，人能看懂；电脑要的是“盐 3 克”。命令里写错一个字母，它就不干了。这让人有点生气，可也是好事：把自己想要的东西说得清清楚楚、一个字不差，这个本事在写作文、跟人约时间、给别人讲路的时候，都用得上。

    这一章的新词

    坐标x、y、z 三个数，说清楚一个地方。y 是高度。

    函数、数据包把很多行命令写进文件、打包放进世界里的办法。
    给大人

    命令方块随 Java 版 1.4.2（2012 年 10 月）加入，1.9（2016 年）加入循环型和连锁型命令方块；函数随 1.12（2017 年），数据包随 1.13（2018 年，快照 17w43a 首次出现）；1.13 重写命令系统、取消数字 ID。基岩版也有命令、命令方块和函数（行为包），写法有细微差别。装置里的命令是简化版：游戏里的 /fill 有单次方块数量上限，还有 replace、hollow 等选项。

    命令方块是从“玩”到“编程”的一座很好的桥：输入要精确、结果立刻能看到。建议给孩子单独建一个“实验世界”，别在他的主世界里试，免得一行 /fill 把他的房子填成石头。打开“允许作弊”的世界，适合当作学习工具，可以和孩子约定在这个世界里不追求成就。

    游戏里带走一样斜杠开头的一行字就是命令；x、y、z 说清一个地方；命令方块收到红石信号就执行，函数和数据包能把很多命令打包。
    游戏外带走一样电脑不会猜你的意思。把想要的东西说得清清楚楚、一个字不差，是和电脑、也是和人打交道的本事。
