你在编程课上学的东西

很多小朋友的第一门编程课，用的是一块一块能拖来拖去的彩色积木：把“移动 10 步”拖到“重复 10 次”里面，小猫就会走一百步。这种方法叫积木编程（也叫图形化编程），积木的形状决定了它们能不能卡在一起，所以几乎不会写错。

积木编程里最重要的几个想法，在方块游戏里全都用得上：

  • 重复（也叫循环）：同一件事做很多遍。盖塔就是“放一块，往上一格”重复二十遍。
  • 变量：一个能变的数，起一个名字。比如 i 从 0 数到 19，第 i 次就把方块放在高度 i 的地方。
  • 如果（也叫条件）：如果前面是水，就搭一座桥；不是，就往前走。第十章的逻辑门，就是“如果”的老祖宗。
  • 坐标：上一章的 x、y、z，告诉程序方块放在哪儿。

一个会听程序的小机器人2015 起

2015 年底，一个推广编程的组织和《我的世界》合作，做了一套免费的网页编程小课：画面是方块世界，玩家拖积木，指挥一个小人去砍树、挖矿、躲开岩浆。它在网页里就能玩，不用装游戏，很多学校的计算机课都用过。

后来，专门给学校用的“教育版”里，加了一个会听程序指挥的小机器人，叫“智能体”（Agent）。在游戏里按一个键，旁边会打开一个积木编程的窗口，积木和你课上用的很像。你写好程序，小机器人就照着去走路、放方块、挖地道、种庄稼。积木写熟了，还可以一键切换成用文字写的 Python 或者 JavaScript，看看同一个程序换成“文字代码”是什么样子。

树莓派上的免费版

2013 年初，英国有一种只有信用卡那么大、很便宜的小电脑，叫树莓派，是专门为了让孩子学编程而做的。Mojang 为它做了一个免费的特别版《我的世界》，叫 Pi Edition（树莓派版）。

它的玩法很少，只有创造模式，可是它带了一个其他版本都没有的东西：一套能用 Python 控制游戏的接口。孩子们写几行 Python，就能在游戏里瞬间盖出一座房子、让脚下自动铺出一条路、把自己“发射”到天上。很多老师和家长就是从这里第一次发现：方块游戏可以拿来学编程。

树莓派版

    
树莓派上的免费版是照着很早的手机版做的，玩法一直很少。后来它就不再更新了，树莓派的新系统也不再自带它。它留下的那套 Python 接口，被热心的程序员接着维护，搬到了别的地方继续用。一个版本停了，它教会大家的那个想法，没有停。

  


  

    
学编程，得先把英语学好半真

    
积木编程有中文版，完全不用英语就能学；你现在就能写出“重复”“如果”的程序。
等到写文字代码的时候，确实会碰到 for、if、range 这样的英文单词，不过常用的也就几十个，多半比英语课上的单词还简单，用着用着就记住了。很多小朋友反过来，是因为编程才多认识了一些英文单词。

循环同一件事重复做很多遍，就是“重复”积木。

    给大人
    
Code.org 与 Minecraft 合作的“编程一小时”网页课程始于 2015 年底，此后每年有新主题，免费、在浏览器中运行。教育版（Minecraft Education）的 Code Builder 集成 Microsoft MakeCode，可在积木、JavaScript、Python 之间切换，2020 年起陆续加入基于 Python 的课程；教育版有 macOS 版本，一般需要学校或机构的 Microsoft 365 教育账号，个人购买与试用政策以官方为准。Minecraft: Pi Edition 2013 年初发布，免费，带 Python API（mcpi），后停止更新，接口由社区维护（如 PyPI 上的 mcpi 包）。装置中的 Python 写法参考 MakeCode 的 blocks.place、blocks.fill 与 world()，方块常量名以 MakeCode 内实际显示为准。

    
建议把这一章交给孩子的编程老师看：很多少儿编程课用的正是 Scratch 一类的积木，和 MakeCode 的思路一致。本书不推荐任何付费课程。如果孩子想自己做“方块游戏”，Scratch 里画一个 8×8 网格、点击放方块，是一个大约一两节课能完成的好项目。

  


  

    
游戏里带走一样重复、变量、如果、坐标，是用代码搭房子的四样工具。写三行代码盖二十层的塔，改一个数字就能盖一百层。

    
游戏外带走一样编程课上的积木和方块游戏是同一套想法。做 5 遍和做 500 遍写起来差不多长：重复的活，交给电脑。
