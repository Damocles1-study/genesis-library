苹果电脑上，能装哪个版本

第一部第六章讲过，《我的世界》后来分成了两套程序：Java 版和基岩版。它们在苹果电脑上的情况是这样的（以官方最新说明为准）：

  • Java 版：能在 Windows、Mac 和 Linux 电脑上玩。苹果电脑上装的就是它。要先用一个微软账号登录官方的启动器，再下载游戏。
  • 基岩版：手机、平板、游戏机和 Windows 电脑上的那个版本。它没有专门的 Mac 版。这就是豆子在平板上的世界，不能直接搬到小格电脑上的原因。
  • 中国版：第一部第七章讲过的网易代理版。它有电脑版，能不能在你的 Mac 上装、要怎么装，以网易官方的说明为准。
  • 教育版：学校用的版本，有 Mac 版，下一章细讲。

有一件事一定要记住：只从官方网站或者官方应用商店下载。网上那些“免费破解版”“绿色版”，常常夹带病毒，还可能偷走你和爸爸妈妈的账号。第一部第八章讲过藏在模组里的病毒，破解版更危险。

M1 芯片和“原生支持”2020—2022

2020 年底，苹果在 MacBook Air 里换上了自己设计的 M1 芯片。它和以前苹果电脑用的芯片“说的不是同一种话”：同样一条指令，两种芯片的写法不一样。第二部第十四章讲过，电脑是一条一条照着指令做事的。

所以一开始，Java 版在 M1 电脑上要靠苹果的一个“翻译程序”（叫 Rosetta 2）一边翻译一边运行，能玩，可是多绕了一道弯。2022 年夏天的 1.19 版本以后，Java 版开始原生支持苹果芯片，就是直接用 M1 听得懂的话来写，不用再翻译了。

8 GB 和 2026 年的新配置说明

2026 年 7 月，Mojang 十几年来第一次正式更新了 Java 版的电脑配置说明。像 M1 这样显卡做在芯片里面的电脑，官方写的最低内存是 12 GB，推荐 16 GB。

小格那台 M1 MacBook Air 只有 8 GB 内存，低于新的最低要求。官方同时也说，低于这个配置的电脑游戏照样能打开，只是不再保证画面和流畅度。所以，对这台电脑来说，最要紧的就是下面讲的：把设置调低一点。报道这件事的媒体也说，游戏本身并没有突然变得更“吃”电脑，只是旧的说明写了十几年，太久没改了。

键盘和触控板

苹果电脑的键盘和别的电脑有一点点不一样。最常用的几个键是这样的：

W A S D往前、左、后、右走
空格跳；连按两下在创造模式里飞
Shift潜行，走到边上不会掉下去
control跑（也可以连按两下 W）
E打开物品栏
1—9换手里拿的东西
T聊天；/直接输入命令
esc暂停、打开菜单
fn + F3显示坐标等信息
fn + F5换成第三人称视角
fn + F2截图，存在游戏文件夹里
两指轻点触控板上的“右键”：放方块、开门

带 fn 的那几个，是因为 Mac 键盘最上面一排默认是调亮度、调音量的，要按住 fn 才变成 F 键（也可以在系统设置里改）。如果觉得触控板太难用，接一个鼠标会轻松很多：左键挖，右键放，滚轮换东西。

卡了、烫了怎么办

MacBook Air 有一个特点：它没有风扇，所以很安静，可是热了只能靠机身慢慢散热。玩久了它会变烫，变烫以后芯片会主动放慢，免得把自己烧坏，于是游戏就开始卡。几个办法：

  • 把“视野距离”调小。这是最管用的一招，下面的装置会告诉你为什么。
  • 把画质调成“流畅”，关掉云、平滑光照这些好看但费力的选项。
  • 玩之前关掉别的程序，尤其是开了很多网页的浏览器。8 GB 内存，大家要省着用。
  • 插上电源，放在硬桌面上。别放在被子、枕头、腿上，底下要能透气。
  • 别装来路不明的“加速”“优化”软件。想装，先问大人。
装置 · 第十七章

视野距离

游戏把世界切成一块一块 16 × 16 格的方柱，叫区块。“视野距离”就是你往四周能看到几个区块。拖动滑块，看看电脑要同时准备多少区块（中间的红点是你，绿色是电脑要准备的地方）。

视野距离

视野距离从 12 调到 6，往四周看的距离少了一半，可是电脑要准备的区块从 625 个变成 169 个，少了将近四分之三。这是因为区块是一圈一圈往外铺的：半径翻一倍，面积要翻四倍。每个区块从底到顶有 384 格高。实际上，游戏不会把每一格都画出来，看不见的会跳过，这里只是帮你感受“多了多少”。

存档放在哪儿

第二部第十二章讲过，你的世界存在硬盘里。在 Mac 上，Java 版的存档一般放在这个文件夹里：

~/Library/Application Support/minecraft/saves

每一个世界是里面的一个文件夹。想备份，就请大人帮你把这个世界的文件夹复制一份，放到别的地方（比如一个 U 盘）。电脑坏了、不小心删掉了、一行 /fill 把房子填成了石头，都还能找回来。

试一试
游戏里
  1. 在“选项”里找到“视野距离”，从 12 调到 8，再调到 4，看看远处的景色有什么变化，游戏是不是更顺了。
  2. 按 fn + F3，找到你站的坐标，再找到一行写着“fps”的字：那是游戏一秒钟画几张画面，越高越顺。
  3. 请大人帮你找到存档文件夹，把你最喜欢的世界备份一份。
游戏外
  1. 在一张纸上画出 MacBook 的键盘，把上面那些游戏里常用的键涂上颜色。
  2. 玩二十分钟以后，摸一摸电脑底部（别摸太久），是不是变热了？想一想，没有风扇的电脑靠什么散热。
  3. 在纸上画一个 3 × 3 的方格，再画一个 5 × 5、7 × 7 的。半径每多一格，要多画多少个格子？
Mojang 账号

很多年里，玩 Java 版用的是 Mojang 自己的账号。微软买下 Mojang 以后，2020 年宣布要把所有账号都换成微软账号，到 2023 年前后，老的 Mojang 账号就不能再登录了。换成微软账号以后，爸爸妈妈可以给孩子开一个“儿童账号”，在家庭设置里管：能不能和别人联机、能不能花钱、能和谁聊天。

苹果电脑玩不了我的世界假

Java 版一直都能在苹果电脑上玩。Notch 当年就是用 Java 写的它，Java 程序本来就能在 Windows、Mac、Linux 上运行。M1 以后的苹果电脑，从 2022 年起还能原生运行。

不能在 Mac 上玩的，是基岩版。所以更准确的说法是：苹果电脑上玩的是 Java 版。

先认识你的工具

木匠要知道自己的锯子能锯多厚的木头，厨师要知道自己的锅能烧多大的火。你的电脑也一样：它有多少内存、怕不怕热、哪个键在哪儿。先把手里的工具摸清楚，再去做大东西，这句话在第三部会反复出现。

给大人

Java 版支持 Windows、macOS、Linux；基岩版没有原生 macOS 版本。2022 年 6 月起官方在电脑上把 Java 版和基岩版合并销售（Mac 上实际可用的是 Java 版）。Java 版 1.19（2022 年 6 月）起原生支持 Apple Silicon，见 AppleInsider 等报道。2026 年 7 月 21 日 Mojang 更新 Java 版配置要求：最低 macOS 12、Apple M1，集成显卡最低 12 GB 内存，推荐 macOS 14、16 GB，并说明低于最低配置仍可启动但不保证表现；见 PC Gamer、Notebookcheck 等报道。Mojang 账号迁移到微软账号于 2020 年宣布，2023 年前后完成。存档路径为 Java 版默认路径。

建议：用家长的微软账号为孩子建立儿童账号，在 Xbox/微软家庭设置里管理多人游戏、聊天和购买。8 GB 的 M1 Air 跑原版 Java 版通常可以，但建议视野距离 6—8、模拟距离 5—6、画质“流畅”，并避免同时开很多浏览器标签页。不要给孩子装来路不明的启动器、破解版或“优化包”。

游戏里带走一样Mac 上玩的是 Java 版，只从官方下载。卡了先调小视野距离；两指轻点是右键；存档在 saves 文件夹里，记得备份。
游戏外带走一样先认识你的工具：它能做什么、怕什么。半径翻一倍，面积翻四倍。
