长大以后门外面的事

走出方块世界，门外面有好东西，也有要小心的事。这一卷讲三件事：网上的人和网上的骗局；为什么一玩就停不下来，怎样和家里人一起定规矩；长大以后，你在方块世界里练出来的本事，能用在什么地方。

你看不见屏幕那头是谁

在游戏里，每个人都是一个方方的小人，顶着一个自己起的名字。名字可以叫“小明”，也可以叫“官方管理员”；可以说自己十岁，也可以说自己是老师。你看不见屏幕那头真正是谁。大多数人只是来玩的，可是也有一些人，是专门来骗东西、骗信息的。

所以，网上交朋友，要比现实里多一份小心。在现实里，你不会把家门钥匙交给一个刚认识的人；在网上，有几样东西就是你的“钥匙”。

四样不能说的东西

  • 密码：账号的密码只能自己和爸爸妈妈知道。好朋友也不给。
  • 你是谁、你在哪儿：真名、学校、班级、家住哪个小区、几点放学。这些拼在一起，别人就能在现实里找到你。
  • 照片和视频：尤其是你自己、你家、你穿着校服的照片。
  • 别的联系方式：电话号码、别的聊天软件的号码。有人想把你“拉”到别的软件里聊，要特别小心。

“免费送”的骗局

在方块游戏里最常见的骗局，几乎都长一个样子：先给你一样好东西，再要你一样东西。

  • “免费送皮肤、送游戏币、送会员”：然后要你的账号密码。
  • “点这个链接领取”：链接打开是一个长得很像官方的假网站，让你输入账号密码，或者下载一个带病毒的文件。
  • “我是官方客服，你的账号有问题”：然后要你的验证码。验证码和密码一样，不能给任何人。
  • “帮你便宜代充”：然后要爸爸妈妈的支付密码，或者让你先转钱。

记住一句话：真的官方，从来不会在游戏里私信问你要密码和验证码。所有“免费”“限时”“只有你中奖了”的话，都先停一停，去问大人。

这条消息怎么办

下面是十件在方块游戏里可能碰到的事。每一件，选一个你觉得最好的做法，马上就会看到解释。

这些情景是编的，可是每一种骗法都真的有人碰到过。十道题里，有一个答案一直在出现：告诉大人。这不是因为你不聪明，而是因为骗子专门挑你一个人的时候下手。

被骂了、房子被炸了

不是所有坏事都是骗局。有时候是有人在聊天里骂人、取笑别人；有时候是有人故意把别人辛辛苦苦盖的东西拆掉、炸掉，玩家叫这个“恶意破坏”。碰到这些：

  • 不要骂回去、炸回去。那样只会越闹越大。
  • 截图，留下证据。
  • 屏蔽、举报，然后离开那个服务器或者世界。
  • 告诉大人，或者服务器的管理员。

最省心的办法，是一开始就只和认识的人玩：和同学、家人一起，在一个只邀请朋友进来的私人世界里玩。公共服务器先让大人看看再去。

2022 年，Java 版也能举报聊天了

基岩版很早就能举报别的玩家。2022 年夏天，Java 版的 1.19.1 版本也加上了这个功能：玩家可以选出让人不舒服的那几条聊天消息，选一个原因，交给 Mojang 的工作人员去处理。为了防止有人伪造聊天记录来诬告别人，游戏还给每条消息加上了一种“电子签名”。

爸爸妈妈还可以在微软的家庭设置里，给孩子的账号设定：能不能和别人一起玩、能不能聊天、只能和朋友聊天，还是谁都不能聊。

遇到不舒服的事，告诉谁

如果在网上看到了让你害怕、恶心、不舒服的东西，或者有人说了让你不舒服的话、让你保密、让你做你不想做的事：

这不是你的错。马上停下来，告诉一个你信任的大人：爸爸妈妈、老师，或者别的你信得过的大人。就算你觉得自己“也做错了一点”，比如偷偷加了好友、偷偷去了不该去的服务器，也要说。大人知道得越早，越能帮你。

不能举报的聊天框

2022 年以前，在 Java 版的服务器里碰到有人骂人，只能找服务器自己的管理员。举报功能刚加上时，也有不少玩家担心被人乱举报，吵了很久。后来大家慢慢习惯了：就像现实里的公园有保安、有规矩一样，网上的公共空间也要有人管。

网上说自己是小朋友的，就一定是小朋友假

网上的年龄、名字、照片都可以是假的。一个说自己“十岁、四年级”的人，可能真的是同龄人，也可能是一个大人。

这不是说网上的人都是坏人，而是说：你没法确认。所以那四样不能说的东西，对谁都不能说。

天上不会掉皮肤

小区门口有人说“扫码免费送玩具”，大人会提醒你别扫；游戏里有人说“免费送皮肤”，也是一样的道理。别人凭什么白白给你东西？先想清楚这个问题，大多数骗局就不灵了。书房里给大人看的《值不值》第十章，讲的是长大以后会碰到的同一种话术。

给大人

Java 版 1.19.1（2022 年 7 月）加入玩家聊天举报与消息签名，见官方更新说明；基岩版此前已有举报功能。微软/Xbox 家庭设置可以管理儿童账号的多人游戏、聊天对象和购买。中国版有实名和防沉迷要求（见第一部第七章）。

比规则更重要的是让孩子愿意说。建议对孩子明确承诺：只要他主动告诉你，就算他也违反了约定（比如偷偷加了好友），这一次先不罚。很多孩子不说，是怕被没收电脑。另外，请亲自看一遍孩子常去的服务器和他关注的视频频道；公共服务器的聊天和私信最难管。

游戏里带走一样密码、你是谁和在哪儿、照片、别的联系方式，四样不能说。真的官方不会私信要密码。被骂、被炸：截图、屏蔽、举报、离开。
游戏外带走一样别人凭什么白白给你东西？拿不准的时候，告诉一个你信任的大人。这不是你的错。
