一块一块我的世界创世记

第四部 · 工

前三部讲的是“为什么”：方块世界从哪里来，红石怎样变成电脑，走出游戏能带走什么。这一部讲“怎么做”。它是一间工坊，每一章都是一个可以照着做的项目。

你会写出自己的第一个数据包，让游戏照着你写的字做事；会让 Python 替你写出几千行命令，盖一个玻璃球；会打开电脑里的“仪表盘”，看游戏到底在用电脑的哪一部分，再做一次像科学家那样的实验；会和朋友局域网联机，弄明白 IP 地址和延迟；会在自己的电脑上开一个服务器。最后一卷离开键盘，讲方块里的数学和物理、怎样和 AI 一起学，和一张从现在到高中的自学地图。

这些事，以前要等到上中学、上大学才会碰到。可是它们并不神秘，只是一步一步的。很多步骤要请大人一起做，每章开头的“工坊卡”会写清楚。

暑假的工坊

四年级结束的那个暑假，舅舅放假回家，在小格家的书桌上贴了一张纸：“工坊开张”。他们约好：每个项目先读一遍、再动手；要用终端、要下载东西、要上网问 AI 的时候，大人必须在旁边；每天做完一个项目，就在第三十二章的技能树上点亮一格。豆子也来了：他想知道，为什么他的平板进不了小格的世界。

每一章怎么读

  • 工坊卡：难度（一到四颗星）、大约多久、要准备什么、要不要大人。
  • 一步一步：带编号的步骤，黑框里是要输入的字，一个字母都不能错（第十五章讲过为什么）。
  • 出错了怎么办：最常见的几种错误。出错是正常的，程序员每天都在出错、找错。
  • 其余的和前三部一样：存档、真事、装置、试一试、传言、眉批、新词、给大人、两样带走。

版本说明：这一部按 2026 年时 Mac 上的 Java 版来写。游戏每年都在更新，有些文件的写法、需要的软件版本会变。碰到对不上的地方，以社区维基和官方说明为准；查资料、对版本，本身也是这一部要学的本事。

  • MacBook Air 的版本、键盘、存档文件夹：第十七章。网上的陌生人：第二十一章。
