先装上 Python

  1. 请大人一起，打开 Python 的官方网站（python.org），在“下载”里找到给 macOS 的安装包，下载、双击安装。安装时电脑会要密码，这一步让大人来。只从官网下载，别从别的网站。

小海龟画螺旋

Python 自带一只会画画的“小海龟”：你告诉它往前走几步、往左转几度，它就在屏幕上画出线来。这和你在编程课上让小猫走路，是同一回事。

  1. 在 IDLE 里点菜单“File”→“New File”，打开一个新窗口，写下： 
    import turtle

t = turtle.Turtle()
for i in range(36):        # 重复 36 次
    t.forward(i * 5)       # 每次走得比上次远一点
    t.left(90)             # 向左转 90 度
turtle.done()
  2. 保存，名字叫 spiral.py。千万别叫 turtle.py：那样 Python 会以为你自己的文件就是“小海龟”，反而找不到真的那只。
  3. 点菜单“Run”→“Run Module”（或者按 fn + F5）。一个窗口弹出来，小海龟画出一个方形的螺旋。
  4. 把 90 改成 91，再运行一次。只差一度，画出来的东西完全不一样了。

注意那几行前面空出来的四个空格，叫缩进。Python 靠缩进知道哪几行在“重复”里面。少一个空格、多一个空格，它就会报错。

方格纸上的勾股定理

怎样让电脑知道一块方块在不在球里面？先在方格纸上想一个圆。圆心在 (0, 0)，半径是 5。点 (3, 4) 在圆上吗？

从圆心往右走 3 格，再往上走 4 格。这两段路和“从圆心直接走到那个点”的那条斜线，围成一个直角三角形。两千多年前人们就知道：3 × 3 + 4 × 4 = 5 × 5，也就是 9 + 16 = 25。所以 (3, 4) 离圆心正好是 5，正好在圆上。这叫勾股定理，中国古书《周髀算经》里有“勾三股四弦五”的说法，你要到初中才会正式学它。

所以规则很简单：x × x + y × y 小于等于 r × r，这个点就在圆里面。到了立体的球，再加上一个 z × z 就行。电脑把球附近的每一格都这样检查一遍，几千格，一眨眼。

一条蛇？不，是一个喜剧节目

    
Python 这个名字的意思是“蟒蛇”，所以很多书的封面上画着蛇。可是它的发明人，荷兰程序员吉多·范罗苏姆，是因为喜欢英国的一个喜剧节目才起了这个名字。1991 年，他公开了 Python 的第一个版本。他想要一种读起来像英语、写起来不啰嗦的语言。

    
今天，Python 是世界上用得最多的编程语言之一：科学家用它算数据，网站用它做后台，人工智能的程序很多也是用它写的。第十四章那个用红石搭的聊天机器人，作者就是先在真电脑上用 Python 把它“训练”好的。

Python 2

    
Python 有过两个大版本。很多老教程里写着 print "hello"，不加括号，那是 Python 2 的写法。Python 2 在 2020 年 1 月 1 日正式“退休”，不再更新。现在装的都是 Python 3，要写成 print("hello")。看到老写法，就知道那篇教程至少是好几年前的了。

  


  

    
Python 能直接控制 Java 版的游戏半真

    
原版的 Java 版游戏里，没有一个让 Python 直接说话的“插口”。第十六章讲的树莓派版有，教育版的代码窗口也有；Java 版要装别人写的模组或者服务器插件才行。
这一章的办法绕开了这个问题：Python 不碰游戏，只负责写文件；游戏只负责读文件。两边各干各的，什么都不用装。很多真实的软件也是这样合作的。
