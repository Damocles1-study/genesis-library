一块芯片里的电脑

第十七章讲过，小格的 MacBook Air 用的是苹果的 M1 芯片。以前的电脑，运算、画画、记东西的零件是分开的好几块；M1 把它们几乎全都放进了一块指甲盖大小的芯片里：

  • CPU（中央处理器）：第十四章说的“处理器”，照着程序一条一条干活。M1 有 8 个核：4 个跑得快的，4 个省电的。游戏里怪物往哪儿走、红石传到哪儿、庄稼长没长，都是它在算。
  • GPU（图形处理器）：专门画画面的。屏幕上每一秒要画几十张画，每张画有几百万个像素（第一章讲过），每个像素什么颜色，都要算。GPU 有很多很多个小核，一起分工画。
  • 内存：第十二章的“会忘的记忆”。8 GB，游戏把你周围的区块、怪物、物品都放在这里。
  • 硬盘：第十二章的“不会忘的记忆”。游戏本身、你的存档都放在这里。
  • 神经网络引擎：专门给人工智能一类的计算用的，玩游戏时基本用不上它。

这些零件挤在一起，好处是快、省电；坏处是热也挤在一起。第十七章讲过，这台电脑没有风扇。

电脑的仪表盘

  1. 打开“应用程序”→“实用工具”→“活动监视器”。
  2. 点上面的“CPU”：列表里有一行叫 java，那就是你的游戏（Java 版是用 Java 写的）。看它的百分比。
  3. 点“内存”：最下面有一条“内存压力”曲线。绿色是轻松，黄色是有点挤，红色是挤不下了，电脑会把一些东西临时挪到硬盘上，就会变慢。
  4. 回到游戏，按 fn + F3：左上角有一个 fps，是游戏一秒钟画了几张画面（帧数）；右上角有一行 Mem，是游戏用了多少内存。

一边玩，一边看这几个数字怎样跟着你变：站着不动、跑起来、飞起来、看着一大片森林。你会发现，电脑的每一样零件，都在为你屏幕上的那一刻忙着。

做一次像科学家那样的实验

问题：视野距离调得越远，帧数会掉多少？科学家做实验，有三条规矩：

  • 只改一样东西：这次只改视野距离。站的地方、看的方向、画质、电脑插没插电，都保持一样。这叫“控制变量”。
  • 量好几次：每个视野距离，等画面稳定以后看三次帧数，记下来，算平均。一次的结果可能是碰巧。
  • 画成图：把数字画成一条线，规律一眼就看出来。

视野和帧数

这是一张实验记录表。一开始填的是编出来的示意数字，用来告诉你图会长什么样。做完实验，把表里的数字换成你自己量的，右边的平均值和下面的图会跟着变。你填的数字只保存在这台电脑的浏览器里。

示意数字是编的，不同电脑、不同版本、不同地形差别很大，所以才要自己量。如果你的线不是往下走的，也不奇怪：可能是电脑还很轻松，帧数被“垂直同步”或者“最大帧率”这个设置封顶了。找出原因，也是实验的一部分。

为什么不拆电脑

笔记本电脑里的锂电池，被扎破、压弯、拆坏，可能会发热、冒烟甚至起火。现在的苹果电脑里，零件又大多焊在一起，自己拆了也修不回去。所以这本书的规矩是：不拆。

想看电脑里面长什么样，可以和大人一起在网上找专业维修网站拍的拆机照片：一张一张，比自己拆看得还清楚。也可以去科技馆，那里常常有剖开的电脑和手机。

英特尔芯片的 Mac

从 2006 年到 2020 年，苹果电脑用的都是英特尔公司的芯片。2020 年底，苹果开始换成自己设计的 M1，到 2023 年，最后一种英特尔芯片的 Mac 也换掉了。这就是第十七章说的“两种芯片说的不是同一种话”，也是 Java 版要专门做一次“原生支持”的原因。

内存越大，游戏越快半真

内存不够的时候，加内存确实能让游戏快很多：东西不用挤来挤去，不用临时挪到硬盘上。

可是内存够了以后，再加也不会更快了，这时候卡在哪儿，要看 CPU 和 GPU 忙不忙。就像书包够大以后，再换一个更大的书包，你也不会走得更快。先量一量瓶颈在哪儿，再想办法，这正是这一章的实验教你的。

从红石火把到八个核

第二部里，一根红石火把是一个开关，几十根拼成一个门，几千块方块拼成一台加法器，一秒钟走一步。小格手里这块芯片，有一百六十亿个开关，一秒钟三十多亿下拍子，八个核一起干活。它们的原理是一样的；差别只在于，开关被做得越来越小，小到要用显微镜也看不见。

给大人

M1（2020）：8 核 CPU（4 性能核 + 4 能效核）、7 或 8 核 GPU、16 核神经网络引擎、8 GB 或 16 GB 统一内存，MacBook Air 机型无风扇，据苹果发布资料。苹果 2020—2023 年完成从英特尔到自研芯片的过渡。活动监视器中 Java 版进程通常显示为 java；F3 调试界面左上角显示帧率，右上角显示内存占用。装置中的数据是示意，不是实测。

这一章的重点是科学方法：控制变量、重复测量、取平均、作图。孩子小学科学课会学到“对比实验”，这是一次很好的练习。不建议让孩子自己拆机，可以一起看专业维修网站的拆机图解。
