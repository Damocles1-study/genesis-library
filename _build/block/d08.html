从现在到高中

下面是一张大概的地图。它不是课程表，不用按年龄卡死：跑得快的可以往前走，哪一段特别喜欢也可以多待一会儿。每一站都有“游戏里”和“游戏外”两条路，因为你最终要做的，是游戏外面的东西。

免费的好地方

学这些东西，不一定要花钱上课。下面这些都是免费的，大多是学校、非营利组织或者官方做的（本书不推荐任何付费课程）：

  • Scratch：麻省理工学院做的积木编程网站，可以看别人的作品、做自己的作品。
  • Code.org：第十六章讲过的“编程一小时”，有方块世界主题的课。
  • CS Unplugged：新西兰的大学老师做的“不插电的计算机课”，用纸牌、绳子、游戏学二进制和算法，第十一章的猜数魔术就是这一类。
  • 可汗学院：数学、科学、编程的免费视频课。
  • 国家中小学智慧教育平台：教育部门办的免费平台，有各年级各科的课。
  • Python 官方教程和 IDLE：装好 Python 就有。
  • Minecraft 社区维基：查命令、查版本、查数据包格式，第二十五章已经用过。
  • MakeCode：微软的免费积木编程网站，可以做小游戏，也能编程控制一块小电路板。

英文网站可以请大人帮你切成中文，或者一起慢慢读。用多了，你会发现编程里那几十个英文词，比英语课本简单。

把创意做到游戏外面去

这本书的最后一句话是第三部的“每一个大世界，开头都只有一块”。到了这里，可以再往前一步：你的第一块，不一定要放在方块世界里。

  • 一个自己的游戏：在 Scratch 或 MakeCode 里，做一个你在方块世界里想要、却没有的玩法。
  • 一个自己的网页：你正在读的这本书，就是一堆网页，用的是 HTML、CSS 和一点点 JavaScript。初中时，你也能做一个介绍自己作品集的网站。
  • 一个能拿在手里的东西：第二十章的纸方块和 3D 打印。
  • 一个给家里用的小工具：用 Python 写一个算零花钱的小程序、一个背单词的小测验。
  • 一份实验报告：第二十七、三十章的实验，写成一张有问题、有方法、有数据、有结论的报告，交给科学课老师。
装置 · 第三十二章

我的技能树

像游戏里的进度一样，每做完一件事，就点亮一格（再点一下取消）。实线框是现在就能去试的，虚线框要先点亮前面的格子。下面会告诉你下一步可以做什么。点亮的格子只保存在这台电脑的浏览器里。

最右下角那一格“我的作品”，需要红石、代码、服务器、物理、AI 几条路都走过。它的意思不是“学完了”，而是：你已经有足够的本事，去做一个只属于你的东西了。

试一试
游戏里
  1. 做一张自己的小地图给朋友玩：用上至少一个数据包函数、一个 Python 生成的形状。
  2. 在技能树上点亮你已经做到的格子，挑一个“现在可以去试”的，这个星期去做。
游戏外
  1. 在一张大纸上画你自己的自学地图：现在在哪儿，下一站去哪儿，想做出一个什么东西。贴在书桌旁边，和第二十二章的公约贴在一起。
  2. 挑一个上面的免费网站，和大人一起注册（或者不注册直接用），做完第一节课。
  3. 想一个“方块世界里没有、但你很想要”的玩法，用 Scratch 做出它的第一版，哪怕很简陋。

照着杂志敲代码

二十世纪八十年代，很多电脑杂志上会印整页整页的程序，读者照着一个字母一个字母地敲进电脑，敲完就能玩一个小游戏。敲错一个字，就要从头找。第一部第二章讲过，Notch 小时候就是这样学会编程的。后来有了网络，代码可以直接下载、复制，这种杂志就消失了。可是“一个字一个字敲、敲错了自己找”的那份功夫，到今天还是学编程最好的办法。

学编程要趁早，晚了就来不及假

很多很厉害的程序员，是上了中学、大学，甚至工作以后才开始学编程的。早一点开始，好处是你有更多时间“玩”着学，不着急。

可是比起“早”，更要紧的是喜欢和一直做下去：一个星期做一个小东西，坚持一年，比一个暑假学十门课有用得多。要是哪天你发现自己更喜欢画画、更喜欢踢球，也完全没关系，这本书里练出来的那些本事，到哪儿都带得走。

给大人

列出的资源均为免费：Scratch（MIT 媒体实验室）、Code.org、CS Unplugged（新西兰坎特伯雷大学团队）、可汗学院、国家中小学智慧教育平台、Python 官方教程、Minecraft 社区维基、Microsoft MakeCode。技能树数据只保存在本机浏览器（键名 genesis-block-skills）。表格里的年级只是大致参考。

比学多少更重要的是节奏：每周固定一小段“工坊时间”，每次做完一个小东西、记进作品集，比假期突击有效得多。孩子的兴趣会变，这很正常；即使他以后不再玩方块游戏，读报错、做实验、查证、把想法做出来的习惯，都会留下来。也请别让工坊挤掉睡眠、运动和自由玩耍的时间（第三部封面装置）。

游戏里带走一样红石、命令、数据包、Python、服务器、物理实验、和 AI 一起检查代码：你已经能在方块世界里做出一个给朋友玩的小游戏了。
游戏外带走一样自己画地图：现在在哪儿，下一站去哪儿。免费的好地方很多，喜欢和坚持比“早”更要紧。轮到你了。
