这一部你做到了多少

每一章末尾都有一张任务卡和一组闯关自测，这一部一共 8 张任务卡、8 关。做过的会记在这台电脑的浏览器里，第十部最后一章的成就墙会把十部加在一起。

哪些是真的

  • 编的：小格、舅舅、妈妈、豆子和“存档”里的故事，包括暑假的工坊和最后的局域网派对。第二十七章实验表里一开始填的数字是编的示意。装置里的数据包、Python 程序、服务器设置是为了教学而写的例子。
  • 真的：游戏、软件和网络的工作方式，以及正文里的年份和事情，尽量核对过。说不准的地方写了“据社区维基”“据报道”。
  • 会变的：这一部写的是 2026 年时 Mac 上的 Java 版。数据包格式号、服务器要的 Java 版本、各家 AI 的年龄规定、教育版和 Realms 的办法，都可能在你读到时已经变了。以社区维基和官方说明为准。

第四部存疑和要核对的地方

  • 数据包格式号：书中的 48（1.21 / 1.21.1）和 88（1.21.9 / 1.21.10）只作举例；1.21.9 起改用 min_format / max_format；2026 年的新版本号码以维基为准。
  • 函数文件夹改名：1.21 起从 functions 改为 function。
  • 书中的命令：按 1.21 系列的写法写成，没有在每个版本里逐一实测，请先在实验世界里试。
  • 服务器要的 Java 版本：1.20.5 起要 Java 21；据 2026 年的报道，新版本要 Java 25。以官方服务器下载页为准。
  • 移动速度、下落规则、摔落伤害、燧石概率、亮度：来自社区维基和玩家对游戏代码的整理，不同版本可能有出入。
  • 伽利略在比萨斜塔扔球：书中已标“存疑”。
  • “两个月一亿用户”：来自 2023 年初的媒体报道和分析机构估计。
  • AI 服务的年龄规定：各家不同、会调整，以服务条款为准。

轮到你了

四部三十三章。第一部讲一块方块从哪里来，第二部讲一根红线怎样变成电脑，第三部讲走出游戏以后能带走什么，第四部把工具一样一样交到你手里：数据包、Python、电脑的仪表盘、局域网、服务器、秒表和方格纸，还有一个要你去检查的 AI。方块世界是一个规则清清楚楚的小宇宙，在这里练会的“写清楚、读报错、做实验、查证、把想法做出来”，在外面那个没有说明书的大世界里，一样用得上。第一块已经放下了，下一块，由你来放。
