自己不干活的键

你按一下 A，屏幕上就出来一个 a。可是你按一下 shift，什么也不会发生。

shift 这样的键，单独按没有用，要和别的键一起按。它们的工作是“改一改”别的键：按住 shift 再按 A，出来的就变成大写的 A。这种键叫修饰键，英文叫 modifier key。“修饰”就是打扮、改一改的意思。

Mac 键盘最下面一排，左边挤着四个修饰键，再加上左边那一列的 shift，一共五个：

符号名字英文（点一下听）在哪儿一句话
⌘命令键command空格键两边，各一个Mac 上用得最多的修饰键，几乎所有快捷键都有它
⇧上档键shift左右两边，最长的那两个打大写字母，打数字键上面那排符号
⌥选项键optioncommand 外面那个“另一种做法”：按住它，很多菜单会变出隐藏的选项
⌃控制键control最左下，fn 右边按住 control 再点一下，等于右键；游戏里按住它是跑
fn功能键function最左下角，上面还画着一个小地球 🌐按住它，最上面一排才变成 F1—F12

还有几个常见符号，也顺便认一认：⎋ 是 esc（逃出、取消），⌫ 是 delete（删除），↩ 是 return（回车），⇥ 是 tab（跳格），⇪ 是 caps lock（大写锁定）。

那朵“花”是从哪儿来的

1984 年，苹果做第一台 Macintosh 电脑的时候，命令键上本来画的是一个苹果标志。乔布斯不喜欢：菜单里到处都是苹果，太多了。

负责画图标的设计师苏珊·卡雷翻开一本符号词典，找到了这个四个圈连在一起的图形。在瑞典，它被画在路牌上，意思是“这里有值得一看的地方”。她把它放到了命令键上，一直用到今天。

参加过那台电脑开发的工程师安迪·赫茨菲尔德，后来把这件事写进了他的回忆文章。

shift 为什么叫“挪一挪”以后学 · 词源

shift 的意思是“挪动”。一百多年前的打字机，每根打字杆上刻着两个字母：下面是小写，上面是大写。按住 shift，整个字母架会往上挪一截，打出来的就变成了大写。电脑上没有字母架了，名字却留了下来。

“大写”英文叫 uppercase，“小写”叫 lowercase。case 是“盒子”：从前印刷工人排字，把大写字母的铅字放在上面那个盒子里，小写的放在下面那个盒子里。upper 是“上面的”，lower 是“下面的”。

快捷键怎么读、怎么按

快捷键表上写的 ⇧⌘4，读作“shift command 4”。按的方法只有一条规矩：

先按住修饰键，再点一下最后那个键，然后一起松开。

不要三个键一起拍下去，也不要先按 4。就像弹钢琴的和弦：左手先按住，右手再点。按住的时候，修饰键的顺序不要紧，⇧⌘4 和 ⌘⇧4 是一样的。

Mac 上的快捷键，大多数都长成“⌘ + 一个字母”，而且这个字母常常就是英文单词的头一个字母：

快捷键做什么那个字母来自
⌘C拷贝copy
⌘V粘贴V 就在 C 旁边，长得像一个往下插的箭头
⌘X剪切（拷贝以后把原来的删掉）X 像一把剪刀
⌘Z撤销：退回上一步Z 在键盘最左下，最好按
⇧⌘Z重做：撤销多了，再往前走一步
⌘A全选all
⌘S存储save
⌘F查找find
⌘N / ⌘T新建窗口 / 新建标签页new / tab
⌘W关掉这个窗口或网页window
⌘Q退出整个程序quit
⌘tab切换到别的程序
⌘空格聚焦搜索：找程序、找文件、算算术
⌘,打开这个程序的“设置”
⌥⌘esc强制退出：程序卡死了的时候用escape：逃出来
这些键在游戏里能帮你什么
  • 在游戏的聊天框里，⌘V 能把一条长命令粘贴进去，不用一个字母一个字母地打（先在网页或笔记里写好，再 ⌘C 拷贝）。
  • ⌘tab 能从游戏切到浏览器去查维基，查完再切回来。切出去以前，先按 esc 暂停，免得你不在的时候被怪打。
  • 千万别在游戏里按 ⌘Q。Q 在游戏里是“扔东西”，手一滑多按了 ⌘，整个游戏就退出了。要退出，按 esc，选“保存并退出到标题画面”。

MacBook Air 的键盘

这是一张 M1 MacBook Air 键盘的示意图（键的大小不完全准）。点任何一个键，看它的名字、英文和用处；上面三个按钮可以只看“Mac 里”或“游戏里”有用的键。点“用真键盘”，再按你电脑上的键，图上同一个键会跳一下。下面的格子是这一章的练习，按对了会自动打勾。

打开“用真键盘”以后，⌘A、⌘C、⌘V、⌘X、⌘Z、⌘S、⌘F 在这一页里会被拦下来，不会真的执行，可以放心按。⌘W、⌘Q、⌘tab、⌘空格拦不住（它们归 Mac 自己管），⌘W 会关掉这一页，别按。fn 键浏览器收不到。

三种截图

截图就是把屏幕上的样子“拍”一张照片存下来。Mac 不用装任何软件，自带三种：

  1. 拍整个屏幕：⇧⌘3。咔嚓一声，屏幕右下角会出现一张小图。
  2. 拍一块地方：⇧⌘4。鼠标变成一个十字，按住拖出一个框，松手就拍好了。拖到一半想反悔，按 esc。
  3. 拍一个窗口：先按 ⇧⌘4，再按一下空格，十字变成一台小相机。把相机移到哪个窗口上，那个窗口就变蓝，点一下就拍下来，连阴影都有。
  4. 截图工具：⇧⌘5。屏幕下面出来一排按钮，能选拍法，还能录屏（录一段视频）。录屏前先问大人，录下来的东西会很占地方。

拍好的图，默认放在桌面上，名字叫“截屏”加上日期和时间。在任何一种截图快捷键里多按一个 ⌃ control，图就不存成文件，而是放进“剪贴板”，可以直接 ⌘V 粘贴到别处。

注意：游戏里的截图是另一回事。在游戏里按 fn F2，图存在游戏自己的 screenshots 文件夹里，不在桌面上。第三十八章教你怎样找到它。

截一张，找到它★
  1. 用 ⇧⌘4 加空格，拍下这个浏览器窗口。
  2. 回到桌面（四根手指在触控板上张开，或者点程序坞里的访达，再点左边的“桌面”），找到那张“截屏……”。
  3. 选中它，按一下空格：这叫“快速查看”，不用打开任何程序就能看一眼。再按一下空格关掉。

聚焦搜索：一个会算术的搜索框

按 ⌘空格，屏幕中间会出来一个搜索框，叫聚焦搜索（英文 Spotlight，意思是舞台上的“聚光灯”）。它能干三件事：

  • 打开程序：打“终端”或者“zhongduan”，按回车，终端就开了。比在一堆图标里找快得多。
  • 找文件：打文件名里的几个字，比如“截屏”，你刚才拍的图就出来了。
  • 算算术：打 64*27，不用按回车，下面直接显示 1728。乘号用 *（shift 加 8），除号用 /。
电脑上的乘号和除号学过 · 二三年级

电脑键盘上没有 × 和 ÷，于是程序员用 * 当乘号、用 / 当除号。以后学 Python、写表格公式、用计算器程序，都是这样写的。

试试在聚焦搜索里算：一组方块是 64 个，一个箱子有 27 格，装满一箱是几个？64*27。大箱子是两个箱子拼起来的，64*27*2 呢？第六十一章会专门讲这些数。

程序卡死了怎么办

有时候一个程序不动了：点哪儿都没反应，鼠标变成一个转个不停的彩色小球。这时候：

  1. 先等一会儿。数到三十。很多时候它只是在忙，忙完就好了。游戏刚打开一个大世界时，常常要等。
  2. 还不行，就强制退出。按 ⌥⌘esc，出来一个小窗口，列着正在运行的程序。卡住的那个后面会写“未响应”。选中它，点“强制退出”。
  3. 知道代价。强制退出就像突然拔掉电源，没来得及存的东西会丢。游戏每隔几分钟会自动存一次，所以最多丢掉最后几分钟。
三个快捷键挑战★
  1. 用 ⌘空格 打开“计算器”程序，再用聚焦搜索算一算 64*36（你的物品栏一共 36 格，全装满是多少个？）。
  2. 同时开着浏览器和计算器，用 ⌘tab 在它们之间来回切换。按住 ⌘ 不放，连点 tab，可以在好几个程序里挑。
  3. 在“备忘录”里打一句话，⌘A 全选，⌘C 拷贝，到另一行 ⌘V 粘贴，再 ⌘Z 撤销一次。
出错了怎么办
按了快捷键，没反应
检查按的顺序：先按住修饰键，再点字母。还要看你“在”哪个程序里：快捷键是发给最前面那个窗口的，屏幕最左上角（苹果标志右边）写着的就是它的名字。
截图找不到
先看桌面。没有的话按 ⇧⌘5，点“选项”，看“存储位置”被改到了哪儿。游戏里 F2 截的图，看第三十八章。
按 ⌘空格 出来的是输入法，不是搜索框
有些电脑把这个键改给了输入法。请大人打开“系统设置”→“键盘”→“键盘快捷键”，看“聚焦”那一项现在是什么键。

键盘上画着 ⌘ 的那个键叫什么？

  1. option
  2. control
  3. command
  4. shift

⌘ 是 command（命令键），在空格键两边各一个。option 是 ⌥，control 是 ⌃，shift 是 ⇧。

“⇧⌘4”应该怎样按？

  1. 三个键同时拍下去
  2. 先按住 shift 和 command，再点一下 4，然后一起松开
  3. 先按 4，再按 shift，再按 command

修饰键先按住，最后那个键点一下。像弹和弦：左手按住，右手再点。

在游戏里，为什么要特别小心 ⌘Q？

  1. Q 是扔东西，多按一个 ⌘ 就会退出整个游戏
  2. 它会删掉存档
  3. 它会把游戏变成英文

⌘Q 是 quit，退出程序。正确的退出办法是 esc → “保存并退出到标题画面”。

在聚焦搜索里打 64*27，会算出多少？（填一个数）

64 × 27 = 1728，正好是一个装满的箱子：27 格，每格一组 64 个。

一个程序卡住不动了，你应该先做什么？

  1. 马上按电源键关机
  2. 马上按 ⌥⌘esc 强制退出
  3. 先等一会儿，还不行再强制退出

很多时候程序只是在忙。强制退出会丢掉没存的东西，所以先等等。关机是最后的办法，而且要问大人。

“大写字母”的英文是什么？（提示：upper 是“上面的”）

uppercase。从前排字工人把大写字母放在上面那个盒子（case）里。小写是 lowercase。

这一章的新词
修饰键 modifier自己不干活，和别的键一起按，改变那个键的意思。
快捷键 shortcut一组键，代替用鼠标点好几下菜单。shortcut 本来是“近路”。
剪贴板 clipboard⌘C 拷贝的东西临时放的地方，一次只放一样。
聚焦搜索 Spotlight⌘空格打开的搜索框，能开程序、找文件、算算术。
强制退出 force quit让卡死的程序立刻关掉，没存的东西会丢。
给大人

修饰键名称与符号见苹果官方《Mac 键盘快捷键》支持文档；M1 MacBook Air（2020）功能键行：F1/F2 亮度、F3 调度中心、F4 聚焦、F5 听写、F6 勿扰、F7—F9 媒体、F10—F12 音量，fn 键带地球仪图标。⌘ 符号的来历见安迪·赫茨菲尔德在 folklore.org 的文章（“Swedish Campground”）。截图快捷键与“在快捷键中加 control 存到剪贴板”见苹果支持文档《在 Mac 上截屏或录屏》。打字机 shift 与印刷“上下字盘”的词源是英语词源学的常见说法。

建议：和孩子一起把最常用的五六个快捷键写在便利贴上，贴在屏幕下沿，用一周以后撕掉。家长账号可以在“屏幕使用时间”里管住录屏和下载。

手指头带走一样⌘ command、⇧ shift、⌥ option、⌃ control、fn。先按住修饰键，再点最后一个键。游戏里小心 ⌘Q。
脑袋带走一样同一个按键，加上不同的“修饰”，意思就变了。很多本事都是这样：会的东西不多，能组合出很多用法。
