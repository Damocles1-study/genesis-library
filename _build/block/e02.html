几根手指，几种意思

MacBook 的触控板是一整块玻璃板，没有左右键。它靠数你用了几根手指、手指怎么动，来猜你想干什么：

手指动作意思英文
一根按下去（或者轻点一下）点：选中、打开按钮click / tap
一根快速点两下打开文件、文件夹double-click
一根按住不放，移动拖：搬文件、选一段字drag
两根一起点一下右键：打开一个小菜单right-click
两根上下或左右滑滚动页面scroll
两根分开或捏拢放大、缩小pinch（捏）
两根从触控板右边缘往左滑打开通知中心swipe
三根往上滑调度中心：所有窗口摊开来看
三根左右滑在全屏的程序之间换来换去
拇指和三根张开露出桌面；捏拢就回来

每台电脑的设置可能被改过，以“系统设置”→“触控板”里为准。那里每一项旁边都有一段小视频，鼠标放上去就会演给你看。顺便看看“轻点来点按”打开了没有：打开以后，轻轻一碰就算点，不用按下去。

在这里试

    接一个鼠标

    在游戏里，触控板很难用：一边要两根手指点着放方块，一边还要滑着转视角。接一个鼠标，游戏会好玩很多。

    M1 MacBook Air 的侧面只有两个小小的、椭圆形的口，叫 USB-C。普通的鼠标插头是扁长方形的（USB-A），插不进去。有两个办法：

    • 买一个“USB-C 转 USB-A”的转接头，把普通鼠标插在转接头上。
    • 用无线鼠标：有的带一个小小的接收器（也要插在转接头上），有的用蓝牙，什么都不用插。蓝牙鼠标要先“配对”：打开鼠标开关，在“系统设置”→“蓝牙”里找到它，点“连接”。

    接上鼠标以后，你可能会觉得滚轮“滚反了”：Mac 默认用的是“自然滚动”，内容跟着手指走，像推一张纸。用鼠标不习惯，可以在“系统设置”→“鼠标”里把“自然滚动”关掉。

    鼠标在游戏里
    • 左键：挖、打。按住不放就一直挖。
    • 右键：放方块、开门、吃东西、拉弓、和村民说话。触控板上就是两指一点。
    • 滚轮滚动：在快捷栏 1—9 格之间换手里的东西。
    • 按下滚轮（中键）：“选取方块”。创造模式里，对着一块方块按中键，手里就会多出一个同样的方块。

    中文还是英文

    你的 Mac 上一般有两种输入法：一种打中文，比如“简体拼音”；一种打英文，叫“ABC”。屏幕最上面一排（菜单栏）的右边，有一个小图标，写着“拼”或者“A”，告诉你现在用的是哪一种。切换的办法：

    • 按一下键盘左边的 中/英 键（它也是大写锁定键）：在拼音输入法里，在“打中文”和“打英文”之间换。
    • 按 ⌃空格：在不同的输入法之间换。按住 control，多点几下空格，可以挑。

    为什么要在意？因为中文输入法里打出来的标点，和英文的长得像，其实是另外一些字：

    名字英文（半角）中文（全角）命令里能不能用
    逗号,，只能用英文的
    冒号:：只能用英文的，比如 minecraft:stone
    引号"“ ”只能用英文的直引号
    括号[ ] { }【 】 ｛ ｝只能用英文的
    波浪号~～只能用英文的，第四十二章要用它
    空格窄空格宽空格（全角空格）只能用窄的

    “半角”“全角”说的是它们占的宽度：英文字符只占半个汉字那么宽，中文标点占一整个汉字那么宽。打命令、写代码、在终端里打字之前，先切到英文。聊天框里的字（比如 /say 你好 后面的“你好”）可以是中文。

    标点侦探

    在框里打一行命令，或者把你在游戏里出错的那一行粘贴进来。混进来的中文标点和宽空格会被标成红色。点“修好它”，会把它们换成英文的。下面还会列出每个字在电脑眼里的“号码”。

    电脑眼里，每个字都是一个数以后学 · 信息课 / 大学

    电脑里存的只有 0 和 1（第二部第十一章讲过）。那它怎样存字呢？办法是给世界上每个字编一个号。这张大号码表叫 Unicode（统一码）。

    英文逗号 , 是 44 号，中文逗号 ， 是 65292 号。窄空格是 32 号，宽空格是 12288 号。大写 A 是 65，小写 a 是 97，差 32；“中”字是 20013 号。

    所以在电脑看来，, 和 ， 就像 44 和 65292 一样，八竿子打不着。上面装置最下面那一行，就是你打的每个字的号码。

    在游戏里对比一次★
    1. 进你的实验世界（打开了“允许作弊”的那个）。
    2. 切到中文输入法，打 /time set day，看看会出什么事（拼音输入法会把字母当拼音，弹出一排候选字）。
    3. 按 中/英 切到英文，再打一遍，按回车。
    4. 再试一行 /say 我会切换输入法了：前面的命令用英文，后面的话可以换成中文。
    手指头的动词

    点一下听：click 点，tap 轻点，press 按，hold 按住，drag 拖，drop 放下，scroll 滚动，swipe 划，pinch 捏，type 打字。

    “拖放”就是 drag and drop。游戏的“控制”设置里你会看到 Attack、Use Item、Pick Block，分别是左键、右键、中键。

    出错了怎么办
    两指点了，可是没出右键菜单
    “系统设置”→“触控板”→“辅助点按”，看看是不是被改成了“点按右下角”。也可以按住 control 再点一下，效果一样。
    鼠标插上了不动
    转接头插紧了吗？无线鼠标的开关开了吗、电池有电吗？蓝牙鼠标要先配对。
    按 中/英 键变成了大写锁定
    短按是切换中英文，按久了才是大写锁定。键上的小绿灯亮着，就是大写锁定开着，再按一下关掉。
    命令里看不出哪里错
    把它粘贴到上面的“标点侦探”里查一查。

    在 MacBook 的触控板上，怎样“右键”？

    1. 一根手指点两下
    2. 两根手指一起点一下
    3. 三根手指往上滑

    两指一点就是右键。按住 control 再点一下也行。三指上滑是调度中心。

    下面哪一行命令能在游戏里正常运行？

    1. /time set day。
    2. /time　set day（中间是宽空格）
    3. /time set day

    第一行多了中文句号，第二行有全角空格。只有第三行全是英文字符。

    游戏里，鼠标的中键（按下滚轮）在创造模式里做什么？

    1. 选取方块：手里多一个看着的那种方块
    2. 跳
    3. 打开物品栏

    中键是 Pick Block，选取方块。

    在 Unicode 号码表里，小写 a 是 97，大写字母比小写字母小 32。那大写 A 是多少号？

    97 − 32 = 65。所有英文字母都是这样：小写比大写大 32。

    “拖”这个动作，英文是哪个词？（四个字母）

    drag。拖完松手是 drop，合起来 drag and drop，拖放。
