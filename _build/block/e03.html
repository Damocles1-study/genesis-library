键名里的英文，一半是你认识的

walk 走，jump 跳，open 打开，close 关上，drop 扔下，swap 交换，save 存，load 读出来，hide 藏起来，take 拿、拍。

有几个是新朋友：sneak 是“偷偷地走”，sprint 是“冲刺跑”，strafe 是“侧着走”，hotbar 是“热”加“条”：放着最常用东西的那一条，offhand 是“不常用的那只手”。

装置 · 第三十五章 · 一

游戏键位图

绿色的是游戏里有用的键。点一个键看它干什么。打开“用真键盘”，再把下面这几件事一件一件在你的键盘上按出来，按对了就打勾。

改键

觉得哪个键不顺手，可以换。比如有人喜欢用 R 跑步，或者把潜行改成“按一下就一直潜行”。

  1. 按 esc，点“选项”，再点“控制”，然后点“按键绑定”。
  2. 找到你想改的那一项，点它右边的按钮。按钮会变成“> ? <”的样子，意思是“等你按新键”。
  3. 按你想用的新键。完成。
  4. 如果新键已经被别的事占了，两边都会变成红色：一个键管两件事，游戏会糊涂。把其中一个改掉，红色就消失了。
  5. 改乱了也不怕：每一项后面有“重置”，页面最下面还有“全部重置”。

在“控制”那一页（不是按键绑定里面），还有“潜行”和“疾跑”的按住 / 切换：选“切换”，就是按一下开始、再按一下停，手指不用一直按着。

你改的这些，游戏都写在 options.txt 这个文件里，一行一个，比如 key_key.inventory:key.keyboard.e。第三十八章会去看看它。

Mac 上的 F 键

MacBook 最上面一排，默认是调亮度、调音量这些“特殊功能”。按住左下角的 fn，它们才变成 F1、F2、F3……所以在游戏里：

  • 截图是 fn + F2，调试屏幕是 fn + F3。
  • F3 组合键要先按住 fn 和 F3，再点那个字母：比如 F3 + G，就是按住 fn 和 F3，点一下 G。

觉得麻烦，可以请大人改一个设置：“系统设置”→“键盘”→“键盘快捷键……”→“功能键”，打开“将 F1、F2 等键用作标准功能键”。改了以后反过来：直接按就是 F 键，按住 fn 才是调亮度、调音量。

F3：游戏的仪表盘

按 fn + F3，屏幕上会盖满白色的小字。别被吓到，你只要先认识左边这几行：

那一行开头意思有什么用
XYZ:你站的精确位置，带小数第四十一章讲坐标
Block:你脚下那一格方块的坐标，都是整数告诉朋友你家在哪儿，用这个
Chunk:你在哪个区块里区块是 16 × 16 格的方柱
Facing:你脸朝哪个方向，比如 north (Towards negative Z)，后面还有两个角度north 是北；第四十二、六十四章讲方向和角度
Biome:你站的地方是什么群系，比如 minecraft:plains（平原）第五十六章有群系的英文
Light:这一格有多亮第六十八章讲光
最上面的 fps一秒钟画几张画面越大越流畅，第二十七章做过实验

新版本的 F3 屏幕可以自己挑显示哪几行，名字和位置也可能变动，以社区维基“调试屏幕”条目为准。基岩版和中国版没有这个屏幕，要看坐标，在设置里打开“显示坐标”。

F3 还能和别的键一起按（Mac 上都要先按住 fn）：

组合做什么
F3 + G显示区块的边界线：地上会出现一圈一圈的线
F3 + H物品的“高级提示”：鼠标停在物品上，能看到它的英文 ID，比如 minecraft:diamond_sword。学单词的好帮手
F3 + B显示生物的“碰撞箱”：每只动物身上套一个线框
F3 + D清空聊天框
F3 + T重新读取资源包
F3 + A重新加载区块（画面出毛病时试试）
F3 + P切出去时要不要自动暂停
F3 + F4游戏模式切换器（要有命令权限）：按住 F3，每点一次 F4 换一个模式
F3 + N在旁观模式和上一个模式之间切换（要有命令权限）
F3 + C把你现在的位置复制成一条命令。别按住十秒：那是故意让游戏崩溃的测试开关
F3 + Q在聊天框里列出所有这些组合
仪表盘四件事★★
  1. 按 fn + F3，把 Block: 后面的三个数写在纸上。往前走十步，再看一次，哪个数变了？
  2. 转身，直到 Facing: 后面写着 north。这就是游戏里的北。
  3. 按 F3 + G，找到一条区块边界线，站在线上。
  4. 按 F3 + H，打开物品栏，把鼠标停在三样东西上，抄下它们的英文 ID。
装置 · 第三十五章 · 二

按键反应

点“开始”，屏幕上会出现一件要做的事，你用最快的速度按出对应的键（按游戏的默认键位）。一共十轮，最后算你的平均反应时间。先把输入法切到英文。

准备好了吗？
平均数学过 · 四年级

上面的小游戏算的是平均数：把十次的时间加起来，再除以 10。平均数让你用一个数说清楚“一般来说有多快”。

你会发现，第一轮常常最慢（还没进入状态），偶尔有一轮特别慢（看错了）。那一次特别慢的，会把平均数拉高很多。第六十五章会讲另一种“一般来说”：把所有数排好队，取中间那个，叫中位数，它就不怕个别特别慢的。

基岩版和中国版

豆子在平板上玩的是基岩版：屏幕上有方向键和按钮，用手指点。基岩版也有电脑版（在 Windows 上），键位和 Java 版大致一样，但没有 F3 调试屏幕，很多细节不同。中国版的电脑版以网易的说明为准。这本书讲的键位，都是 Mac 上的 Java 版。

出错了怎么办
按 F3 变成了调亮度
要按住 fn。或者请大人改“将 F1、F2 等键用作标准功能键”。
按住 control 跑的时候，点左键变成了右键
有的 Mac 会把“control + 点”当成右键，这个问题有玩家遇到过。可以把疾跑改成别的键，或者在“控制”里把疾跑设成“切换”，或者连按两下 W 跑。
某个键突然不管用了
去“按键绑定”里看看那一项是不是变红了（和别的键冲突），或者被改掉了。

在 Mac 上打开调试屏幕，要按什么？

  1. F3
  2. fn + F3
  3. ⌘ + F3

MacBook 最上面一排默认是亮度、音量这些功能，按住 fn 才是 F3（除非大人改过设置）。

改键的时候，两个按键变成了红色，说明什么？

  1. 键盘坏了
  2. 这两个键不能改
  3. 两件事用了同一个键，冲突了

一个键管两件事，游戏会糊涂。改掉其中一个。

想看物品的英文 ID（比如 minecraft:diamond_sword），按哪个组合？

  1. F3 + H
  2. F3 + G
  3. F3 + B

H 是高级提示（advanced tooltips）。G 是区块边界，B 是碰撞箱。

shift 在游戏里是“潜行”，英文是哪个词？

sneak，偷偷地走。按住它走到方块边上不会掉下去。

五次反应时间分别是 320、280、300、260、340 毫秒，平均是多少毫秒？

320 + 280 + 300 + 260 + 340 = 1500，1500 ÷ 5 = 300。

这一章的新词
按键绑定 key binds哪个键管哪件事的一张表，可以自己改。
快捷栏 hotbar屏幕下面那九格，按 1—9 选。
调试屏幕 debug screenF3 打开的一屏小字。debug 是“找虫子”，就是找毛病。
冲突 conflict两件事抢一个键。
平均数 average总数除以个数，说清“一般有多大”。
给大人

默认键位依据 Minecraft 社区维基“控制”条目（Java 版），英文名称取自游戏英文界面，各版本可能有增减。F3 组合键依据维基“调试屏幕”条目；F3 + C 长按 10 秒触发调试崩溃是有意设计。2025 年起的版本对调试屏幕做了可自定义的改动，书中只举最常用的几行。macOS“将 F1、F2 等键用作标准功能键”的位置以所用 macOS 版本为准。“control + 点按被识别为右键”是一些 Mac 玩家报告过的现象，是否出现取决于系统和游戏版本，书中写作“有玩家遇到过”。

F3 + H 显示英文 ID 是学单词的好入口：可以和孩子约定每次玩游戏时抄三个新 ID，配合第七部的复习台。

手指头带走一样WASD 走，空格跳，shift 潜行，control 跑，E 物品栏，T 聊天，/ 命令。F 键要按住 fn。改坏了就“重置”。
脑袋带走一样工具的设置可以按自己的习惯改；改之前记住原来是什么样，改坏了知道怎样回去。
