树文件放在哪儿

电脑里有几十万个文件，可是它从来不会把它们堆成一堆。它们住在一棵倒着长的大树上：每个文件都在一个文件夹里，每个文件夹又在另一个文件夹里。认清这棵树，你就再也不会“找不到了”。

访达是什么

程序坞（屏幕最下面那一排图标）最左边，有一张蓝白两色的笑脸，那就是访达，英文 Finder，意思是“找东西的人”。它是 Mac 上管文件的程序，一直开着，关不掉。

点一下笑脸，会打开一个窗口。窗口左边一竖条叫边栏，列着常去的地方：

边栏上写的真名（英文）放什么
应用程序Applications装好的程序：浏览器、终端、我的世界启动器……
桌面Desktop屏幕背景上那些东西，截屏默认放这儿
文稿Documents你写的东西：作业、笔记、程序
下载Downloads从网上下载的东西
你的名字（比如 xiaoge）个人文件夹，也叫家，home上面这些（除了应用程序）都在它里面

四种看法

同一个文件夹，访达能用四种样子给你看。窗口上面有四个小按钮，也可以用快捷键：

  • ⌘1 图标：一个个大图标，像桌面。
  • ⌘2 列表：一行一个，能看大小和日期，点小三角能展开。
  • ⌘3 分栏：一栏一层，点一个文件夹，右边多出一栏显示它里面的东西。
  • ⌘4 画廊：大图预览，看照片用。

找东西的时候，最好用分栏。因为分栏把“这个文件在哪个文件夹里、那个文件夹又在哪个文件夹里”一栏一栏摆在你眼前。

图

一棵倒着长的树

最上面那个叫根（整个硬盘）。往下长出树枝（文件夹），树枝上再长树枝，最末端是叶子（文件）。每片叶子只长在一根树枝上：每个文件只在一个文件夹里。

树：程序员最爱的一种形状以后学 · 大学数据结构

这种“一个分成好几个、每个再分成好几个”的形状，程序员叫它树（tree）。最上面的叫根（root），每个分叉点叫节点（node），没有再分叉的叫叶子（leaf）。一个节点上面那一个叫它的“父亲”（parent），下面那些叫它的“孩子”（children）。

游戏里的进度（按 L 打开的那张图）、家谱、学校的年级和班级，也都是树。第七十七章会专门讲它。

一个好习惯：名字用英文、拼音、数字和下划线，不用空格。比如 mc_notes 比“我的世界 笔记 (1)”好。第三十七章和第三十九章会告诉你为什么：路径和终端里，空格和中文常常添麻烦。

文件名后面那个“点什么”

每个文件的全名，后面常常跟着一个点和几个字母，叫后缀名或者扩展名（extension）。它告诉电脑：“我是什么文件，该用哪个程序打开”。Mac 平时把它藏起来，我们要让它露出来：

  1. 点一下访达窗口，让屏幕左上角写着“访达”。
  2. 点菜单“访达”→“设置”（或者按 ⌘,），点上面的“高级”。
  3. 勾上“显示所有文件扩展名”。
  4. 再点菜单“显示”→“显示路径栏”（⌥⌘P），窗口最下面会多出一行路径。
后缀是什么在哪儿见过
.png .jpg图片截屏、游戏截图

.pyPython 程序（其实也是纯文本）第二十六章、第十部

给自己建一根树枝★★
  1. 在真电脑上打开访达，按 ⌘3 换成分栏。打开“显示所有文件扩展名”和“显示路径栏”。
  2. 进“文稿”，新建文件夹 mc。在它里面再建三个：screenshots、notes、code。
  3. 把桌面上的截屏（第三十三章拍的）拖进 screenshots。
  4. 在纸上画出这一小棵树：从 xiaoge（你的名字）开始，画到你刚建的三个文件夹。
文件的单词

file 文件，folder 文件夹（本来是夹纸的硬纸夹），new folder 新建文件夹，rename 改名（re- 是“再一次”，name 是名字），move 移动，copy 拷贝，trash 废纸篓，empty trash 清倒废纸篓，Get Info 显示简介。

边栏上的几个，Pictures 图片、Music 音乐、Movies 影片，都是复数：一个文件夹里放的是很多张、很多首、很多部，所以后面加了 s。

出错了怎么办
不小心拖错了地方
马上按 ⌘Z 撤销，访达里也能撤销。
东西不见了
按 ⌘空格，打它名字里的几个字搜一搜。搜到以后按住 ⌘ 看搜索结果最下面，能看到它在哪个文件夹里。
删错了
打开废纸篓，右键“放回原处”。如果已经清倒了，去问大人：有“时间机器”备份的话，还能找回来。

想一层一层地找文件，访达用哪种看法最方便？

  1. 图标 ⌘1
  2. 画廊 ⌘4
  3. 分栏 ⌘3

分栏一栏一层，正好把树的一条枝摊开给你看。

访达边栏上写的“文稿”，它的真名（英文名）是？

  1. Documents
  2. Desktop
  3. Downloads

文稿 Documents，桌面 Desktop，下载 Downloads。终端和路径里用的都是英文真名。

拖文件时按住哪个键，会拷贝一份，而不是搬过去？

  1. ⌘ command
  2. ⌥ option
  3. ⇧ shift

按住 option 拖，鼠标旁边会出现绿色加号，表示拷贝。

Python 程序文件的后缀名是什么？

.py，比如“小海龟.py”。它其实就是纯文本，只是后缀告诉电脑“这是 Python 程序”。

在一棵“树”里，没有再分叉、在最末端的那些叫什么？

  1. 根
  2. 叶子
  3. 父亲

最末端的叫叶子（leaf），在电脑里就是文件。最上面的叫根。
