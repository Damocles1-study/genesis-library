路径就是地址

第三十六章说，文件夹是一棵树。要说清楚一片叶子在哪儿，就从根开始，把一路经过的树枝一个一个念出来，中间用斜杠 / 隔开。这一串，叫路径（path，本来是“小路”）。

/Users/xiaoge/Documents/编程课/小海龟.py

从左往右读：

  1. 最前面的 /：根，整个硬盘。
  2. Users：根里面的“用户”文件夹，这台电脑上每个人都在里面有一个家。
  3. xiaoge：小格的家（个人文件夹）。
  4. Documents：家里的“文稿”。
  5. 编程课：文稿里的一个文件夹。
  6. 小海龟.py：最后这个是文件，叶子。

和地址一模一样：从大到小，一层一层。斜杠就是“里面的”。

访达说中文，路径说英文

访达边栏上写“文稿”，可路径里写的是 Documents。这是因为 Mac 为了让大家看得懂，给几个系统文件夹起了中文的“外号”，真名一直是英文。终端里、路径里、程序里，用的都是真名。

常见的几对：用户 Users、桌面 Desktop、文稿 Documents、下载 Downloads、应用程序 Applications、资源库 Library。你自己建的文件夹，起什么名字就叫什么名字，没有外号。

波浪号 ~：回家

每次都写 /Users/xiaoge 太长了。于是有一个简写：~ 就代表“我的家”（个人文件夹）。

  • ~ = /Users/xiaoge
  • ~/Desktop = /Users/xiaoge/Desktop
  • ~/Library/Application Support/minecraft = /Users/xiaoge/Library/Application Support/minecraft

好处是：这串路径在谁的电脑上都能用。豆子的名字是 doudou，~ 在他电脑上就是 /Users/doudou。所以网上的教程写存档位置，都写 ~/Library/…。

波浪号在键盘左上角，esc 下面那个键，要按住 shift。记得先切到英文：中文输入法打出来的是 ～，不管用。（第四十二章，~ 在命令里还会出现，意思是“从我现在站的地方算”，和这里的“家”很像：都是“以我为起点”。）

装置 · 第三十七章 · 一

读路径

在框里打一个路径（或者点下面的例子），装置会把它拆成一级一级，告诉你每一级是什么、在小格的电脑上找不找得到。

藏起来的资源库

你的家里有一个文件夹叫 Library（资源库），访达平时不让你看见。里面放的是各个程序自己的设置和数据，比如我的世界的存档。乱删里面的东西，程序可能就打不开了，所以苹果把它藏了起来。要去那里，有三个办法：

  1. 前往文件夹（最推荐）：在访达里按 ⇧⌘G，弹出一个框，打 ~/Library/Application Support/minecraft，按回车，一下子就到了。打到一半可以按 tab，它会帮你补全名字。
  2. 按住 option 看菜单：点屏幕上面的菜单“前往”，按住 ⌥ option，菜单里会多出一项“资源库”。（第三十三章说过：option 会变出隐藏的选项。）
  3. 显示隐藏文件：在访达里按 ⇧⌘.（句号），所有藏起来的文件夹和文件都会半透明地出现，再按一次又藏起来。名字以点开头的文件（比如 .zshrc）也是这样藏起来的。
装置 · 第三十七章 · 二

前往文件夹

还是那个模拟访达。这次从桌面开始。在上面的“前往文件夹”框里打路径，或者点“⇧⌘. 隐藏文件”让藏起来的东西露出来；点“显示真名”可以在中文名和英文真名之间切换。

拷贝一个文件的路径

求助的时候、写程序的时候，常常要把一个文件的完整路径告诉别人。不用自己一个字一个字地打：

  1. 在访达里选中那个文件，右键（两指点）。
  2. 按住 ⌥ option，菜单里的“拷贝”会变成“将……拷贝为路径名称”，点它。快捷键是 ⌥⌘C。
  3. 到别的地方 ⌘V 粘贴，出来的就是完整路径。

还有一个办法：把文件直接拖进终端窗口，终端里就会出现它的路径（第三十九章会用到）。

绝对路径和相对路径

问路的时候有两种说法：

  • “人民路 18 号”：不管你在哪儿，这个地址都一样。这叫绝对路径，以 / 或 ~ 开头，从根（或家）出发。
  • “从这儿往前走，第二个路口左转”：要看你现在站在哪儿。这叫相对路径，从“我现在在的文件夹”出发。

相对路径里有两个特别的记号：.（一个点）是“这里”，..（两个点）是“上一层”。比如你现在在 ~/Documents，那 编程课/小海龟.py 就是相对路径，../Desktop 是“退回到家，再进桌面”。

绝对和相对，坐标里也有以后学 · 七年级 数轴

路径的这两种说法，和游戏里坐标的两种写法一模一样：/tp 100 64 -20 是绝对坐标，不管你在哪儿都传到同一个地方；/tp ~ ~5 ~ 是相对坐标，“从我现在的位置往上 5 格”。第四十二章细讲。数学里，从 0 点量起的叫“位置”，从某一点量起的叫“距离”或“变化”，也是同一个想法。

在真电脑上找到存档★★
  1. 打开访达，按 ⇧⌘G，打 ~/Library/Application Support/minecraft/saves，回车。
  2. 你看到的每一个文件夹，就是一个世界。找一找你最喜欢的那个。
  3. 把这个文件夹拖到访达边栏的“个人收藏”里，以后一点就到。
  4. 选中一个世界文件夹，用 ⌥⌘C 拷贝它的路径，粘贴到“备忘录”里看看。

只看，先别动里面的东西。下一章教你怎样安全地备份。

出错了怎么办
前往文件夹说“找不到”
一个字母一个字母检查：大小写一般不要紧，但空格、斜杠、拼写要对。Application Support 中间有一个空格。最稳的办法是打几个字母就按 tab，让它补全。
波浪号打出来是 ～
你在中文输入法里。按 中/英 键切到英文再打。
没有 minecraft 文件夹
说明这台电脑还没有运行过 Java 版，或者游戏目录被改到了别处。在启动器的“安装”里可以看到游戏目录在哪儿。

在小格的电脑上，~/Desktop 和下面哪个是同一个地方？

  1. /Desktop
  2. /Users/xiaoge/Desktop
  3. ~/Users/Desktop

~ 代表家，也就是 /Users/xiaoge。所以 ~/Desktop = /Users/xiaoge/Desktop。

在访达里，哪个快捷键能打开“前往文件夹”？

  1. ⇧⌘G
  2. ⇧⌘.
  3. ⌘G

⇧⌘G 前往文件夹（Go）。⇧⌘. 是显示隐藏文件。

你现在在 ~/Documents/编程课 里，.. 指的是哪个文件夹？

  1. ~/Documents/编程课
  2. ~
  3. ~/Documents

两个点是“上一层”。编程课的上一层是 Documents。

存档在 ~/____/Application Support/minecraft/saves，横线上那个被藏起来的文件夹叫什么？（英文）

Library，资源库。访达平时把它藏起来，用 ⇧⌘G 或者按住 option 看“前往”菜单就能进去。

/tp ~ ~5 ~ 里的 ~，最像路径里的哪种写法？

  1. 绝对路径：从根开始
  2. 相对路径：从“我现在在的地方”开始

命令里的 ~ 是“从我现在的位置算”，是相对的。路径里的 ~ 是“家”，路径从家开始，算绝对路径的一种简写。两个 ~ 的共同点：都以“我”为起点。
