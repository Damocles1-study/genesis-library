minecraft 文件夹的地图

上一章找到的 ~/Library/Application Support/minecraft，就是 Java 版的游戏目录。里面最重要的几样：

名字是什么英文意思
saves/所有的世界。一个世界一个文件夹saves：存下来的东西
screenshots/游戏里按 fn + F2 截的图screenshots：屏幕的照片
backups/游戏里“制作备份”做出来的压缩包backups：备份
resourcepacks/资源包：换方块的样子、换声音resource packs
logs/latest.log日志：游戏一边运行一边写的“日记”，出错时很有用log：航海日志
crash-reports/游戏崩溃（突然退出）时写的报告crash report
options.txt你在“选项”里调的所有设置，包括按键options：选项
versions/下载过的游戏版本versions

打开 saves 里的一个世界，又能看到：

名字是什么
level.dat这个世界的“总设置”：名字、种子、游戏规则、现在几点
region/主世界的地形和方块，切成很多个 r.x.z.mca 文件
playerdata/每个玩家站在哪儿、背包里有什么
datapacks/这个世界的数据包（第二十五章）
advancements/ stats/进度和统计
icon.png选择世界时那张小图
DIM-1/ DIM1/下界和末地（新版本里这些文件夹的安排可能变，以维基为准）
DIM 是什么

DIM 是 dimension 的头三个字母，意思是“维度”，游戏里指下界、末地这样的“另一个世界”。DIM-1 是下界（−1），DIM1 是末地（1），主世界是 0。用数字给世界编号，一个往“下”、一个往“上”，正好用上了负数。

不用找路，游戏帮你打开

其实很多时候，根本不用记路径，游戏里就有按钮：

  • 世界文件夹：“单人游戏”→ 选中一个世界 →“编辑”→“打开世界文件夹”。
  • 截图：按 fn + F2 截图后，聊天框里会出现一行“已将截图保存为……”，点那个文件名就能打开。
  • 资源包文件夹：“选项”→“资源包”→“打开包文件夹”。
  • 备份文件夹：“编辑”世界的那一页里，有“打开备份文件夹”。

按钮的名字和位置可能随版本变一点，找找就有。

游戏文件夹寻宝

模拟访达已经打开在 minecraft 文件夹里。按下面的单子一样一样找。点到文本文件（.txt、.log、.mcfunction、.mcmeta），右边能看到里面写着什么。

options.txt：所有设置写在一张纸上

用“文本编辑”打开 options.txt（要先关掉游戏），你会看到几百行这样的字：

renderDistance:8
maxFps:60
lang:zh_cn
key_key.inventory:key.keyboard.e

冒号左边是设置的名字，右边是它的值。renderDistance 是视野距离，lang:zh_cn 是语言“简体中文”。这种“名字:值”的写法，程序员叫键值对，第七十七章的“字典”就是它。

可以看，先别改。改错了游戏可能读不懂。在游戏的“选项”里调，效果一样，还不会出错。

三种备份

备份就是把重要的东西多存一份，放在别的地方。做法从简单到稳妥：

  1. 游戏里一键备份：“单人游戏”→ 选中世界 →“编辑”→“制作备份”。游戏会把整个世界打成一个 .zip 压缩包，放进 backups 文件夹。最省事，可是它和游戏放在同一台电脑上，电脑坏了就一起没了。
  2. 复制一份文件夹：先退出这个世界（回到标题画面），打开 saves，选中世界文件夹，按住 option 拖到“文稿”里的 mc 文件夹，或者右键 →“压缩”，做成一个 zip 再放过去。名字后面加上日期，比如 我的第一个家_2027-01-20.zip。
  3. 放到电脑外面：把上一步的 zip 拷到 U 盘或者移动硬盘上。这台 MacBook 只有 USB-C 口，U 盘也许要转接头。大人如果开了“时间机器”，电脑会自己定时备份到外接硬盘。

换回来：退出游戏，把坏掉的那个世界文件夹拖进废纸篓（或者改名留着），把备份的 zip 双击解压，把解压出来的文件夹放回 saves。重新打开游戏，世界就回到备份那一刻了。

为什么要先退出世界再复制

世界开着的时候，游戏随时在往文件里写东西。你复制到一半，它正好写了一半，复制出来的就可能是“半截”的，打不开。就像别人还在写作业，你就把作业本拿去复印。先关，再拷。这个道理以后备份任何东西都适用。

给老世界存一份后悔药★★
  1. 用游戏里的“制作备份”给你最重要的世界做一个备份，再点“打开备份文件夹”看看它。
  2. 用第二种办法再做一份，放进 ~/Documents/mc，名字加上今天的日期。
  3. 在游戏里按 fn + F2 截一张图，点聊天框里的文件名打开它。
  4. （大人在的时候）把 zip 拷到 U 盘上。

一块地存在哪个文件里

region 文件夹里的文件名字很怪：r.0.0.mca、r.-1.0.mca……其实这是在说“这一大片地在哪儿”。规则是这样的：

  • 世界切成 16 × 16 格的区块。
  • 32 × 32 个区块，组成一个区域，存成一个 .mca 文件。一个区域是 16 × 32 = 512 格见方。
  • 文件名里的两个数，是区域在 x 方向和 z 方向的编号。r.0.0 管 x 从 0 到 511、z 从 0 到 511 的那一大片；r.-1.0 管 x 从 −512 到 −1。

算法是：坐标除以 512，再“往小的方向”取整。x = 700，700 ÷ 512 ≈ 1.37，往小取是 1。x = −20，−20 ÷ 512 ≈ −0.04，往小取是 −1（不是 0！）。

“往小的方向取整”以后学 · 七年级 负数 / 高中 取整函数

正数除完去掉小数，大家都会：1.37 变成 1。负数要小心：−0.04 在数轴上夹在 −1 和 0 之间，“往小的方向”是往左，所以是 −1。数学里把它写成 ⌊−0.04⌋ = −1，叫“向下取整”，英文 floor（地板）：不管你飘在哪儿，都掉到下面那块地板上。编程语言里都有这个功能，Python 里叫 math.floor。

为什么不能直接去掉小数？因为那样的话，x = −20 和 x = 20 会算进同一个文件 r.0.…，可它们明明一个在 0 的左边，一个在右边。

出错了怎么办
备份的世界打开后是空的，或者打不开
可能是世界开着的时候复制的。再用游戏里的“制作备份”做一次。
放回 saves 后，世界列表里没有它
解压以后可能多了一层文件夹：saves/我的世界/我的世界/level.dat。要让 level.dat 正好在 saves 下面第一层的那个文件夹里。
游戏崩溃了
去 crash-reports 里找最新的那个报告，第四十章教你怎样拿着它去求助。

游戏里按 fn + F2 截的图在哪个文件夹里？

  1. 桌面
  2. minecraft/screenshots
  3. minecraft/saves

游戏自己的截图放在 screenshots。⇧⌘3 这种系统截图才放在桌面。

复制世界文件夹做备份之前，最重要的一步是什么？

  1. 把电脑音量关掉
  2. 把世界改成英文名字
  3. 先退出这个世界

世界开着时游戏一直在写文件，复制到一半可能是坏的。先关，再拷。

x = 600，它在 region 文件名的 x 编号是多少？（600 ÷ 512，往小取整）

600 ÷ 512 ≈ 1.17，往小取整是 1，所以在 r.1.?.mca 里。

x = −5，region 文件名的 x 编号是多少？

−5 ÷ 512 ≈ −0.01，在数轴上 −1 和 0 之间，往小的方向取是 −1。

options.txt 里的 lang:zh_cn 这种“名字:值”的写法，叫什么？

  1. 键值对
  2. 快捷键
  3. 后缀名

冒号左边是“键”（名字），右边是“值”。第七十七章的字典就是一大堆键值对。
