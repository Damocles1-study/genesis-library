终端是什么

在电脑还没有窗口、没有鼠标的年代（第二部讲过），人们用电脑就是打一行字、按回车、看它回一行字。今天的 Mac 把这种方式留了下来，装在一个程序里，叫终端（Terminal）。按 ⌘空格，打“终端”，回车，就打开了。

打开以后，你会看到一行字，最后面有一个闪烁的小方块：

xiaoge@MacBook-Air ~ %

这一行叫提示符（prompt），意思是“我准备好了，请说”。它告诉你三件事：

  • xiaoge：现在是谁在用。
  • MacBook-Air：这台电脑的名字。
  • ~：你现在站在哪个文件夹里。~ 是家（第三十七章）。走到别处，这里会变。

最后的 % 只是一个记号，表示“该你了”。你打的字跟在它后面。

六个命令

终端里的命令和游戏里的命令很像：先写做什么（命令），再写对谁做（参数），中间用空格隔开。这六个命令都只是“看”和“走”，很安全：

命令做什么名字从哪儿来例子
pwd我现在在哪个文件夹？print working directory：打出工作文件夹pwd
ls这里有什么？list：列出来ls、ls Desktop
cd走到另一个文件夹change directory：换文件夹cd Documents、cd ..、cd ~
open用访达或者默认程序打开它open：打开open .（在访达里打开“这里”）
cat把一个文本文件的内容打出来看concatenate：连起来（不是猫）cat options.txt
clear把屏幕擦干净clear：清除clear

还有几个小窍门，会让你像高手一样快：

  • tab 补全：打名字的头几个字母，按 tab，终端会帮你补完。补不出来，说明有好几个名字开头一样，或者根本没有这个名字。多按 tab，少打错。
  • ↑ 上一条：按向上的箭头，刚才打过的命令又出来了，改一改再用。
  • ⌃C 停下：一个命令跑个不停（比如服务器），按 control + C 让它停。注意是 control，不是 command。
  • ls -a：后面加 -a（all），连藏起来的、以点开头的文件也列出来。这种以减号开头的叫选项。

一个模拟的终端

这是一个假的终端，里面装着第三十六章那台“小格的电脑”。点一下黑框，开始打字，按回车执行。照着下面的单子一件一件做。打 help 能看到它认识哪些命令。

提示：路径里有空格的文件夹（Application Support），要写成 Application\ Support（反斜杠加空格），或者用引号包起来 "Application Support"。最省事的办法：打 Appl 然后按 tab。

名字里的空格

终端用空格来分开命令和参数。所以 cd Application Support 在它看来是“走到 Application，然后还有一个多余的 Support”，就出错了。两个办法告诉它“这个空格是名字的一部分”：

  • 在空格前面加一个反斜杠 \：cd Application\ Support。反斜杠在 return 上面那个键。
  • 用英文引号把整个名字包起来：cd "Application Support"。

这就是第三十六章说“文件名别用空格”的原因。中文名字在终端里能用，可是打起来要切输入法，也容易混进中文标点，所以自己起名字，尽量用英文、拼音和下划线。

命令 + 参数 = 函数调用以后学 · 编程

你已经见过三种长得很像的东西：

  • 游戏里：/give @p diamond 3
  • 终端里：cd Documents
  • Python 里：print("你好")

它们都是“做什么 + 对谁、怎么做”。前面那个叫命令或函数，后面那些叫参数（argument）。第七十五章会讲：你还可以自己发明新的命令，这就是写函数。

这几样，没有大人在旁边别碰
  • rm：删除。它不进废纸篓，删了就没了。打错一个路径，可能删掉一整个文件夹。
  • sudo：用管理员的权限做事。它会要密码，有了密码，电脑什么都听，包括把系统弄坏。
  • 网上、视频里、陌生人发给你的命令：哪怕说是“加速”“免费皮肤”“修复”，也不要复制粘贴进终端。有些看起来很短的命令，会下载并运行坏程序。第三十一章说过，AI 给的命令也要大人先看。

规矩很简单：看不懂的命令不运行。

在真终端里走一圈★★

请大人坐在旁边。按 ⌘空格，打“终端”，回车。然后一行一行打（每行打完按回车）：

  1. pwd　看看你在哪儿。
  2. ls　看看家里有什么。和访达里的对一对。
  3. cd Desktop　走进桌面，再 ls。
  4. open .　访达会打开桌面这个文件夹。
  5. cd ~/Library/Appl 然后按 tab，再打 min 按 tab，回车。你进了游戏目录。
  6. ls saves　列出你所有的世界。
  7. cd ~　回家。然后输入 exit 或者按 ⌘Q 关掉终端。
终端里的英文

报错的时候，终端说的是英文，其实就那么几句：

  • command not found：没有这个命令（多半拼错了）。found 是 find 的过去式：没找到。
  • No such file or directory：没有这个文件或文件夹。such：这样的。
  • Permission denied：权限不够，不让你做。permission 许可，denied 被拒绝。
  • Is a directory / Not a directory：这是一个文件夹 / 这不是文件夹。
出错了怎么办
command not found
命令拼错了，或者大小写错了（终端里的命令一般全是小写）。也可能你在中文输入法里。
No such file or directory
先 pwd 看看自己在哪儿，再 ls 看看这里有什么。名字里有空格吗？用 tab 补全最保险。
终端一直在跑，不出提示符
按 control + C。
打错了一长串还没按回车
按 control + C 整行作废，或者 control + U 删掉整行。

想知道自己现在在哪个文件夹，打哪个命令？

pwd，print working directory。

提示符 xiaoge@MacBook-Air Desktop % 说明你现在在哪儿？

  1. 家里
  2. 桌面文件夹里
  3. 游戏里

% 前面那个词就是你现在站的文件夹：Desktop，桌面。

下面哪一行能走进 Application Support 文件夹？

  1. cd Application Support
  2. cd Application,Support
  3. cd Application\ Support

空格是分隔符。要么在空格前加反斜杠，要么用引号把名字包起来。

终端里一个程序停不下来，按什么？

  1. control + C
  2. command + C
  3. esc

终端里是 control + C（中断）。command + C 是拷贝。

视频里有人说“把这行命令粘贴进终端，就能免费拿到皮肤”。你该怎么办？

  1. 试一下，反正不会怎样

看不懂的命令不运行，尤其是陌生人给的。这正是坏人常用的骗法。

想把藏起来的文件也列出来，打什么？（命令加选项）

ls -a。-a 是 all，全部。

给大人

macOS 自 Catalina（10.15）起默认 shell 为 zsh，默认提示符形如 用户名@电脑名 当前目录 %。书中命令 pwd、ls、ls -a、cd、open、cat、clear、exit 均为 macOS 自带的标准命令；control + C 中断、control + U 删除整行是 zsh 的默认行为。网页上的终端是模拟的，不会接触真实文件，不支持 rm、sudo。

建议：第一次打开真终端时陪在旁边。可以和孩子约定“三不”：不打 rm，不打 sudo，不粘贴看不懂的命令。终端用熟了，第二十九章开服务器、第十部写 Python 都会顺很多。
