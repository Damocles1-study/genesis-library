卡住的五步

会用电脑的人，不是从来不卡住，而是卡住了知道下一步干什么。程序员每天都会卡住好几次。他们的办法，归结起来就是五个字：

  1. 读：停下来，把屏幕上的字读完。报错的字虽然常常是英文，但它往往已经告诉你哪里错了：“找不到”“拼错了”“权限不够”。读不懂的单词，抄下来。
  2. 试：自己先试三样最简单的。① 回想“我最后改了什么”，把它改回去；② 关掉重开；③ 换一个最小的例子试试（比如命令出错，先试一条最短的同类命令）。
  3. 查：去社区维基或者搜索引擎查。把报错里最关键的几个英文词，加上“minecraft”和你的版本号一起搜。
  4. 问：问大人、问同学、在大人陪着时问 AI。问之前先把问题写清楚（下面的问题卡）。
  5. 记：解决了，花一分钟记下来：出了什么事、原因是什么、怎么解决的。下次再碰到，一看就懂。第八十一章会教你做一本“错题本”。

先弄清“我用的是什么”

同一个问题，在不同的电脑、不同的版本上，答案可能不一样。所以求助之前，先查清楚这三样：

  • 电脑型号和芯片：点屏幕最左上角的苹果标志 →“关于本机”。会写着“MacBook Air”“芯片 Apple M1”“内存 8 GB”。
  • macOS 版本：同一个窗口里，写着“macOS”后面跟一个名字和数字。
  • 游戏版本：游戏标题画面的左下角，写着“Minecraft 1.21.……”这样的字；启动器的“安装”里也能看到。

把问题说清楚

“游戏坏了”“命令不管用”，谁也帮不了。一个说得清楚的问题，要回答这几样：

要说清的不清楚的说法清楚的说法
我想做什么我想弄个东西我想用 /fill 在我家下面挖一个 50×50 的大地下室
我做了哪几步我打了命令我站在家门口，按 / 打了 /fill ~ ~-1 ~ ~50 ~-20 ~50 air
我以为会怎样（没说）脚下挖出一个大坑
实际怎样了不行聊天框里出现红字：“……too many blocks……”
我已经试过（没说）我把 50 改成 20，就成功了
我用的是（没说）M1 MacBook Air，Java 版 1.21.x

有意思的是：很多时候，你把问题一条一条写清楚，写到一半就自己想明白了。程序员管这叫“小黄鸭调试法”：对着桌上的一只玩具鸭子，一句一句把问题讲给它听，讲着讲着，答案就冒出来了。

在维基上查

    
我的世界有一个大家一起写的“百科全书”，叫社区维基（第一部第八章讲过它的来历）。它有中文版和英文版，英文版内容最全、更新最快。搜的时候：

    
    
      
  • 用游戏里的名字搜：方块、物品、命令的名字。命令可以直接搜“fill 命令”或者 “fill command”。
    • 
      
  • 报错原文照抄：把聊天框或日志里那句英文报错，挑最关键的几个词去搜。
    • 
      
  • 看版本：维基上很多地方会写“Java 版”“基岩版”，还会写“从 1.13 开始”。Mac 上看 Java 版的那部分。
    • 
      
  • 小心山寨网站：搜索结果里有很多模仿维基、到处是广告和“下载”按钮的网站。不点任何“下载”，看不准就问大人。
    • 
    

  


  

    
搜英文，用这几个词

    
how to 怎样，not working 不管用，error 错误，crash 崩溃，fix 修好，command 命令，Java Edition Java 版。

    
比如：minecraft java fill command too many blocks。搜索不用写完整的句子，几个关键词就够了。

  


  

    
Mac 教程少？这反而是一个机会

    
用 Mac 玩我的世界的人，比用 Windows 的少，所以网上很多教程讲的是 Windows：按的是 ctrl 不是 ⌘，路径写的是 %appdata% 不是 ~/Library。照着做，常常对不上。

    
以前，碰到这种事只能干着急。现在有了会聊天的 AI，事情变了：你可以把自己的情况告诉它，让它“翻译”成 Mac 上的做法。用得好，AI 就像一个随时能问的舅舅。用法有几条规矩（第三十一章讲过为什么）：

  

  

    
    
      
  1. 在大人的账号下、大人在旁边时用。很多 AI 服务规定了使用年龄，以它们的条款为准。
    2. 
      
  2. 先说清楚你的情况：用上面的问题卡。一定要写“我用的是 M1 MacBook Air 和 Java 版”，不然它可能给你 Windows 的办法。
    3. 
      
  3. 让它讲道理，不只是给答案：多问一句“为什么这样做？”“这一步是什么意思？”。弄懂了，下次你就不用问了。
    4. 
      
  4. 自己验证：AI 会自信地说错。它说的按钮名字、命令写法，先在实验世界里试；它给的终端命令，请大人看过再运行。
    5. 
      
  5. 别把个人信息告诉它：真名、学校、住址、密码，都不写进去。
    6. 
    

    
你会发现，学会了“怎样问”，Mac 冷门就不再是缺点。因为全世界的教程，经过一次“翻译”，都能变成你的。

  


  

    
好问题的样子

    
一个好问题，别人不用再问你一句就能回答。上面的问题卡就是在帮你做到这一点。你还可以在问题后面加一句“请先解释原理，再告诉我步骤”，或者“请用四年级学生能看懂的话”。

    
这个本事不只用在电脑上：问老师一道题，先说“我是这样想的，卡在了这一步”，老师一下子就知道该从哪儿讲起。

    2. 
        
  2. 打开游戏，记下标题画面左下角的版本号。

    4. 
        
  4. 回想一次你以前卡住的事，用上面的问题卡生成器写一张问题卡。

小格的闪退后来怎样了

    

      
读
闪退时弹出的窗口里有一句 “The game crashed”，还说报告存在 crash-reports 里。

最后做的事是装资源包。把那个资源包从 resourcepacks 文件夹里拖出来，游戏能打开了。

资源包的说明里写着“适用于 1.20”，小格的游戏是更新的版本。

卡住的五步，正确的顺序是？
  1. 问、查、试、读、记
  2. 试、问、记、读、查
  3. 读、试、查、问、记
先读屏幕上的字，再自己试，再查，再问，解决了记下来。

    
想知道自己的 Mac 是什么芯片、多大内存，去哪儿看？
  1. 苹果菜单 →“关于本机”
  2. 游戏标题画面左下角
  3. 访达的废纸篓
“关于本机”里写着型号、芯片、内存和 macOS 版本。游戏版本才在标题画面左下角。

    
下面哪个问题说得最清楚？
  1. 命令不管用，怎么办？
  2. 我在 M1 MacBook Air 上的 Java 版 1.21 里打 /fill 挖地下室，出现红字 too many blocks，改小以后就成功了，为什么？
  3. 游戏坏了！
第二个说清了电脑、版本、做了什么、看到什么、试过什么。

    
AI 告诉你一条终端命令，说能让游戏更流畅。你应该？
  1. 马上运行
  2. 改几个字再运行
  3. 请大人看过、弄懂它是干什么的，再决定
AI 会说错，终端命令可能有危险。看不懂的命令不运行。

    
“错误”的英文是哪个词？（五个字母）
error。报错信息里最常见的词之一。

  


  
这一章的新词

  

    
报错 error message程序出错时显示的说明，常常已经写了原因。

    
闪退、崩溃 crash程序突然自己退出。

    
小黄鸭调试法 rubber duck debugging把问题一句句讲出来，讲着讲着自己就想通了。

    
验证 verify自己动手试一试，看别人说的对不对。

  


  

    给大人
    
“关于本机”位于苹果菜单；游戏版本显示于 Java 版标题画面左下角。“小黄鸭调试法”出自 1999 年的《程序员修炼之道》（The Pragmatic Programmer）。社区维基的官方站点以 Minecraft 官网或社区公告为准，请帮孩子把正确的网址存成书签，避免进入广告和下载站。AI 服务的年龄要求见各家服务条款。

    
这一章想教的，是比任何具体知识都重要的东西：遇到困难先自己定位、再有条理地求助。孩子来问你时，也可以反过来问他：“你最后改了什么？屏幕上写了什么？你试过什么？”，帮他养成习惯。

  


  

    
手指头带走一样读、试、查、问、记。求助时写清：想做什么、做了什么、以为会怎样、实际怎样、试过什么、用的什么。

    
脑袋带走一样会问问题，是自学的一半。AI 能帮你把别人的教程变成你的，但最后要你自己验证。
