一块一块我的世界创世记 · 指南

第六部 · 令

第十五章第一次在聊天框里打了斜杠，第二十五章把命令写进了数据包。这一部把常用的命令一条一条讲透：每条命令的英文是什么意思，参数怎么写，它背后藏着哪一块数学或者编程。

学完这一部，你能瞬移到世界上任何一个坐标、让天永远是白天、给自己一身钻石装备、召唤一群小猪又只让其中一只飞起来，最后用变量和“如果……就……”做一个会计时、会记分的小游戏。

封面装置

一条命令的样子

每条命令都是一句英文的“命令句”（祈使句）：开头一个动词，后面跟着“对谁”“什么”“多少”“在哪儿”。点上面的按钮换一条命令，看它每一段是什么，再看它翻成英文句子、中文句子是什么样。

开始前：建一个实验世界

这一部的命令，先在网页上的练习台里试，再到游戏里试。游戏里请专门建一个实验世界，别在你辛苦盖了一年的老世界里折腾（真要在老世界里用，先照第三十八章备份）：

  1. “单人游戏”→“创建新的世界”。名字用拼音或英文，比如 lab。
  2. 游戏模式选“创造”。“允许作弊”（有的版本叫“允许命令”）选开。
  3. 点“世界”那一页，世界类型选“超平坦”。整个世界是一大片平地，最适合练坐标。
  4. 创建。进去以后按 fn + F3，看 XYZ 那一行：在超平坦世界里，你脚下的高度 y 是 −60，一个负数。下一章就从它讲起。

网页上的练习台也做成了“超平坦”：地面是 y = −61 那一层草方块，人站在 y = −60。练习台只认识这一部讲到的命令，写法照 Java 版 1.21 系列；报错的话是仿照游戏的意思写的中文，不是游戏原文。游戏每年都会改几条命令的写法，以社区维基为准。
