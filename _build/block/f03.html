游戏的钟：刻

第十三章讲过，游戏每秒钟“打”20 下拍子，每一下叫一刻（tick，本来是钟表“嘀嗒”的那一声）。白天黑夜一轮，是 24000 刻。

  • 24000 刻 ÷ 每秒 20 刻 = 1200 秒 = 20 分钟。游戏里过一整天，现实里只过 20 分钟。
  • 游戏里的 1 小时 = 24000 ÷ 24 = 1000 刻 = 50 秒。
  • 第 0 刻是早上 6 点左右，太阳刚升起。所以 1000 刻是 7 点，6000 刻是正午 12 点，18000 刻是半夜 12 点。

刻和钟点

第几刻
单位换算学过 · 三四年级 时间单位

1 分 = 60 秒，1 秒 = 20 刻，所以 1 分 = 60 × 20 = 1200 刻。游戏一天 = 24000 刻 = 24000 ÷ 1200 = 20 分。这种“一层一层乘过去”的换算，和“1 元 = 10 角 = 100 分”是一个道理。

试试：一场 30 秒的小游戏是多少刻？（30 × 20 = 600。第五十章的计时器会用到这个数。）

/time 的三种用法

命令做什么
/time set day设成白天：第 1000 刻（早上 7 点）
/time set noon正午：第 6000 刻
/time set night晚上：第 13000 刻（天刚黑，怪开始出来）
/time set midnight半夜：第 18000 刻，月亮在头顶
/time set 23000直接写数：快天亮的时候
/time add 1000往前拨 1000 刻（一个游戏小时）。也能写 /time add 30s（30 秒）、/time add 1d（一天）
/time query daytime问：现在是一天里的第几刻？
/time query day问：今天是第几天？
/time query gametime问：这个世界从创建到现在一共走了多少刻？

注意 set 和 add 的区别：set 是“改成”，不管现在几点，改成 6000 就是 6000；add 是“加上”，在现在的基础上往后拨。时间只能往前拨，不能倒回去（不能 add 负数）。这和上一章的“绝对坐标、相对坐标”又是同一个想法。

/weather：晴、雨、雷雨

  • /weather clear：天晴。
  • /weather rain：下雨。在冷的地方（雪原、高山）会变成下雪，在沙漠里什么也不下。
  • /weather thunder：雷雨。天很暗，会打闪电，怪物白天也可能出来。
  • 后面可以加持续时间：/weather rain 600 下 600 刻，也就是 30 秒；新版本也认 /weather rain 30s 这种带单位的写法（以维基为准）。不写的话，持续多久由游戏随机决定。

在床上睡觉，能跳过黑夜，也能结束雷雨。

让时间停住

想一直是中午，要改一条游戏规则：

/time set noon
/gamerule doDaylightCycle false

doDaylightCycle 是“让白天黑夜轮换”，设成 false（否）就停了。想让它接着走，改回 true（是）。同样，/gamerule doWeatherCycle false 让天气不再自己变。下一章细讲游戏规则。

（据社区维基，较新的版本把游戏规则的名字改成了小写加下划线的样子，比如 keepInventory 变成 keep_inventory，也有的规则干脆换了名字（以维基为准）。如果老写法报错，在聊天框里打 /gamerule 加一个空格，按 tab 看看你的版本里叫什么。）

真的一天为什么是 24 小时以后学 · 五年级科学 / 初中地理

游戏里是太阳绕着方块世界转。真实的世界反过来：是地球自己在转，转一圈大约 24 小时。转到对着太阳的那一面就是白天，背着太阳的那一面就是黑夜。太阳“从东边升起”，是因为地球从西往东转。第七十一章会讲这件事，还有游戏里的八种月亮。

天气和一天里的时候

天气：weather 天气，clear 晴朗，sunny 阳光好的，cloudy 多云的，rain 雨 / rainy 下雨的，snow 雪 / snowy，thunder 雷声，lightning 闪电，storm 暴风雨。

你会发现：名词后面加 -y，常常变成“……的”：sun → sunny，cloud → cloudy，rain → rainy，snow → snowy，wind → windy。

一天：sunrise 日出（太阳 + 升起），morning 早上，noon 正午，afternoon 下午（after 之后 + noon），sunset 日落，evening 傍晚，night 夜，midnight 半夜（mid 中间 + night）。
