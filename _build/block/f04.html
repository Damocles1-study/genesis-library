四种游戏模式

命令模式能做什么英文是什么意思
/gamemode survival生存要挖、要吃、会受伤、会死survival：活下来（survive 活下来 + -al）
/gamemode creative创造东西无限、能飞、不会受伤creative：有创造力的（create 创造）
/gamemode adventure冒险不能随便挖和放方块，给别人玩你做的地图时用adventure：冒险
/gamemode spectator旁观能穿过墙飞来飞去，别人看不见你，什么也碰不了spectator：看热闹的人、观众

后面可以加一个玩家：/gamemode adventure doudou 把豆子变成冒险模式。不写就是改你自己。

Java 版从 2018 年起只认英文单词；以前能写数字（0 生存、1 创造……），现在不行了。基岩版和中国版还认数字和字母，以它们的说明为准。

第三十五章讲过一个快捷键：按住 F3 再点 F4（Mac 上先按住 fn），会弹出一个模式切换器。“极限模式”不是一种 gamemode，而是创建世界时的一个选项：困难难度，死了就不能复活。

spect 是“看”

spectator 里的 spect 是“看”：inspect 检查（往里看），respect 尊重（再看一眼，看重），spectacles 眼镜。后面的 -or 是“……的人”：actor 演员，visitor 访客，creator 创造者。

creative 和 creator 都来自 create（创造）。词尾 -ive 是“……样的”，-or 是“……的人”：一个词根，几种身份。

四种难度

  • /difficulty peaceful：和平。不会生成怪物，已经有的怪物也会马上消失；血会自己回，不会饿。
  • /difficulty easy：简单。有怪，怪打人不太疼。
  • /difficulty normal：普通。默认的难度。
  • /difficulty hard：困难。怪更凶，饿肚子能饿死。

只打 /difficulty，后面什么都不写，是问“现在是什么难度”。

英文：peaceful = peace（和平）+ -ful（充满……的）。同样的还有 colorful 五颜六色的、helpful 有帮助的、beautiful 美丽的。

游戏规则：世界的开关

/gamerule 能改世界的规矩。大多数规则只有两种值：true（是、开）和 false（否、关）。几条最常用的：

规则开着（true）的意思本来是
keepInventory死了以后，物品栏里的东西还在false
doDaylightCycle白天黑夜轮换（时间在走）true
doWeatherCycle天气自己变true
doMobSpawning生物自己生成true
mobGriefing生物能破坏方块：苦力怕炸坑、末影人搬方块true
doFireTick火会蔓延true
doInsomnia好几天不睡觉，会有幻翼来抓你true

还有几条规则要填数，像一个旋钮：randomTickSpeed（默认 3）管庄稼、树苗长得多快，调到 100，你能看着麦子“唰”地长出来；playersSleepingPercentage（默认 100）是百分之几的玩家睡觉就能跳过黑夜。

  • 改：/gamerule keepInventory true
  • 查：/gamerule keepInventory（后面不写值，游戏会告诉你现在是什么）

规则的名字是驼峰写法：几个词连在一起，第一个词小写，后面每个词的头一个字母大写，像骆驼的驼峰：keep + Inventory，do + Daylight + Cycle。上一章说过，较新的版本把一部分名字改成了小写加下划线（以维基为准），打 /gamerule 加一个空格再按 tab 就能看到你的版本里有哪些。

布尔值：只有是和否以后学 · 信息课 / 编程

只有 true 和 false 两种值的东西，程序员叫它布尔值（Boolean），名字来自英国数学家乔治·布尔。第二部第十章讲过他：1847 年，他想出了用“是”和“否”做算术的办法，九十年后被用来设计电路。

红石灯的亮和灭、拉杆的开和关、游戏规则的 true 和 false、Python 里的 True 和 False，都是布尔值。下一卷的“如果……就……”，判断出来的结果也是一个布尔值。

程序里的名字也常用驼峰写法：keepInventory、playerCount。Python 喜欢另一种：全小写加下划线，player_count，叫“蛇形”写法，因为它像一条贴着地爬的蛇。
