/summon 和 /effect

讲什么
召唤生物到一个位置；给它起名字；状态效果：速度、跳跃、夜视、飘浮；等级为什么从 0 数起；可写可不写的参数；/kill 的危险

学完这一章，你能……
  • 用 /summon 在指定的位置召唤生物，给它起名字。
  • 用 /effect give 给自己加效果，用 /effect clear 去掉。
  • 说出“等级 0 就是一级”的道理，算对效果的等级。
  • 只消灭某一种生物，而不是把世界里的东西全清掉。

/summon：召唤

/summon pig
/summon cow ~3 ~ ~
/summon cat ~ ~ ~ {CustomName:"小花"}
  • 只写生物 ID：召唤在你脚下。
  • 后面写坐标：召唤到那个位置，上一章的 ~ 和 ^ 都能用。~3 ~ ~ 是你东边 3 格。
  • 最后的大括号 {…} 是给它的“附加数据”，CustomName 是自己起的名字。这一段的写法这几年改过（老版本要写成 {CustomName:'"小花"'}），以维基为准。

生物的 ID 也是英文：pig 猪，cow 牛，sheep 羊，chicken 鸡，horse 马，wolf 狼，cat 猫，fox 狐狸，bee 蜜蜂，villager 村民（village 村子 + -er 人），iron_golem 铁傀儡，zombie 僵尸，skeleton 骷髅，spider 蜘蛛。第五十五章有全部生物的词卡。

在和平难度里召唤怪物，它会马上消失。还有一个特别的：/summon lightning_bolt 召唤一道闪电。别在木房子旁边试：闪电会点着东西。

/effect：状态效果

/effect give @s speed 60 1
/effect give @s night_vision infinite
/effect clear @s

/effect give 后面四样：给谁、什么效果、多少秒、等级。秒数不写是 30 秒；写 infinite 就一直有效。

效果 ID中文做什么
speed速度走得快
slowness缓慢走得慢
jump_boost跳跃提升跳得高（boost：推一把）
night_vision夜视黑的地方也看得清（night 夜 + vision 视力）
invisibility隐身别人看不见你（in- 不 + visible 看得见的）
levitation飘浮慢慢往天上飘（levitate：飘起来）
slow_falling缓降像羽毛一样慢慢落下，不摔伤
water_breathing水下呼吸在水里不会憋气
regeneration生命恢复血慢慢回来
glowing发光隔着墙也能看见轮廓
等级 0 就是一级以后学 · 编程

命令里的“等级”那个数，英文叫 amplifier（放大器）：它说的是“比最低一级多放大几次”。所以：

  • 写 0（或者不写）→ 1 级，显示成“速度 I”
  • 写 1 → 2 级，“速度 II”
  • 写 4 → 5 级，“速度 V”

规律：显示的等级 = 写的数 + 1。和上一章“快捷栏从 0 号开始”是同一种思路。写程序的人每天都在和这个“+1 还是不 +1”打交道。

还有一个编程的概念藏在这里：秒数和等级可以不写，不写就用默认值（30 秒、0）。程序里的函数也常常这样：有些参数必须写，有些可以省，省了就用默认的。

罗马数字

游戏里显示效果等级用的是罗马数字：I = 1，II = 2，III = 3，IV = 4（5 减 1），V = 5。钟表上、书的章节号上也常见。附魔书上的“锋利 V”，就是锋利 5 级。

/kill：小心

  • /kill @e[type=pig]：只消灭所有的猪。方括号里是筛选条件，下一卷细讲。
  • /kill @s：消灭自己（你会在出生点复活）。
  • /kill @e：消灭世界里所有的实体，包括你自己、所有动物、你的狗、掉在地上的东西、盔甲架、矿车……千万别在有宠物的世界里打这一行。

一个好习惯：打 /kill 之前，先把 kill 换成 say 试一下，比如 /say @e[type=pig]，聊天框会列出它选中了谁。看清楚了再 kill。下一卷的练习台有一个“选择器预览”，就是干这个的。

出错了怎么办
/effect speed @s 报错
那是老写法（基岩版现在还用）。Java 版要先写 give：/effect give @s speed。

难度是和平。
名字没显示出来
大括号的写法随版本变，去维基查你版本的“CustomName”。

想要“跳跃提升 III”（3 级），命令里的等级写几？

显示的等级 = 写的数 + 1，所以写 2。

/effect give @s speed 后面什么都不写，效果持续多久？

  1. 一直有效
  2. 30 秒
  3. 1 秒

秒数的默认值是 30。

哪一条命令最危险？

  1. /kill @e[type=pig]
  2. /kill @s
  3. /kill @e

@e 是所有实体，包括你、宠物、掉落物。

invisibility 是“隐身”。去掉 in-（不）以后，“看得见的”是哪个词？（以 -ible 结尾）

visible，看得见的。in + visible = 看不见的。

/summon cow ~3 ~ ~ 会把牛召唤到哪儿？

  1. 你东边 3 格
  2. 原点东边 3 格
  3. 你头顶 3 格

~ 是从你的位置算，第一个是 x，x 加 3 是往东。

给大人

/summon、/effect（give/clear，默认 30 秒、放大器 0、infinite）与 /kill 的 Java 版语法见社区维基对应条目；1.21.5 起 SNBT 中的文本组件写法改变，CustomName 写法以维基为准。和平难度下召唤的敌对生物会立即消失。基岩版 /effect 写法为 /effect 目标 效果 秒 等级。

建议：/kill @e 是孩子最容易闯祸的一条。可以和孩子一起在练习台里用“选择器预览”看看 @e 到底选中了多少东西。

游戏里带走一样/summon 生物 x y z；/effect give 谁 效果 秒 等级，等级写 0 是一级；kill 之前先用 say 看看选中了谁。
