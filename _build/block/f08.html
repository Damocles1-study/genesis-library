六个选择器

写法选中谁来自哪个英文词
@p离（执行命令的位置）最近的一个玩家player（最近的玩家）
@a所有玩家all
@s执行这条命令的那一个：在聊天框里打，就是你自己self：自己
@e所有实体：玩家、动物、怪物、掉在地上的东西、矿车……entity
@r随机一个玩家random
@n离得最近的一个实体（不管是不是玩家，1.21 新加的）nearest

基岩版和中国版还有一个 @initiator（和村民说话的那个人），用得少。

方括号：筛子

在选择器后面加方括号，里面写条件，几个条件用逗号隔开，逗号和等号两边都不要加空格：

条件例子意思
type 种类@e[type=pig]所有的猪
distance 距离@e[distance=..5]离我 5 格以内的所有实体
limit 最多几个@e[type=cow,limit=3]最多 3 头牛
sort 排序sort=nearest / furthest / random由近到远 / 由远到近 / 随机
tag 标签@e[tag=pet]贴了 pet 标签的（用 /tag 贴）
name 名字@e[name="小花"]名字叫“小花”的
gamemode@a[gamemode=survival]所有生存模式的玩家
! 不是@e[type=!player]所有不是玩家的实体

好几个条件写在一起，要同时满足才被选中：@e[type=pig,distance=..10,limit=2,sort=nearest] 是“10 格以内的猪里，最近的两头”。

贴标签很有用：/tag @e[type=cat,limit=1,sort=nearest] add pet 给最近的猫贴上 pet，以后 @e[tag=pet] 就只选它，@e[type=cat,tag=!pet] 就是“除了宠物以外的猫”。

两个点：范围以后学 · 七年级下 不等式

distance=..5 里的两个点，意思是“到”。一边不写，就是那一边没有限制：

  • ..5：小于或等于 5，数学写成 d ≤ 5
  • 5..：大于或等于 5，d ≥ 5
  • 2..8：在 2 和 8 之间（包括 2 和 8），2 ≤ d ≤ 8
  • 5：正好等于 5

在数轴上画出来，就是一段线。初一下学期学“不等式”时，课本上画的就是这样的线段。第四十九、五十章判断分数时，matches 1.. 也是这种写法。

筛选：程序最常干的活以后学 · 编程

从一大堆东西里，挑出符合条件的，再排序、取前几个，程序员几乎每天都在写这件事：挑出全班数学 90 分以上的、按身高排队取前三个、找出离你最近的公交车站。写法换了，想法完全一样：

选中 = [e for e in 所有实体 if e.种类 == "猪" and 距离(e) <= 10]
选中.sort(按距离)
选中 = 选中[:2]

“几个条件同时满足”，叫与（and）；感叹号“不是”，叫非（not）。第二部第十章的红石“与门”“非门”，就是这两个。

选择器练习台

地图上有一群动物（黄色）、几只怪（红色）和豆子。上面那个红框是选择器预览：在里面打一个选择器，被选中的会在地图上画红圈，不会真的做任何事。看清楚了，再到下面的黑框里打命令。

给宠物上保险★★
  1. 在实验世界里召唤一只狗（wolf）和三头猪。
  2. 给狗贴标签：/tag @e[type=wolf,limit=1,sort=nearest] add pet。
  3. 先用 /say @e[type=!player,tag=!pet] 看看会选中谁。
  4. 确认狗不在里面，再把 say 换成 kill。

这就是专业的做法：先预览，再动手。

出错了怎么办
说“不认识参数”
拼错了条件名，或者等号、逗号旁边加了空格。
@p 选中的不是我
@p 是离“执行位置”最近的玩家。命令方块里执行时，执行位置是命令方块，不是你。
一下子选中了好多东西
@e 会选中所有实体，包括掉在地上的物品。加上 type 筛一筛。

哪个选择器会选中“所有实体”，包括动物和掉落物？

  1. @a
  2. @p
  3. @s
  4. @e

@a 只是所有玩家，@e 是所有实体。

distance=..5 是什么意思？

  1. 正好 5 格远
  2. 5 格以内（≤ 5）
  3. 5 格以外

左边不写，就是“从多近都行，到 5 为止”。

写一个选择器：所有不是玩家的实体。

@e[type=!player]。感叹号是“不是”。

@e[type=pig,limit=1,sort=nearest] 选中几个？

  1. 最多 1 个：最近的那头猪
  2. 所有的猪
  3. 1 个随机的实体

先筛出猪，按由近到远排，只取第一个。

在聊天框里打命令时，@s 是谁？

  1. 离你最近的人
  2. 所有人
  3. 你自己

@s 是执行命令的那一个。在聊天框里打，就是你。

选择器 selector@ 开头、用来挑出目标的写法。
筛选 filter只留下符合条件的。
排序 sort按某个规矩排好队。

给大人

目标选择器与参数（type、distance、limit、sort、tag、name、gamemode、scores 等）、范围写法、@n（Java 版 1.21 新增）见社区维基“目标选择器”条目；基岩版另有 @initiator。练习台的预览只计算选中的实体，不执行任何操作。不等式在人教版七年级下册。

游戏里带走一样@p 最近的玩家、@a 所有玩家、@s 自己、@e 所有实体、@r 随机、@n 最近的实体。方括号里的条件要同时满足，! 是“不是”。先 say，再 kill。
脑袋带走一样挑东西的时候，把条件一条一条写清楚：哪一种、多远、几个、按什么排。写清楚了，电脑和人都不会挑错。
