第一步：建一个变量

/scoreboard objectives add coins dummy "金币"
/scoreboard objectives setdisplay sidebar coins

第一行新建一个记分项（objective，“目标”）：名字叫 coins，类型是 dummy，显示出来叫“金币”。名字只能用英文字母、数字和下划线这些。

dummy 的意思是“假的、摆设”：这个分数游戏自己不会去改，只有命令能改它。游戏还有一些会自己记数的类型，比如 deathCount（死了几次）、minecraft.custom:minecraft.jump（跳了几次）；做小游戏，最常用的是 dummy。

第二行让它显示在屏幕右边栏（sidebar）上。

第二步：改分数

命令做什么Python 里大概是
/scoreboard players set @s coins 10把你的 coins 设成 10coins = 10
/scoreboard players add @s coins 5加 5coins = coins + 5
/scoreboard players remove @s coins 3减 3coins = coins - 3
/scoreboard players get @s coins查：现在是多少print(coins)
/scoreboard players reset @s coins清掉这个人的分数del coins

注意一个不同：Python 里一个变量就是一个数；计分板的一个记分项，是每个人一个数：你的 coins 是 15，豆子的 coins 可以是 3。在后面换成 @a，就是所有人一起改。

分数只能是整数，没有小数，最大二十一亿多（2147483647，和第六十一章的 2 的幂有关）。

变量：有名字的盒子以后学 · 编程第一课

变量（variable，“会变的”）就像一个贴了名字的盒子：盒子里放一个数，你可以看、可以换。几乎每一个程序都从“建一个变量”开始：

  • 起名字（coins）
  • 放进去一个值（10）
  • 用旧的值算出新的值（10 + 5 = 15，放回去）

数学课上的 x 和程序里的变量很像，也有一点不同：数学里 x 是“一个不知道的数”，等你算出来；程序里的 coins 是“一个随时会变的数”，等你去改。第七十二章会在 Python 里把这件事做一遍。

第三步：用分数做算术

operation 让两个分数互相算：

/scoreboard players operation @s coins += doudou coins

意思是“我的 coins 加上豆子的 coins，结果放回我的 coins”。中间的运算符号有这些：

符号意思例子（a 原来是 17，b 是 5）
=a 变成 ba = 5
+=a 加上 ba = 22
-=a 减去 ba = 12
*=a 乘以 ba = 85
/=a 除以 b，只留下商，扔掉余数a = 3
%=a 除以 b，只留下余数a = 2
< / >a 和 b 里取小的 / 取大的a = 5 / a = 17

想乘以一个固定的数（比如 2），要先把 2 存在一个“假玩家”身上：名字以 # 开头的，不是真的人，只是用来放数的。

/scoreboard objectives add const dummy
/scoreboard players set #two const 2
/scoreboard players operation @s coins *= #two const

“#” 开头的假玩家不会显示在右边栏上，专门用来放常数。

商和余数，两个符号学过 · 二年级下 有余数的除法

17 ÷ 5 = 3 …… 2。计分板把这两部分拆开给你：/= 拿商（3），%= 拿余数（2）。Python 里一模一样：17 // 5 是 3，17 % 5 是 2。

余数特别有用：余数是 0，说明能整除。判断一个数是不是偶数，就看它 % 2 是不是 0。第五十章做计时器时，“每 20 刻是一秒”也要用到它。

dummy 类型的记分项，分数怎样才会变？

  1. 游戏自己数
  2. 只有命令能改
  3. 永远不变

dummy 是“摆设”，游戏不碰它，全靠命令。

你的 coins 是 10，执行 add @s coins 5 再执行 remove @s coins 3，现在是多少？

10 + 5 − 3 = 12。

a 是 17，b 是 5，a %= b 以后 a 是多少？

17 ÷ 5 = 3 余 2，%= 留下余数 2。

a 是 7，b 是 2，a /= b 以后 a 是多少？

7 ÷ 2 = 3 余 1，/= 只留商 3。分数没有小数。

名字以 # 开头的“玩家”是什么？

  1. 管理员
  2. 机器人
  3. 假玩家，只用来存数，不显示在右边栏

比如 #two 用来存常数 2。

给大人

/scoreboard 的 objectives 与 players 子命令、准则（dummy、deathCount、minecraft.custom:minecraft.jump 等）、operation 运算符（= += -= *= /= %= < > ><）、分数为 32 位整数，见社区维基“/scoreboard”“记分板”条目。/= 为向下取整的整数除法。

计分板是孩子第一次接触“变量”的绝佳入口：它看得见（右边栏）、改得动、结果马上出来。可以让孩子先口算“做完这一步应该是几”，再执行验证。

游戏里带走一样objectives add 名字 dummy 建变量，setdisplay sidebar 显示；players set/add/remove/get 改和查；operation 做 += -= *= /= %=。
脑袋带走一样变量就是贴了名字的盒子：取出来、算一算、放回去。除法有两个答案：商和余数。
