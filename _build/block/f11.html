哪些是真的

  • 编的：小格、舅舅、豆子和“存档”里的故事；练习台里的世界（猪和牛的位置、豆子的位置）。
  • 真的：命令的写法和效果，按社区维基的 Java 版条目核对过。练习台是简化的模拟：它不计算碰撞、窒息、摔落和生物的行动，报错的话是仿照游戏的意思写的中文，不是游戏的原文。
  • 会变的：命令几乎每年都会改一点写法。在游戏里，用 tab 补全看你的版本认什么；拿不准，以社区维基为准。

第六部存疑和要核对的地方

  • 游戏规则的名字：2025 年起的版本把一部分规则改成了小写加下划线的写法，也有改了名字的；书中用的是流传最广的老名字。
  • /summon 的 CustomName 写法、/give 的附魔写法：1.20.5 和 1.21.5 前后都改过。
  • /weather 的持续时间单位、/fill 的上限：新版本有调整（上限可以用游戏规则改）。
  • @n 选择器：Java 版 1.21 加入，老版本没有。
  • 基岩版和中国版：多数命令相同，/effect 等少数几条写法不同，以它们的说明为准。

命令讲完了，下面认认它们的英文

十章下来，你会说清楚一个地方、一眨眼过去，会让太阳停在天上，会给自己一身钻石，会召唤、会填满一座玻璃房，会从一大群里挑出你要的那一个，会用变量记分、用“如果”做判断、用循环让时间一刻一刻地走。你已经在写程序了。你一定也发现了：每一条命令都是一句英文。下一部，我们就把游戏里的英文单词，一组一组认下来。
