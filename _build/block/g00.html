第七部 · 词

上一部你已经发现：每一条命令都是一句英文。/give @s diamond_sword 就是 “Give me a diamond sword.” 你会打 diamond_sword，就已经认识了 diamond 和 sword 两个词。

这一部把游戏里的英文一组一组认下来：方块、物品、工具、生物、颜色、群系、方向、数字、时间、天气和命令里的动词，一共三百多个。可是我们不背单词表。我们用的是一种更省力的办法：在你本来就喜欢的游戏里听、看、拼、用，再请电脑帮你安排“什么时候该复习哪个词”。

每个英文词点一下都会念给你听。每张词卡上都有“+ 复习”：放进第五十八章的复习台，它会按科学的间隔提醒你复习。

这一部怎么读

  • 第五十一、五十二章是“方法”：怎样听、怎样拼、怎样记。先读这两章。
  • 第五十三到五十七章是“词卡”：一章一两组。不用一次看完，每天挑一组里的十个就够了。
  • 第五十八章是“复习台”：每天花五到十分钟，把该复习的词过一遍。

这一部的中文名，用的是 Java 版简体中文的叫法；中国版（网易）的名字大多一样，个别不同的以游戏里为准。英文用的是游戏里的 ID（比如 oak_planks），它就是英文单词加下划线。

全书目录

    给大人：为什么这样学英语

    这一部的设计基于几个比较可靠的学习研究结论：词汇在有意义的情境里比孤立的词表记得牢；把“听到的声音”“看到的样子”“用到的场合”连在一起，比只连“中文意思”好；间隔重复（隔一段时间再回忆一次，间隔逐渐拉长）比集中背诵更省时、记得更久；主动回忆（先想再看答案）比反复看更有效。游戏 ID 天然是“情境 + 构词”的好材料。

    读音用的是浏览器自带的语音合成（Safari 和 Chrome 在 Mac 上都有美式英语声音），不需要联网下载任何东西，质量和真人有差距，但足以建立“字母和声音”的联系。建议每天固定一个时间用复习台，五到十分钟即可；游戏可以切换成英文界面玩一段时间，遇到不认识的词，和孩子一起查、一起念。

    法怎样听、怎样拼、怎样记

    学单词最累的办法，是一个一个背中文意思。这一卷讲三样更聪明的本事：听懂字母的声音，看出单词是怎样拼起来的，和让大脑在快忘的时候复习。
