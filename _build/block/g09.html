这一部你做到了多少

哪些是真的

  • 编的：小格、舅舅、豆子和“存档”里的故事；遗忘曲线装置里的曲线（只是示意形状）。
  • 真的：游戏 ID 和 Java 版简体中文的名字（按社区维基和游戏语言文件核对），染料的合成组合，构词和复数的规则，艾宾浩斯 1885 年的记忆实验和莱特纳的卡片盒办法。
  • 会变的：游戏会加新方块、新生物，个别中文名也会改；中国版的个别叫法可能不同。以游戏里显示的为准。

第七部存疑和要核对的地方

  • 读音：来自浏览器自带的语音合成，不同电脑、不同浏览器的声音不一样，有时会把下划线、缩写念得怪怪的。拿不准时，请大人或者英语老师念一遍。
  • “地图”：游戏里没画过的地图叫“空地图”，ID 是 map。
  • 盔甲的材料：和工具不完全一样（有皮革和锁链，没有木头和石头）。
  • 遗忘曲线：艾宾浩斯的原始数据是他一个人的实验，后来的研究大致重复出了“开始忘得快、后来慢”的形状，具体百分比因人因材料而异。

第七部出处

  • Minecraft 社区维基（英文与中文）：各方块、物品、生物、群系、染料条目；Java 版语言文件（en_us、zh_cn）。
  • Hermann Ebbinghaus，《论记忆》（1885）。
  • Sebastian Leitner，《学会学习》（So lernt man lernen，1972）。
  • Dunlosky 等，《用有效的学习技巧提高学生学习》，Psychological Science in the Public Interest，2013。
  • 英语构词法与复数规则：常见的英语语法参考书。
第七部 · 词 · 完

三百多个词，下面数一数方块

你学会了先听后看、拆开再拼、在快忘的时候复习。三百多张词卡不用一口气记住，交给复习台，每天十分钟就好。下一部换一门课：方块世界里藏着的数学。负数、2 的幂、比例、体积、角度、概率、速度、勾股定理，有的你已经学过，有的初中才学，在游戏里，它们都是你天天碰到的东西。
