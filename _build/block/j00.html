第十部 · 程

你已经写过很多“程序”了：命令方块里的命令、数据包里的函数、第二十六章用 Python 生成的命令、第五十章的倒计时。这一部把编程最重要的几样东西，一样一样讲透：变量、条件、循环、函数，列表、字典、队列，查找、排序、递归，还有程序员每天都在做的事：找错。

这一部有一个特别的帮手：小蟒。它是一个装在网页里的迷你 Python，你在黑框里写代码，点“运行”就能看到结果，点“一步一步”能看着电脑一行一行地执行、变量一个一个地变。它还认识一个特别的命令 setblock(x, y, z, "stone")，能在一块小地上放方块。

小蟒只会 Python 的一小部分。真正的 Python 请照第二十六章，在大人帮助下装在你的 Mac 上：这一部里的代码，在真的 Python 里也能运行（setblock 除外）。

这一部怎么读

卷二十一“基础”四章：变量、条件、循环、函数，是所有程序的骨头，按顺序读。卷二十二“数据”三章：列表、字典和树、队列，讲怎样放很多东西。卷二十三“算法与本事”四章：查找排序、递归、调试，最后一章讲怎样自学，还有一面成就墙，看看你在整本书里走了多远。

每一章的小蟒下面都有任务单，写出来了会自动打勾。先自己想，再看提示。写不出来很正常：照第四十章和第八十一章的办法，一样一样排除。

全书目录

    给大人：关于“小蟒”

    小蟒是本书自己写的一个 Python 子集解释器，完全在浏览器里运行，不联网、不读写电脑上的文件。它支持整数、小数、字符串、列表、元组、字典、if/while/for、def 与递归、f-string 和常用内置函数，不支持类、异常处理、关键字参数、列表推导式等。报错信息模仿 Python 的英文格式，并附中文解释，方便孩子以后看懂真正的 Python 报错。

    第十部覆盖的概念大致相当于中学信息技术课和大学“程序设计入门”前几周的内容。对十岁孩子，重点不是记住语法，而是建立“程序是一步一步执行的、变量会变、条件选路、循环重复、函数打包”的直觉；“一步一步”按钮和跟踪表就是为此设计的。
