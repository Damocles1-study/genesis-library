if、elif、else

time = 14000
if time < 12000:
    print("白天")
elif time < 13000:
    print("傍晚")
else:
    print("晚上，小心怪物")

读法：如果 time 小于 12000，打“白天”；不然如果小于 13000，打“傍晚”；都不是，打“晚上”。三条路只走一条，从上往下，碰到第一个成立的就走它，后面的不看了。

两个规矩：每个 if、elif、else 这一行最后都有一个冒号；冒号下面要做的事，往里缩进四格（按 tab）。缩进回来，就是 if 管完了。

比较和组合

  • == 等于、!= 不等于、< 小于、> 大于、<= 小于等于、>= 大于等于。比出来的结果是 True 或 False。
  • and：两个都成立才成立。light == 0 and time > 13000：又黑又是晚上。
  • or：有一个成立就成立。
  • not：反过来。

判断能不能整除，用余数（第四十九章）：n % 2 == 0 就是“n 是偶数”。

小蟒 · 条件

照任务单写。改一改变量的值，再运行，看看走了哪条路。

x = 5，下面程序打出什么？
if x > 10: print("大")
elif x > 3: print("中")
else: print("小")

  1. 大
  2. 中
  3. 小

5 > 10 不成立，5 > 3 成立，走第二条路。

True and False 是？

  1. False
  2. True

and 要两个都 True。

True or False 是？

  1. False
  2. True

or 有一个 True 就行。
