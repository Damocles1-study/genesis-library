for 和 range

for y in range(6):
    setblock(4, y, 4, "stone")

读法：“对于 range(6) 里的每一个 y，都放一块石头。”range(6) 是 0、1、2、3、4、5，一共 6 个，从 0 开始，不包括 6。为什么不包括 6？因为这样“range(6)”正好是 6 个，和第四十五章“快捷栏 0—8 号一共 9 格”是一个道理。

range 还有两种写法：range(1, 11) 是 1 到 10；range(0, 20, 2) 是 0、2、4……18，每次跳 2。

循环里套循环

for x in range(10):
    for y in range(4):
        setblock(x, y, 0, "oak_planks")

外面的循环走一步（x 换一个），里面的循环就要从头走一遍（y 从 0 到 3）。所以一共放了 10 × 4 = 40 块：一面 10 宽 4 高的墙。再套一层 z，就是第四十七章的 /fill。

把东西加起来

total = 0
for i in range(1, 101):
    total += i
print(total)

从 1 加到 100，答案是 5050。有一个有名的故事：数学家高斯小时候，老师让全班从 1 加到 100，他很快就说出了 5050：1 + 100、2 + 99……每对都是 101，一共 50 对（故事的细节有好几个版本，存疑）。电脑不用想巧办法，老老实实加 100 次，一眨眼就完。

while：直到……才停

coins = 0
while coins < 64:
    coins += 10
print(coins)

“当 coins 小于 64 的时候，一直加 10”。到 70 时条件不成立了，循环停下。小心死循环：如果条件永远成立（比如忘了让 coins 变），程序永远停不下来。小蟒数到三十万步会帮你喊停；真的 Python 里按 control + C（第三十九章）。

两个开关：break 立刻跳出循环；continue 跳过这一圈剩下的，直接开始下一圈。

点“一步一步”，每点一下走一句，下面的跟踪表会记下每一步时的变量。看懂一个循环最好的办法，就是自己当一回电脑，一步一步跟着走。

跟踪表：自己当一回电脑

看不懂一段程序时，拿一张纸，画一张表：第一列写“第几步”，后面每个变量一列。一句一句往下走，变量变了就在表里写下新的值。这叫跟踪表（trace table），是程序员从古到今的老办法，信息学竞赛的选手也天天用它。

range(4) 是哪几个数？（用逗号隔开）

0, 1, 2, 3。从 0 开始，不包括 4。

外面循环 3 次、里面循环 4 次，里面那句一共执行几次？

3 × 4 = 12。

从 1 加到 100 是多少？

5050。

coins = 0，while coins < 64: coins += 10，最后 coins 是多少？

0、10、20……60 都小于 64 继续加，加到 70 停。

想让循环立刻停下、不再继续，用哪个？

  1. continue
  2. break
  3. pass

break 跳出循环。
