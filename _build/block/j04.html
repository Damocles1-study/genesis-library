def：发明一个命令

def tower(x, z, height):
    for y in range(height):
        setblock(x, y, z, "stone")

tower(1, 1, 3)
tower(5, 2, 6)

def 是 define（定义）的缩写。第一行说：我要发明一个叫 tower 的命令，用它的时候要给三个东西：x、z、高度。这三个叫参数（第三十九章说过，命令后面跟着的就是参数）。冒号下面缩进的几行，是这个命令要做的事。

定义的时候不会执行，只是“记下来”。下面写 tower(1, 1, 3) 时，才真的去做，而且 x 是 1、z 是 1、height 是 3；第二次 x 是 5……同一段代码，不同的参数，盖出不同的塔。

return：交回一个结果

def volume(a, b, c):
    return a * b * c

v = volume(10, 10, 5)
print(v)

有的函数是“做事”（盖塔、打印），有的函数是“算一个结果交回来”。return 就是交回。volume(10, 10, 5) 算出 500，放进 v。像不像数学里的“函数”？给一个（或几个）数，得到一个数。初二会学的“函数”正是这个意思。

还有一个细节：函数里面新建的变量（比如上面 tower 里的 y），只在函数里面有，函数做完就扔掉了，外面看不见。这叫局部变量。这样，不同函数里都叫 y 的变量，不会互相打架。

为什么要用函数以后学 · 编程的第三根骨头
  • 不用抄：写一次，用一百次。要改，只改一个地方。
  • 有名字：build_house() 一看就懂，比二十行 setblock 好读。
  • 能拆开：大问题拆成小问题，一个函数解决一个小问题。第二十五章的数据包，每个 .mcfunction 文件就是一个函数。

你一直在用别人写好的函数：print、len、range。现在你也会写了。
