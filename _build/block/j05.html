一排编了号的格子

hotbar = ["diamond_sword", "iron_pickaxe", "torch", "bread"]
print(hotbar[0])      # diamond_sword
print(hotbar[-1])     # bread：−1 是最后一个
print(len(hotbar))    # 4
hotbar[2] = "water_bucket"

列表的下标（编号）从 0 开始，最后一个是 len − 1。负数下标从后往前数：−1 是最后一个，−2 是倒数第二个。下标超出范围会报 IndexError（第八十一章会专门找这种错）。

写法做什么
a.append(x)在最后加一个（append：附加）
a.pop()拿走最后一个，并把它交回来
a.pop(0)拿走第 0 个（后面的都往前挪一格）
a.insert(1, x)在 1 号的位置插进去（后面的往后挪）
a.remove(x)找到第一个 x，删掉它
x in a问：a 里有没有 x？
a.index(x)x 在第几号
a[1:3]切片：1 号和 2 号（不包括 3），和 range 一样
a.sort()从小到大排好（第七十九章讲排序是怎么做到的）

列表里套列表

    
grid = [[0, 0, 1],
        [0, 1, 1],
        [1, 1, 1]]
print(grid[1][2])   # 第 1 行、第 2 列

    
一个列表，每一格又是一个列表，就成了一张表格（二维列表）：先选第几行，再选第几列。一张平面地图、一块像素画、一张棋盘都能这样存。再套一层，就是三维：world[x][y][z]，整个方块世界就是一个巨大的三维列表（游戏实际存的时候分成区块、压缩过，第三十八章）。

a 有 3 个东西，a[3] 会怎样？

  2. 得到 None

下标只能是 0 到 2。
