字典：用名字找

zh = {"stone": "石头", "dirt": "泥土", "sand": "沙子"}
print(zh["stone"])        # 石头
zh["glass"] = "玻璃"      # 加一个
print("dirt" in zh)       # True
print(zh.get("lava", "不认识"))

字典用大括号，里面是一对一对的 键: 值（第三十八章 options.txt 里的“名字:值”）。列表用编号找，字典用名字找。用一个不存在的键会报 KeyError；不想报错，用 .get(键, 没有时给什么)。

走一遍：for k, v in zh.items():，每一圈 k 是键、v 是值。

数一数每种有几个

chest = ["stone", "dirt", "stone", "torch", "stone", "dirt"]
count = {}
for item in chest:
    if item in count:
        count[item] += 1
    else:
        count[item] = 1
print(count)   # {'stone': 3, 'dirt': 2, 'torch': 1}

这是程序员最常写的几行代码之一：投票统计、成绩分段、单词出现了几次，都是它。第六十五章算“众数”，也可以这样做。

树

第三十六章说，文件夹是一棵倒着长的树。如果字典的值又是一个字典，就能表示一棵树：

home = {"Desktop": {}, "Documents": {"编程课": {"小海龟.py": None}},
        "Library": {"Application Support": {"minecraft": {"saves": {}}}}}

游戏里按 L 打开的进度（成就）也是一棵树：根是“我的世界”，往下分出“获得木头”“石器时代”……每一个都要先完成它上面那个，才能解锁。家谱、学校的年级和班级、生物的分类（界门纲目科属种），也都是树。

树和递归以后学 · 第八十章

想把整棵树都打印出来，该怎么写？每个文件夹里面又是文件夹，层数不知道有多少，用几层 for 都不够。办法是让一个函数“打印一个文件夹，再对它里面的每个文件夹，调用自己”。这叫递归，第八十章细讲。

装置 · 第七十七章 · 二

小蟒 · 字典

照任务单写。

zh = {"stone": "石头", "dirt": "泥土"}，zh["dirt"] 是？

用键 dirt 找到值“泥土”。

列表和字典最大的不同是？

  1. 列表能放字，字典不能
  2. 列表用编号找，字典用名字（键）找
  3. 没有不同

一个按编号，一个按名字。

字典里没有 "lava"，zh["lava"] 会怎样？

  1. 得到 None
  2. 自动加上
  3. KeyError

用 .get 就不会报错。

下面哪个不是树？

  1. 一排快捷栏
  2. 文件夹
  3. 游戏的进度

快捷栏是一排（列表），没有分叉。

这一章的新词
字典 dictionary一对一对的键和值。
键 key用来找的那个名字。
值 value找到的东西。
树 tree一个分成好几个、每个再分的结构。
游戏里带走一样ID → 中文名就是字典；进度和文件夹都是树。
脑袋带走一样按编号找用列表，按名字找用字典，有分叉用树。
