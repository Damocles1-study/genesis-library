哪些是真的

  • 编的：小格、舅舅、妈妈、豆子和“存档”里的故事，包括开学第一周那一段；装置里的迷宫、箱子里的数、虫子程序。
  • 真的：Python 的写法和报错的格式；查找、排序、递归、广度优先搜索这些算法；1947 年的飞蛾和汉诺塔的来历。
  • 小蟒是本书自己写的迷你 Python，只会真 Python 的一小部分（没有类、异常处理、关键字参数等），运行速度也慢得多。这一部的代码在真的 Python 3 里都能运行（setblock 除外）。

第十部存疑和要核对的地方

  • 高斯小时候算 1 到 100：故事流传很广，细节有好几个版本。
  • 汉诺塔的寺庙传说：是 1883 年发明这个游戏的法国数学家卢卡斯编出来的宣传故事。
  • “第一只虫子”：飞蛾是真的，但 bug 这个词在那以前就有了。

第十部出处

  • Python 官方文档与教程（中文版）。
  • 史密森学会国家美国历史博物馆：哈佛马克二号工作日志（1947）。
  • Édouard Lucas 与汉诺塔（1883）的数学史资料。
  • 常见的算法入门教材（查找、排序、递归、广度优先搜索）。

十部八十三章。前四部讲方块世界的故事，后六部把它拆开给你看：键盘和文件、命令、英语、数学、物理、编程。你会发现，它们其实是同一件事的不同侧面：把东西拆成小块，弄懂每一块，再一块一块搭起来。方块世界是这样造出来的，你的本事也是这样长出来的。剩下的，交给你自己。
