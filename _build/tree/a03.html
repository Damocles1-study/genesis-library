一排挨着的格子

数组就是一排挨着的格子，每格放一样东西，编号从 0 开始。Python 的列表就是一种数组。

《地基》里说过，内存是一排带号码的柜子。数组就占着其中挨着的一段：第 0 格在某个号码，第 1 格紧挨着它，第 2 格再紧挨着……

拿第 i 个：一步

要拿第 i 个，电脑不用一格一格地数。它知道第 0 格在哪儿，每格多大，一算就知道：

第 i 格的位置 ＝ 第 0 格的位置 ＋ i × 每格的大小

一次乘法、一次加法，直接跳过去。所以不管数组有 10 个还是 100 万个，拿第 i 个都只要一步：常数。

插队：要挪一串

可是要往中间插一个，就麻烦了。格子是挨着的，没有空隙。要在第 2 格插一个新的，原来第 2 格以后的东西都得往后挪一格，而且要从最后一个开始挪，不然会把后面的东西盖掉。

插在最前面，所有东西都要挪；插在最后面，一个都不用挪。删掉中间一个也一样：后面的都要往前挪一格，把空补上。

把地图拉成一排

方格岛是 10 行，每行 16 格。电脑的内存只是一长排，二维的地图要怎样放进去？最常见的办法是一行接一行：先放第 0 行的 16 格，再放第 1 行……

这样，(x, y) 那一格就是一长排里的第 y × 16 + x 格：先跳过 y 整行，再往右走 x 格。反过来，第 i 格就是 x = i % 16、y = i // 16（% 是余数，// 是整除）。

bar = ['石', '沙', '木', '草', '花']
moves = 0

def insert(i, item):
    global moves
    bar.append(None)                 # 先在最后加一个空位
    k = len(bar) - 1
    while k > i:                     # 从后往前挪
        bar[k] = bar[k - 1]
        moves = moves + 1
        k = k - 1
    bar[i] = item

insert(0, '鸭')
print(bar, '挪了', moves, '次')

线性表和顺序表

线性表是 n（≥ 0）个相同类型数据元素的有限序列。除第一个元素外每个元素有唯一的直接前驱，除最后一个外每个有唯一的直接后继。注意 408 的约定：线性表的位序从 1 开始，数组下标从 0 开始，写代码时别差一位。

用顺序存储实现的线性表叫顺序表：

#define MAXSIZE 100
typedef struct {
    int data[MAXSIZE];   /* 静态分配：大小编译时定死 */
    int length;
} SqList;

typedef struct {
    int *data;           /* 动态分配：用 malloc 申请，满了可以 realloc 换一块更大的 */
    int capacity, length;
} SeqList;

动态分配仍然是顺序存储：换大以后元素还是连续的，只是整体搬到了一块新地方（《地基》第二十一章的堆）。

插入和删除

/* 在第 i 个位置（1 ≤ i ≤ length+1）插入 e */
int insert(SqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1 || L->length >= MAXSIZE) return 0;
    for (int j = L->length; j >= i; j--)    /* 从最后一个往后挪 */
        L->data[j] = L->data[j - 1];
    L->data[i - 1] = e;
    L->length++;
    return 1;
}
/* 删除第 i 个（1 ≤ i ≤ length），用 *e 带回 */
int delete(SqList *L, int i, int *e) {
    if (i < 1 || i > L->length) return 0;
    *e = L->data[i - 1];
    for (int j = i; j < L->length; j++)     /* 后面的往前挪 */
        L->data[j - 1] = L->data[j];
    L->length--;
    return 1;
}

在第 i 个位置插入要移动 n − i + 1 个元素。插入位置有 n + 1 种，等概率时平均移动 n/2 次；删除第 i 个移动 n − i 个，n 种位置，平均 (n − 1)/2 次。两者都是 O(n)。按位置取值 O(1)（随机存取），按值查找平均 (n + 1)/2 次比较，O(n)。

三道经典题：双指针

顺序表的算法题，很多都可以用“一个读、一个写”的两个下标在一遍之内做完，时间 O(n)、空间 O(1)。

典型题 · 原创

（1）删除顺序表中所有值在 [s, t] 之间的元素，要求时间 O(n)、空间 O(1)。（2）把数组 A[0..n−1] 循环右移 k 位（0 < k < n），空间 O(1)。（3）两个升序数组 A、B 各有 n 个数，找出合并以后的第 n 小的数（下中位数），要求尽量快。

看解答

（1）读指针 i 从头走到尾，写指针 k 记“留下的有几个”：A[i] 不在 [s, t] 内就 A[k++] = A[i]，最后 length = k。每个元素只看一次。

int k = 0;
for (int i = 0; i < L->length; i++)
    if (L->data[i] < s || L->data[i] > t) L->data[k++] = L->data[i];
L->length = k;

（2）三次逆置：先整体逆置，再分别逆置前 k 个和后 n − k 个。例如 1 2 3 4 5 右移 2：整体逆置 5 4 3 2 1，前 2 个逆置 4 5，后 3 个逆置 1 2 3，得 4 5 1 2 3。每次逆置是首尾两个下标往中间走、交换，总共约 n 次交换，O(n) 时间、O(1) 空间。（左移 k 位就是右移 n − k 位。）

（3）O(n) 的做法：两个指针像合并一样往前走 n 步。更快的做法是二分：比较 A 和 B 的中位数 a、b；若 a = b 即为所求；若 a < b，答案不可能在 A 的前半段和 B 的后半段，各舍去相同的个数，规模减半，O(log n)。写对舍去时奇偶长度的处理是这题的难点：保证两边舍去的个数相等。

数组的地址公式

二维数组 A[0..m−1][0..n−1]，每个元素占 L 个字节，起始地址 LOC：

  • 按行优先（C、Python 的二维列表的“逻辑顺序”）：LOC(i, j) = LOC + (i × n + j) × L。
  • 按列优先（Fortran、MATLAB）：LOC(i, j) = LOC + (j × m + i) × L。
下标从几开始

题目里的数组常从 1 开始（A[1..m][1..n]），公式要写成 (i − 1) × n + (j − 1)。先看清题目的下界，再套公式；算完用 A[1][1] 和最后一个元素检验一下。

特殊矩阵的压缩存储

有些矩阵有一半是重复的或者是 0，没必要全存。把它们压进一个一维数组 B，关键是写出 aij 在 B 里的下标 k。下面都设矩阵 n 阶、下标从 1 开始、B 的下标从 0 开始、按行优先存：

矩阵存哪些元素个数aij 的下标 k
对称矩阵（aij = aji）下三角（含对角线）n(n+1)/2i ≥ j 时 k = i(i−1)/2 + j − 1；i < j 时交换 i、j
下三角矩阵（上方全是常数 c）下三角 + 最后一格放 cn(n+1)/2 + 1i ≥ j 时同上；i < j 时 k = n(n+1)/2
上三角矩阵（下方全是 c）上三角 + 最后一格放 cn(n+1)/2 + 1i ≤ j 时 k = (i−1)(2n−i+2)/2 + j − i；i > j 时 k = n(n+1)/2
三对角矩阵（|i − j| ≤ 1 才非零）三条对角线3n − 2k = 2i + j − 3

不要死背：下三角“第 i 行前面有 1 + 2 + … + (i − 1) 个元素，再往右数 j − 1 个”；上三角“第 i 行前面有 n + (n−1) + … + (n−i+2) 个元素，再往右数 j − i 个”；三对角“第 i 行前面有 3(i−1) − 1 个，再往右数 j − i + 1 个”。每次推一遍，再拿 a11、ann 检验。

稀疏矩阵：非零元素很少且没有规律，用三元组表（行, 列, 值）按行优先存非零元素，再记上矩阵的行数和列数；也可以用十字链表。三元组表失去了随机存取的能力。

典型题 · 原创

（1）10 阶对称矩阵 A（下标从 1 开始）按行优先压缩存储下三角到 B[0..54]，a3,7 存在 B 的第几个位置？（2）8 阶三对角矩阵按行优先压缩到 B[0..21]，B[11] 存的是哪个元素？

看解答

（1）a3,7 = a7,3，i = 7、j = 3：k = 7 × 6 / 2 + 3 − 1 = 23。

（2）k = 2i + j − 3 = 11，且 |i − j| ≤ 1。试 i = 5：j = 11 + 3 − 10 = 4，满足，是 a5,4。检验：第 1 行 2 个、第 2—4 行各 3 个，共 11 个（B[0..10]），第 5 行的第一个就是 B[11] = a5,4。

长度为 n 的顺序表，在各位置插入的概率相等，平均移动几个元素？

  1. (n−1)/2
  2. n/2
  3. (n+1)/2
  4. n

n+1 种插入位置，移动 n, n−1, …, 0 个，平均 n/2。删除是 (n−1)/2。

顺序表最大的优点是？

  1. 随机存取
  2. 插入删除快
  3. 不需要连续空间

按位置 O(1) 存取。

二维数组 A[0..9][0..19] 每个元素 4 字节，按行优先，起始地址 1000，A[1][2]（行 1 列 2）的地址是？

1000 + (1 × 20 + 2) × 4 = 1088。按列优先则是 1000 + (2 × 10 + 1) × 4 = 1084。本题答案 1088。

n 阶三对角矩阵压缩存储需要 3n − 2 个单元。10 阶需要几个？

3 × 10 − 2 = 28。

把数组循环左移 p 位、空间 O(1)，最常用的办法是？

  1. 开一个新数组
  2. 每次左移一位、重复 p 次
  3. 三次逆置

三次逆置 O(n)。逐位移动是 O(pn)。

Python 的 list 放的是什么

CPython 的 list 是一块连续的数组，可里面存的不是数本身，而是指向对象的指针（每个 8 字节）。[1, 2, 3] 里的 1、2、3 是三个各自住在堆上的整数对象。所以 list 能装不同类型的东西，代价是每个元素多一次“照着纸条找过去”，而且对象散落在内存各处，缓存不友好。

要存大量同类型的数，用标准库的 array.array('i')，或者 NumPy 的数组：它们把数直接挨着放，省空间、算得快，NumPy 还能用 SIMD 指令一次算好几个。

量一量占多少内存10 分钟
import sys, array
n = 1_000_000
lst = list(range(n))
arr = array.array('i', range(n))
print('list 本身', sys.getsizeof(lst) // 1024, 'KB（只算指针数组）')
print('再加上一百万个 int 对象，约', (sys.getsizeof(lst) + n * sys.getsizeof(10**6)) // 1024, 'KB')
print('array(\'i\')', sys.getsizeof(arr) // 1024, 'KB')
a = []
last = sys.getsizeof(a)
for i in range(40):
    a.append(i)
    s = sys.getsizeof(a)
    if s != last:
        print('长度', len(a), '时扩容，现在', s, '字节'); last = s

最后一段打出 list 扩容的时刻：容量不是每次加一，而是按比例多要一些（第一章第三层的均摊分析）。具体数字随 CPython 版本略有不同。

结构体的数组，数组的结构体

游戏里有一万只鸭子，每只有 x、y、颜色、名字。可以存成“一万个结构体排成一排”（AoS，array of structures），也可以存成“四个数组，各有一万个”（SoA，structure of arrays）。如果某个循环只更新所有鸭子的 x、y，SoA 让要用的数挨在一起，每次读进缓存的 128 字节（Apple Silicon 的缓存行，《地基》第十六章）全是有用的；AoS 会把名字、颜色也一起读进来，浪费带宽。游戏引擎和数据库的“列式存储”都是这个想法。

为什么连续存放格外快

现代处理器访问内存的代价，和“访问的是不是挨着的”关系极大：顺序访问能被预取器提前搬进缓存，随机跳着访问每次都可能要等上百个时钟周期。所以数组的常数常常比链表小一个数量级，这也是第三章链表的第三层要讨论的。
