第一层 · 入门要会：指针是写着号码的纸条（《地基》第十八章）、数组（第二章）约 35 分钟

寻宝纸条

寻宝游戏里，第一张纸条写着“去书架”；书架上有第二张，写着“去冰箱”；冰箱上有第三张……最后一张写着“宝藏在这里”。

这一串纸条可以藏在家里的任何地方，不用挨着。只要每一张都写清楚下一张在哪儿，就能一张一张找下去。

这就是链表。链表里的每一个东西叫一个结点，每个结点里有两样：

  • 它自己的东西（比如一只鸭子的名字）；
  • 一张纸条，写着下一个结点在哪儿。最后一个结点的纸条是空的，表示“到头了”。

另外还要记着第一个结点在哪儿，叫头（head）。没有头，就不知道从哪儿开始找。

纸条就是指针

《地基》第十八章说，写着柜子号码的纸条叫指针。链表就是一串用指针连起来的结点。在 Python 里不用写指针：一个变量“指着”一个字典或列表，就是一张纸条。

鸭子队伍

方格岛上，三只小鸭子跟在你身后。主线第 3 步就用链表来存这支队伍：每只鸭子记着自己站在哪儿，还拿着一张纸条，写着下一只是谁。

你往前走一步，队伍怎样跟上？不用把每只鸭子都挪一遍，只要两件事：

  1. 在你刚才站的地方，加一只新的“头鸭子”，让它的纸条指着原来的第一只。
  2. 把最后一只拿走。

看起来，就像整支队伍跟着你挪了一步。

什么快，什么慢

加到最前面很快：新结点的纸条写上“原来的头”，再把头改成新结点。两步，不管链表有多长。数组插到最前面，要挪一整串（第二章）。

找第 k 个很慢：没有“开头 + k × 大小”这种算法，因为结点不挨着。只能从头开始，照着纸条一个一个走，走 k 步。数组一步就到。

拿走最后一个也慢：要先从头走到倒数第二个，才能把它的纸条改成空的。

数组链表
拿第 k 个一步从头走 k 步
加到最前面挪一整串两步
放在内存里要一整块挨着的哪儿有空放哪儿
每个东西多占的地方没有一张纸条

单链表

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

多数教材和 408 默认带头结点：在第一个数据结点前面放一个不存数据的结点，头指针指着它。好处：① 在第一个位置插入删除和在别处一样，不用特殊处理；② 空表和非空表的处理统一（空表时头结点的 next 为 NULL）。判空：带头结点 L->next == NULL，不带头结点 L == NULL。

/* 头插法：每个新结点插在头结点后面。读入顺序和链表顺序相反 */
LinkList build_head(int *a, int n) {
    LinkList L = malloc(sizeof(LNode)); L->next = NULL;
    for (int i = 0; i < n; i++) {
        LNode *s = malloc(sizeof(LNode)); s->data = a[i];
        s->next = L->next; L->next = s;
    }
    return L;
}
/* 尾插法：多一个尾指针 r，顺序和读入一致 */
LinkList build_tail(int *a, int n) {
    LinkList L = malloc(sizeof(LNode)); LNode *r = L;
    for (int i = 0; i < n; i++) {
        LNode *s = malloc(sizeof(LNode)); s->data = a[i];
        r->next = s; r = s;
    }
    r->next = NULL;
    return L;
}

按序号查找、按值查找都要从头走，O(n)。插入：在第 i 个位置插入，先找到第 i − 1 个结点 p，再 s->next = p->next; p->next = s;，两句不能颠倒（颠倒了 p 原来的后继就丢了）。找位置 O(n)，真正插入 O(1)。删除第 i 个：找到第 i − 1 个 p，q = p->next; p->next = q->next; free(q);。

只给了 p 本身，要在 p 前面插入或删除 p

单链表找不到前驱。技巧是“偷梁换柱”：在 p 后面插入新结点 s，再交换 p 和 s 的数据，效果等同于插在 p 前面，O(1)。删除 p：把后继 q 的数据抄进 p，再删掉 q。但 p 是最后一个结点时不能这样删，只能从头找前驱。

双链表和循环链表

双链表每个结点多一个 prior 指针，可以 O(1) 找前驱。在 p 之后插入 s，四句的一种正确顺序：

s->next = p->next;           /* ① s 先接上 p 的后继 */
if (p->next) p->next->prior = s;  /* ② 后继回指 s（p 是尾结点时没有后继）*/
s->prior = p;                 /* ③ */
p->next = s;                  /* ④ 最后才改 p->next */

原则：在 p->next 被改掉之前，先用完它。删除 p 的后继 q：p->next = q->next; if (q->next) q->next->prior = p; free(q);。

循环单链表：最后一个结点指回头结点，判空是 L->next == L。常只设尾指针 r：头是 r->next，这样在头和尾插入都是 O(1)。循环双链表：头结点的 prior 指向尾结点。

静态链表：用数组存结点，“指针”是下一个元素的下标（游标），−1 或 0 表示结束。适合没有指针的语言，或者要预先分配好空间的场合（比如操作系统的 FAT 文件分配表，《地基》第二十八章）。

快慢指针和几道高频题

/* 原地逆置（带头结点）：一个一个摘下来，头插回去 */
void reverse(LinkList L) {
    LNode *p = L->next, *r; L->next = NULL;
    while (p) { r = p->next; p->next = L->next; L->next = p; p = r; }
}
/* 找中点：慢的走一步，快的走两步；快的到头时慢的在中间 */
LNode *middle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
    return slow;
}
/* 判环（弗洛伊德）：有环则快慢终会相遇 */
int has_cycle(LinkList L) {
    LNode *slow = L, *fast = L;
    while (fast && fast->next) {
        slow = slow->next; fast = fast->next->next;
        if (slow == fast) return 1;
    }
    return 0;
}
  • 倒数第 k 个：快指针先走 k 步，然后两个一起走，快的到头时慢的就是倒数第 k 个。一遍扫描。
  • 环的入口：相遇以后，一个指针回到头，两个都每次走一步，再次相遇处就是入口。（设头到入口 a、入口到相遇点 b、环长 c，快走的路程是慢的两倍：2(a + b) = a + b + kc，得 a = kc − b，即从相遇点再走 a 步正好回到入口。）
  • 合并两个有序链表：两个指针比较，小的接到结果后面，O(m + n)。
  • 两个链表的第一个公共结点：先求长度差 d，长的先走 d 步，再一起走到相遇。
典型题 · 原创

带头结点的单链表 L 有 n 个结点（n ≥ 2）。设计一个时间 O(n)、空间 O(1) 的算法，把它重排成 a₁, aₙ, a₂, aₙ₋₁, a₃, … 的顺序（第一个、最后一个、第二个、倒数第二个……交替）。

看解答

三步：① 用快慢指针找到中点，把链表断成前后两半；② 原地逆置后一半；③ 两个指针交替地把后一半的结点插进前一半。每一步都是 O(n)，只用了几个指针。

void reorder(LinkList L) {
    LNode *slow = L, *fast = L;
    while (fast->next && fast->next->next) { slow = slow->next; fast = fast->next->next; }
    LNode *q = slow->next, *r; slow->next = NULL;   /* 断开，q 是后一半 */
    LNode *rev = NULL;
    while (q) { r = q->next; q->next = rev; rev = q; q = r; }   /* 逆置后一半 */
    LNode *p = L->next;
    while (rev) { r = rev->next; rev->next = p->next; p->next = rev; p = rev->next; rev = r; }
}

自己用 1 2 3 4 5 走一遍：前一半 1 2 3、后一半 4 5 逆置成 5 4，交替插入得 1 5 2 4 3。

面试题

只给你单链表中间某个结点的指针（不是头），怎样删除它？有什么限制？

看要点

把后继结点的值复制到这个结点，再删除后继（“偷梁换柱”），O(1)。限制：不能删除最后一个结点（没有后继可以抄）；如果外面还有别的指针指着那个后继结点，会出问题；结点里的数据很大、或者不能复制（比如有身份的对象）时也不合适。面试时把这些限制说出来，比只给答案加分。

带头结点的单链表 L 为空的条件是？

  1. L == NULL
  2. L->next == NULL
  3. L->next == L

头结点还在，只是后面没有结点。L->next == L 是循环链表的判空。

用头插法依次插入 1, 2, 3，链表从头到尾是？

  1. 3, 2, 1
  2. 1, 2, 3

头插法顺序相反。

在单链表中 p 所指结点后面插入 s，正确的是？

  1. p->next = s; s->next = p->next;
  2. s->next = p; p->next = s;
  3. s->next = p->next; p->next = s;

先让 s 接上 p 原来的后继，再改 p->next。

设尾指针的循环单链表，在表头和表尾插入的时间分别是？

  1. O(1)、O(n)
  2. O(1)、O(1)
  3. O(n)、O(1)

头就是 r->next，两处都能直接拿到。

判断单链表有没有环，空间 O(1) 的办法是？

  1. 快慢指针
  2. 把走过的结点放进集合
  3. 先逆置再看

快慢指针（弗洛伊德判圈）。用集合要 O(n) 空间。

第三层 · 深入真实系统里的链表约 25 分钟Linux 内核的侵入式链表和 container_of；为什么链表在今天的处理器上常常输给数组；什么时候链表真的好用。

侵入式链表

教科书的链表是“结点里装着数据”。Linux 内核反过来：数据结构里嵌一个只有两个指针的 struct list_head { struct list_head *next, *prev; }。一个进程描述符可以同时挂在好几条链上（运行队列、父子关系、同一个组……），每条链用它里面不同的 list_head 字段。顺着链走到某个 list_head 以后，用 container_of(ptr, type, member) 宏减去这个字段在结构体里的偏移（offsetof），就得到整个结构体的地址。好处是链表代码只写一份、不用为每种数据单独 malloc 结点。

#include <stddef.h>
#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))

struct list_head { struct list_head *next, *prev; };
struct duck { int x, y; struct list_head line; };   /* 鸭子挂在队伍链上 */
/* 给出 line 的地址 p，就能拿回整只鸭子：container_of(p, struct duck, line) */

链表为什么常常更慢

复杂度表上，链表在“已知位置插入删除”上赢数组。但实际程序要先找到那个位置，而沿着链表走，每一步都是一次难以预测的内存访问：结点散落在堆里，预取器猜不到下一个在哪儿，每一步都可能缓存未命中（《地基》第十六章）。C++ 之父斯特劳斯特鲁普做过一个有名的演示：随机位置插入删除几万个整数，vector 比 list 快得多，因为 vector 挪动的是连续内存，比追指针便宜。

链表真正好用的场合：元素很大或不能移动（别处有指针指着它）；需要在已经拿在手里的位置 O(1) 拼接、摘除（LRU 缓存用“散列表 + 双链表”，第二十三章）；内存分配器的空闲链表（《地基》第二十一章）；无锁并发数据结构。
