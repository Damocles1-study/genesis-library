第一层 · 入门要会：一摞盘子（《地基》第二十章）、Python 的列表约 30 分钟

只许从一头进出

一摞盘子：新的放在最上面，拿也从最上面拿。后放上去的，先被拿走。这种队伍叫栈（stack）。

栈只有两个动作：

  • 压栈（push）：放一个到最上面。
  • 弹栈（pop）：从最上面拿走一个。

中间的和下面的，碰都不许碰。规矩这么严，有什么用？用处很多。

你见过的栈

《地基》第二十章：函数调用就是一摞盘子，最后叫的最先做完。《一块一块》第七十八章你用过栈和队列。在 Python 里，列表的 append 就是压栈，pop() 就是弹栈。

撤销：做过的事摞成一摞

在方格岛上，你每放一块石头、挖一块沙，就把“这一步怎样改回去”写在一张卡片上，放到一摞的最上面。

按“撤销”，就从最上面拿一张，照着改回去。最后做的事，最先被撤销。再按一次，撤销的是倒数第二件事。

重做呢？再准备一摞。撤销时拿下来的卡片，不扔掉，放到“重做”那一摞上。按“重做”，就从那一摞拿回来。

还有一条规矩：撤销了几步以后，你又做了一件新的事，“重做”那一摞就要清空。因为你已经走上了另一条路，原来那些步子接不上了。

括号配对

写程序时，括号必须一对一对的：(1 + [2 × 3]) 是对的，(1 + [2 × 3)] 就错了：方括号还没关，圆括号先关了。

用一个栈就能检查：从左往右读，

  • 看到左括号 ( [ {，压栈；
  • 看到右括号，看栈顶是不是和它配对的那种左括号：是，就弹掉；不是（或者栈是空的），就错了；
  • 读完以后，栈必须是空的。还剩下左括号，说明有的没关。

为什么是栈？因为最后打开的括号，必须最先关上，正好是后进先出。

def ok(s):
    pair = {')': '(', ']': '[', '}': '{'}
    stack = []
    for c in s:
        if c in '([{':
            stack.append(c)              # 左括号：压栈
        elif c in ')]}':
            if not stack or stack.pop() != pair[c]:
                return False             # 栈空了，或者对不上
    return not stack                     # 读完了，栈要是空的

顺序栈

#define MAX 50
typedef struct { int data[MAX]; int top; } SqStack;
void init(SqStack *S) { S->top = -1; }            /* top 指向栈顶元素 */
int  empty(SqStack *S) { return S->top == -1; }
int  push(SqStack *S, int x) { if (S->top == MAX - 1) return 0; S->data[++S->top] = x; return 1; }
int  pop(SqStack *S, int *x) { if (S->top == -1) return 0; *x = S->data[S->top--]; return 1; }

另一种约定是 top 初始为 0、指向栈顶元素的下一个位置：入栈 data[top++] = x，出栈 x = data[--top]，栈空 top == 0，栈满 top == MAX。做题先看清用的是哪一种，元素个数分别是 top + 1 和 top。

共享栈：两个栈共用一个数组，一个从 0 往上长（top0 初值 −1），一个从 MAX − 1 往下长（top1 初值 MAX），栈满条件 top1 − top0 == 1。两个栈此消彼长时能更充分地用空间，但只适合两个栈。

链栈：用不带头结点的单链表，所有操作都在表头做，push 是头插、pop 是删第一个结点。不会栈满（除非内存耗尽）。

出栈序列

1, 2, …, n 依次入栈，中间随时可以出栈，能得到哪些出栈序列？

  • 判断一个序列是否可能：模拟。按序列依次要出栈的数 x：若 x 还没入栈，就把它之前（含它）的数依次入栈，再弹出 x；若 x 已在栈里，它必须正好在栈顶，否则不可能。
  • 一个快速的必要条件：对出栈序列里的任意一个数 x，排在它后面、且比它小的数，必须按从大到小的顺序出现。所以 3, 1, 2 不可能（3 后面的 1、2 是从小到大）。
  • 个数是卡特兰数 Cn = C(2n, n) / (n + 1)：n = 3 时 5 种，n = 4 时 14 种，n = 5 时 42 种。

表达式求值

中缀表达式 3 + 4 × (2 − 1) 对人友好，对电脑不友好：要看优先级和括号。后缀表达式（逆波兰式）把运算符放在两个运算数后面：3 4 2 1 − × +，不需要括号，从左往右用一个栈就能算：遇到数压栈；遇到运算符弹出两个数（先弹出的是右操作数），算完把结果压栈；最后栈里剩下的就是答案。

中缀转后缀，用一个运算符栈，从左往右扫：

  1. 遇到运算数，直接输出。
  2. 遇到 (，压栈。
  3. 遇到 )，依次弹出并输出栈里的运算符，直到弹出 (（括号不输出）。
  4. 遇到运算符 op，依次弹出并输出栈顶优先级大于或等于 op 的运算符（遇到 ( 或栈空停），再把 op 压栈。“等于也弹”保证了同级运算从左往右算。
  5. 扫完以后，把栈里剩下的运算符依次弹出输出。
典型题 · 原创

（1）把 a × (b + c) − d / e 转成后缀表达式，写出转换过程中运算符栈的最大深度。（2）1, 2, 3, 4, 5 依次入栈，下列哪个出栈序列不可能：A. 2 3 1 5 4 B. 4 5 3 2 1 C. 3 1 2 4 5 D. 1 2 3 4 5。（3）一个栈的入栈序列是 1, 2, …, n，出栈序列的第一个是 n，那么第 i 个出栈的是？

看解答

（1）a 输出；× 入栈；( 入栈；b 输出；+ 入栈（栈顶是 ( 不弹），此时栈为 × ( +，深度 3；c 输出；) 弹出 +，弹掉 (；− 来了，弹出优先级 ≥ − 的 ×，− 入栈；d 输出；/ 入栈（− 优先级低，不弹）；e 输出；最后弹出 /、−。结果 a b c + × d e / −，最大深度 3。

（2）C。3 先出，说明 1、2 已在栈里且 2 在 1 上面，下一个出栈不能是 1。

（3）第一个就是 n，说明 1 到 n 全部入栈后才开始出栈，出栈序列只能是 n, n−1, …, 1，第 i 个是 n − i + 1。

递归和栈

递归调用靠系统的调用栈保存每一层的现场（《地基》第二十章）。任何递归都可以改写成“用自己的栈模拟”的非递归形式，第七章会把油漆桶填色改写一遍。递归的代价是深度太大时栈溢出，以及重复计算（比如直接递归求斐波那契数，第二十二章用动态规划解决）。

面试题

设计一个栈，除了 push、pop、top 以外，还能在 O(1) 时间里返回当前栈中的最小值。

看要点

再开一个辅助栈 min：push(x) 时，若 min 为空或 x ≤ min 的栈顶，把 x 也压进 min；pop 时若弹出的值等于 min 的栈顶，min 也弹一次。getMin 返回 min 的栈顶。注意比较用 ≤，否则重复的最小值会出错。另一种做法是每个元素和“压入时的当前最小值”成对存放，空间多一倍但更简单。

1, 2, 3 依次入栈，不可能的出栈序列是？

  1. 1 2 3
  2. 2 1 3
  3. 3 1 2
  4. 3 2 1

3 先出时 1、2 都在栈里，2 在上面，接下来只能出 2。

1, 2, 3, 4 依次入栈，一共有几种不同的出栈序列？

卡特兰数 C₄ = C(8,4)/5 = 70/5 = 14。

共享栈（数组下标 0..MAX−1，两栈分别从两端往中间长），栈满的条件是？

  1. top0 == top1
  2. top1 − top0 == 1
  3. top0 == MAX − 1

两个栈顶相邻时就没有空位了。

a + b × c − d 的后缀表达式是？（不写空格也行）

× 先算：a b c × + d −。

后缀表达式 2 3 4 × + 的值是？

3 × 4 = 12，2 + 12 = 14。

栈式虚拟机

后缀表达式的求值办法，正是很多虚拟机执行代码的办法。CPython 把源码编译成字节码，字节码在一个“求值栈”上工作：

看 Python 的字节码5 分钟
import dis
def f(a, b, c):
    return a + b * c
dis.dis(f)

会看到大致这样的指令（名字随版本略有不同）：LOAD_FAST a、LOAD_FAST b、LOAD_FAST c、BINARY_OP *、BINARY_OP +、RETURN_VALUE。这就是后缀表达式 a b c × +：三个数压栈，乘法弹两个压一个，加法再弹两个压一个。

JVM 和 WebAssembly 也是栈式的；Lua 和安卓的 Dalvik 是寄存器式的。栈式的指令短（不用写操作数在哪个寄存器），编译器好写；寄存器式的指令条数少，解释执行更快。真实处理器（《地基》第十四章）都是寄存器式的。

单调栈

面试题：给一列数，对每个数求它右边第一个比它大的数。笨办法 O(n²)。单调栈 O(n)：从左往右扫，栈里存“还没找到答案的下标”，并保持对应的值从栈底到栈顶递减；新来的数 x 比栈顶大，就说明栈顶的答案是 x，弹出，继续比，直到不比栈顶大，再把 x 的下标压栈。每个下标最多进出栈一次，所以是 O(n)。

def next_greater(a):
    ans = [-1] * len(a)
    st = []                       # 存下标，对应的值从底到顶递减
    for i, x in enumerate(a):
        while st and a[st[-1]] < x:
            ans[st.pop()] = x
        st.append(i)
    return ans

print(next_greater([2, 7, 3, 5, 4, 6, 8]))   # [7, 8, 5, 6, 6, 8, -1]

“每日温度”“柱状图中最大的矩形”“接雨水”都是这一类。
