第一层 · 入门要会：二叉搜索树（第十章）约 30 分钟

两边一样高

上一章看到：搜索树如果歪成一根棍，找东西就和一个一个看一样慢。我们希望它一直匀称：每个结点左边那一片和右边那一片，高度差不多。这叫平衡。

1962 年，两位苏联数学家阿杰尔松-韦利斯基和兰迪斯想出了第一种会自己保持平衡的搜索树，用他们名字的头一个字母，叫 AVL 树。规矩是：每个结点左右两边的高度，最多差 1。

歪了就转一下

每插进一个新数，就从它往上一个一个看：有没有哪个结点，左右两边的高度差变成了 2？有，就在那里做一次旋转。

旋转像跷跷板：一边太重了，就把这一边的那个孩子提上来当“爸爸”，原来的爸爸降下去当它的孩子。神奇的是，转完以后，左小右大的规矩一点没坏，树却矮了一层。

例子：依次插 1、2、3。插完 3 以后，1 的右边高 2、左边高 0，歪了。把 2 提上来：2 当根，1 当它的左孩子，3 当它的右孩子。1 < 2 < 3，规矩没坏，树从 3 层变成 2 层。

平衡因子和四种调整

结点的平衡因子 = 左子树高度 − 右子树高度，AVL 树里只能是 −1、0、1。插入后，从新结点往上找到第一个平衡因子绝对值为 2 的结点 A，以 A 为根的子树叫最小不平衡子树，只调整它就够了（调整后它的高度恢复成插入前，上面的结点也就都平衡了）。按新结点插在 A 的哪一边分四种：

类型新结点插在调整
LLA 的左孩子 B 的左子树右旋一次：B 上升为根，A 成为 B 的右孩子，B 原来的右子树挂到 A 的左边
RRA 的右孩子 B 的右子树左旋一次（与 LL 对称）
LRA 的左孩子 B 的右子树（B 的右孩子 C）先对 B 左旋，再对 A 右旋：C 升为根，B、A 分别成为 C 的左、右孩子
RLA 的右孩子 B 的左子树（B 的左孩子 C）先对 B 右旋，再对 A 左旋：C 升为根

记法：LR 和 RL 的结果，都是“孙子”C 升到最上面，C 原来的左子树给了左边那个、右子树给了右边那个。

typedef struct N { int key, h; struct N *l, *r; } N;
int H(N *p) { return p ? p->h : 0; }
void upd(N *p) { p->h = 1 + (H(p->l) > H(p->r) ? H(p->l) : H(p->r)); }
N *rotR(N *a) { N *b = a->l; a->l = b->r; b->r = a; upd(a); upd(b); return b; }
N *rotL(N *a) { N *b = a->r; a->r = b->l; b->l = a; upd(a); upd(b); return b; }
N *insert(N *p, int k) {
    if (!p) { p = calloc(1, sizeof(N)); p->key = k; p->h = 1; return p; }
    if (k < p->key) p->l = insert(p->l, k); else if (k > p->key) p->r = insert(p->r, k); else return p;
    upd(p);
    int bf = H(p->l) - H(p->r);
    if (bf == 2)  { if (k > p->l->key) p->l = rotL(p->l); return rotR(p); }   /* LR 先左旋；LL 直接右旋 */
    if (bf == -2) { if (k < p->r->key) p->r = rotR(p->r); return rotL(p); }   /* RL 先右旋；RR 直接左旋 */
    return p;
}

删除时可能要一路向上调整多次（最多 O(log n) 次旋转），插入最多调整一处。

最少有几个结点

设高度为 h 的 AVL 树最少有 N(h) 个结点：最“瘦”的树，根的一边高 h − 1、另一边高 h − 2，都要最瘦，所以 N(h) = N(h−1) + N(h−2) + 1，N(0) = 0，N(1) = 1：1, 2, 4, 7, 12, 20, 33, 54……（和斐波那契数只差 1：N(h) = F(h+2) − 1）。反过来，n 个结点的 AVL 树高度不超过约 1.44 log₂n，查找 O(log n)。

（1）依次插入 20, 10, 30, 5, 15, 12 构造 AVL 树，插入 12 时发生哪种不平衡？画出调整后的树。（2）高度为 6 的 AVL 树最少有几个结点？所有非叶结点的平衡因子都是 1 时，这棵树最少有几个结点？

看解答

（1）插完前五个：20 为根，10（左）、30（右），5、15 是 10 的孩子。插 12：12 < 20 → 10，> 10 → 15，< 15 → 15 的左。往上看：15 的因子 1，10 的因子 1 − 2 = −1，20 的因子 3 − 1 = 2，最小不平衡子树根是 20；12 插在 20 的左孩子 10 的右子树里：LR。C 是 15：15 升为根，10 成为左孩子（10 保留左孩子 5，并接过 15 原来的左子树 12 作右孩子），20 成为右孩子（右孩子 30）。结果：15（10（5，12），20（—，30））。

（2）N(6) = 20。平衡因子全是 1（或 0 只出现在叶子）的就是最瘦的 AVL 树本身，也是 20 个。

红黑树

408 从近年起考红黑树的基本性质。红黑树是一棵二叉搜索树，每个结点是红或黑，满足五条：

  1. 每个结点是红色或黑色。
  2. 根是黑色。
  3. 叶结点（虚构的外部结点，即空指针 NIL）都是黑色。
  4. 红结点的两个孩子都是黑色（不能有两个相连的红结点）。
  5. 从任一结点到它下面每个 NIL 的路径上，黑结点个数相同。

从某结点出发（不含它本身）到 NIL 路径上的黑结点数叫它的黑高 bh。由性质 4、5：从根到 NIL 的最长路径（红黑相间）不超过最短路径（全黑）的两倍；n 个内部结点的红黑树高度 ≤ 2 log₂(n + 1)。红黑树只是“大致平衡”，所以插入删除时的旋转次数少：插入最多 2 次旋转，删除最多 3 次；其余调整只是改颜色。新插入的结点一律先涂红（不破坏性质 5），再按叔叔结点的颜色分情况：叔叔红，就把父亲和叔叔染黑、爷爷染红，问题上移；叔叔黑，就像 AVL 一样旋转一次或两次再改色。

AVL 树红黑树
平衡程度严格：左右高度差 ≤ 1大致：最长路径 ≤ 2 × 最短
查找略快（树更矮）略慢
插入删除可能多次旋转旋转次数少，常数小
常用在查找多、改动少标准库的有序容器、内核

高度为 5 的 AVL 树最少有几个结点？

N(5) = N(4) + N(3) + 1 = 7 + 4 + 1 = 12。

新结点插在最小不平衡子树根 A 的左孩子的右子树上，应做？

  1. LL 右旋
  2. RR 左旋
  3. LR 先左旋后右旋

左孩子的右子树：LR。

红黑树中，新插入的结点先涂成什么颜色？

  1. 黑
  2. 红

涂红不改变黑高，只可能违反“不能连红”。

红黑树中，根到叶子的最长路径和最短路径的关系是？

  1. 最长 ≤ 2 × 最短
  2. 相差不超过 1
  3. 没有关系

最短全黑，最长红黑相间。

一棵 AVL 树一定是红黑树吗？（能不能给每个结点涂上合适的颜色）

  1. 能
  2. 不一定

能。AVL 树总可以涂成合法的红黑树（经典结论）；反过来红黑树不一定是 AVL 树。

来历

红黑树源于 1972 年拜尔提出的“对称二叉 B 树”，1978 年吉巴斯和塞奇威克给它涂上了红黑两色，名字就这样来了。它其实是 2-3-4 树（第十五章的 B 树的一种）的二叉表示：一个黑结点加上它的红孩子，合起来就是 B 树的一个大结点。2008 年塞奇威克又提出“左倾红黑树”，只允许红链接朝左，代码短了很多，是教学里常用的版本。

Linux 内核

Linux 内核的 lib/rbtree.c 被大量使用：完全公平调度器 CFS 按“已经跑了多久”把进程挂在红黑树上，每次挑最左边（跑得最少）的那个（《地基》第二十六章）；进程的内存区域（mmap 出来的一段段虚拟地址，《地基》第二十七章）、高精度定时器、epoll 管理的文件描述符，也都用红黑树。这里用的是第三章说过的“侵入式”写法：rb_node 嵌在各种结构体里。

为什么数据库不用它

平衡二叉树一个结点只放一个关键字，一百万个数要二十层。在内存里二十次比较很快，可如果树放在硬盘上，每走一层就要读一次硬盘，二十次读盘就太慢了（《地基》第十六章的存储层次：硬盘比内存慢几个数量级）。所以放在硬盘上的索引，要让每个结点装下成百上千个关键字，树只有三四层高：这就是第十五章的 B 树和 B+ 树。
