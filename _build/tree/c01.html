第一层 · 入门要会：列表和字典、树（第八章）约 30 分钟

点和线

方格岛上有六个地方：家、湖边、石山、沙滩、树林、码头。有的地方之间有小路，有的没有。把每个地方画成一个点，有路就连一条线，就得到一张图。

树也是一种图，只是规矩多：有一个根，每个结点只有一个爸爸，没有圈。图没有这些规矩：谁都可以和谁连，可以绕成圈，也可以分成几块互不相连。

你见过的图

封面的七座桥就是一张图：四块地是点，七座桥是线。地铁图、班里谁和谁是好朋友、网页之间的链接，都是图。《地基》第三十章的网络，一台台电脑和路由器连成的，也是一张图。

几种图

  • 无向图：线没有方向，A 能到 B，B 就能到 A。岛上的小路。
  • 有向图：线有方向，画成箭头。单行道、传送门（只能从这头进、那头出）、“我关注了你，你没关注我”。
  • 带权图：每条线上写一个数，比如路有多长、要走几步。

一个点连着几条线，叫这个点的度。封面上的“岛”连着 5 座桥，度是 5。

怎样存进电脑：两种办法

办法一：名单（邻接表）。每个点后面跟一串名单，写着它连着谁：

家   → 湖边 4，石山 3，树林 5
湖边 → 家 4，沙滩 6
石山 → 家 3，树林 2，码头 9
……

办法二：表格（邻接矩阵）。画一张方表，行和列都是这六个地方；第 i 行第 j 列写着“i 到 j 的路有多长”，没有路就写 0。

名单省地方：只写真有的路。表格查起来快：“家和码头之间有没有路？”看一格就知道。地方很多、路很少的时候（大多数真实的图都这样），用名单；地方少、路很多的时候，用表格。

第二层 · 本科对照 408：图的基本概念、图的存储约 55 分钟简单图、完全图、子图、连通、强连通、生成树和生成森林、度和握手定理、路径和回路；邻接矩阵、邻接表、十字链表、邻接多重表；几道边数的计算题。

基本概念

  • 图 G = (V, E)，|V| = n 个顶点、|E| = e 条边；408 讨论的都是简单图（无重边、无自环）。线性表可以是空表、树可以是空树，但图的顶点集不能为空（边集可以）。
  • 完全图：无向完全图有 n(n − 1)/2 条边；有向完全图有 n(n − 1) 条弧。
  • 连通（无向）：任意两点之间有路径。极大连通子图叫连通分量。强连通（有向）：任意两点 u、v 之间，u 到 v、v 到 u 都有路径；极大的叫强连通分量。
  • 生成树：连通图的极小连通子图，包含全部 n 个顶点、恰好 n − 1 条边；多一条边就有回路，少一条就不连通。非连通图的各分量的生成树组成生成森林。
  • 度：无向图中所有顶点的度之和 = 2e（握手定理）；有向图中入度之和 = 出度之和 = e。
  • 路径长度是边数；第一个和最后一个顶点相同的叫回路；顶点不重复的叫简单路径。n 个顶点的图，边数大于 n − 1 就一定有回路。
典型题 · 原创

（1）无向图有 16 条边，度为 4 的顶点 3 个、度为 3 的顶点 4 个，其余顶点的度都小于 3，问图至少有几个顶点？（2）n = 8 个顶点的无向图，至少要几条边才能保证它一定连通（不管边怎么连）？（3）有向图有 n 个顶点，要保证它是强连通的，至少要几条弧？

看解答

（1）度之和 = 32；已知 3 × 4 + 4 × 3 = 24，剩下 8 要由度 ≤ 2 的顶点提供，每个至多 2，至少 4 个。共 3 + 4 + 4 = 11 个。

（2）最坏情况：7 个顶点组成完全图（21 条边），第 8 个孤立。再加 1 条就一定连通：(n − 1)(n − 2)/2 + 1 = 22。

（3）n 条，连成一个有向环。（n 个顶点的无向图要连通至少 n − 1 条边，这是另一个问法。）

  • 邻接矩阵：无向图的矩阵对称，可以只存上（或下）三角（第二章的压缩存储）；第 i 行非零元个数是顶点 i 的度（有向图：行是出度，列是入度）。若 A 是邻接矩阵（0/1），Ak 的 [i][j] 元素是从 i 到 j 长度为 k 的路径条数。
  • 邻接表：顶点表（数组）+ 每个顶点一条边表（链表）。有向图的邻接表求出度容易、求入度要扫全部，可以另建逆邻接表。邻接表不唯一（边表里的顺序随意），所以由邻接表得到的遍历序列也不唯一。
  • 十字链表：有向图的每条弧是一个结点，同时挂在“弧尾的出弧链”和“弧头的入弧链”上。
  • 邻接多重表：无向图的每条边只用一个结点，同时挂在两个端点的链上（邻接表里每条边要存两次）。

CSR

邻接表用链表，每条边一个结点、一个指针，又散又慢（第三章第三层）。真正处理大图的程序常用 CSR（压缩稀疏行）：把所有顶点的邻居一个接一个排进一个大数组 adj，再用一个长 n + 1 的数组 start 记着第 i 个顶点的邻居从 adj 的哪里开始。顶点 i 的邻居就是 adj[start[i] : start[i+1]]，连续存放、对缓存友好。缺点是加边删边很贵，适合“建好以后只读”的图。科学计算里的稀疏矩阵、图神经网络框架都用它。

def to_csr(n, edges):
    deg = [0] * n
    for a, b in edges: deg[a] += 1
    start = [0] * (n + 1)
    for i in range(n): start[i + 1] = start[i] + deg[i]
    adj, fill = [0] * len(edges), start[:-1]
    for a, b in edges:
        adj[fill[a]] = b; fill[a] += 1
    return start, adj

图论的开端，和今天的图

欧拉 1736 年关于七座桥的文章被看作图论的开端（封面装置）。今天，谷歌早年的网页排名算法把整个网络看成一张有向图：被很多重要网页链接的网页更重要，是一个在图上反复迭代的计算。社交网络推荐“你可能认识的人”、导航软件、芯片布线、蛋白质相互作用，都是图上的问题。专门存图的“图数据库”（如 Neo4j）让“朋友的朋友的朋友”这类查询变得直接。
