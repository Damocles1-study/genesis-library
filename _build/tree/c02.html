第一层 · 入门要会：队列和倒水（第五章）、栈（第四章）、图（第十六章）约 35 分钟

走遍一张图

从一个点出发，把能走到的点都走一遍，叫图的遍历。和树的遍历（第九章）不一样的是：图里可能有圈，绕着绕着会回到走过的地方。所以要做记号：走过的点记下来，下次碰到就不再走。

广度优先：一圈一圈往外

第五章倒水时已经见过它了：先看离起点一步远的所有点，再看两步远的，再看三步远的……用一个队列排队，先看到的先往外扩。

因为是一圈一圈往外找的，第一次碰到目标时，走的一定是步数最少的路。

深度优先：一条路走到黑

走迷宫的老办法：看到一条没走过的路就走进去，一直往前走；走到死路，就退回上一个岔口，换一条没走过的路。用一个栈记着回去的路（第七章的油漆桶用的就是这个办法）。

深度优先也能走遍所有的点，但它找到目标时走的路，不一定最短。

把路画出来

找到了目标，可是怎么知道路是怎么走的？办法是：每走到一个新的格子，都记一下“我是从哪一格走过来的”。找到目标以后，从目标开始，顺着“从哪来”一格一格倒着走回起点，再把这串格子反过来，就是路。

第二层 · 本科对照 408：图的遍历及其应用约 55 分钟BFS 和 DFS 的代码；在邻接表和邻接矩阵上的复杂度；广度优先生成树、深度优先生成树；遍历序列不唯一；无权单源最短路径；连通分量；有向图判环。

代码和复杂度

int visited[MAXV];
void BFS(Graph *G, int v) {                 /* 邻接表 */
    int Q[MAXV], f = 0, r = 0;
    visit(v); visited[v] = 1; Q[r++] = v;
    while (f < r) {
        int u = Q[f++];
        for (ArcNode *p = G->adj[u].first; p; p = p->next)
            if (!visited[p->to]) { visit(p->to); visited[p->to] = 1; Q[r++] = p->to; }
    }
}
void DFS(Graph *G, int v) {
    visit(v); visited[v] = 1;
    for (ArcNode *p = G->adj[v].first; p; p = p->next)
        if (!visited[p->to]) DFS(G, p->to);
}
void traverse(Graph *G) {                   /* 非连通图：每个没访问过的顶点开一次 */
    for (int v = 0; v < G->n; v++) visited[v] = 0;
    for (int v = 0; v < G->n; v++) if (!visited[v]) BFS(G, v);   /* 调用次数 = 连通分量个数 */
}

BFS 是在入队时就标记 visited，否则同一个顶点可能被多次入队。复杂度：邻接表 O(n + e)，邻接矩阵 O(n²)（每个顶点要扫一整行）。空间：BFS 的队列、DFS 的递归栈，最坏都是 O(n)。

遍历时走过的边构成广度优先生成树和深度优先生成树（非连通时是生成森林）。邻接矩阵是唯一的，所以给定起点，基于矩阵的遍历序列和生成树唯一；邻接表不唯一，所以基于它的遍历序列和生成树都不唯一。

典型题 · 原创

无向图的顶点为 1—7，边为 (1,2)(1,3)(2,4)(2,5)(3,6)(5,6)(6,7)。邻接表中每个顶点的边表按顶点编号从小到大排列。（1）从顶点 1 出发，写出 BFS 和 DFS 序列。（2）BFS 生成树的高度是多少（根为第 1 层）？（3）若删去边 (5,6)，从 1 出发的 DFS 序列是什么？

看解答

（1）BFS：1，然后 2、3，然后 2 的邻居 4、5，3 的邻居 6，然后 6 的邻居 7：1 2 3 4 5 6 7。DFS：1 → 2 → 4（4 没有未访问邻居，回到 2）→ 5 → 6（5 的邻居 6）→ 3（6 的邻居按编号：3 未访问）→ 回到 6 → 7。序列 1 2 4 5 6 3 7。

（2）BFS 树：1；2、3；4、5、6；7。高度 4。

（3）1 → 2 → 4 → 回 2 → 5（5 没有其他邻居）→ 回 1 → 3 → 6 → 7：1 2 4 5 3 6 7。

几个应用

  • 无权图的单源最短路径：BFS，d[v] = d[u] + 1，第一次被发现时就是最短。
  • 连通分量个数：外层循环里调用 BFS 或 DFS 的次数。
  • 判断顶点 i 到 j 是否有路径：从 i 遍历，看 j 是否被访问。
  • 有向图判环：DFS 时给顶点三种颜色：白（未访问）、灰（在递归栈里）、黑（已完成）。若沿边走到一个灰色顶点，就有环。也可以用拓扑排序判断（第二十章）。无向图判环：DFS 时遇到一个已访问、且不是父结点的邻居，就有环；或者看边数是否 ≥ n（连通时）。
面试题

“单词接龙”：给一个起始词、一个目标词和一个词表，每次只能改一个字母，且中间的词都要在词表里，最少几步变到目标？

看要点

把每个词看成图的顶点，只差一个字母的两个词之间有边，求无权最短路径：BFS。建图不必两两比较：对每个词，把每个位置分别换成通配符（如 h*t），同一个模式下的词互为邻居。词表很大时可以用双向 BFS（第三层），从两头同时扩，相遇就停。

第三层 · 深入搜索的变种约 20 分钟双向 BFS 为什么快；迭代加深：用深度优先的内存做广度优先的事；DFS 的时间戳和树边、后向边、前向边、横叉边；强连通分量。

双向 BFS 和迭代加深

每个点平均有 b 个邻居、目标在 d 步之外时，BFS 大约要看 bd 个点。从起点和终点同时各扩 d/2 步，只要看约 2bd/2 个点：b = 10、d = 6 时，从一百万降到两千。这是社交网络里算“你和他隔着几个人”的办法。

BFS 要把一整圈都放进队列，内存可能爆掉；DFS 省内存，但找到的不是最短。迭代加深：先做只许走 1 步的 DFS，再做只许走 2 步的……重复的工作看起来很多，但最后一圈占了绝大部分，总代价和 BFS 同一个量级，内存却只要 O(d)。下棋程序常用它。

DFS 的时间戳

给每个顶点记下“第一次到达”和“完成”的时间。有向图的边按此分四类：树边、后向边（指向祖先，说明有环）、前向边（指向后代）、横叉边（指向已完成的别的分支）。塔扬 1972 年用 DFS 在 O(n + e) 时间内求出全部强连通分量，这类线性时间的图算法几乎都建立在 DFS 的这些性质上。

出处与延伸

  • R. E. Tarjan, “Depth-First Search and Linear Graph Algorithms”, SIAM J. Computing, 1972。
  • R. E. Korf, “Depth-first iterative-deepening”, Artificial Intelligence, 1985。
