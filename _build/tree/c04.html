第一层 · 入门要会：图（第十六章）、并查集（第十四章）约 30 分钟

连起来，又不多修

六个地方，要让每个地方都能走到别的任何地方。最少要修几条路？5 条：连着 n 个点又没有圈，正好 n − 1 条线，这样的一组线叫生成树（它是一棵树：第八章说过，树没有圈）。多修一条就有圈了，圈上总有一条是多余的；少修一条就断开了。

可以修的路有很多种组法。在所有组法里，路的总长最短的那一种，叫最小生成树。

克鲁斯卡尔：从最短的挑起

  1. 把所有能修的路按长度从短到长排好。
  2. 从最短的开始，一条一条看：这条路的两头已经连着了吗？
    • 没连着：修！
    • 已经连着（修了就会成圈）：跳过。
  3. 修够 n − 1 条就停。

“两头连没连着”怎么判断？第十四章的并查集正好干这个：找两头的队长，一样就是连着。

普里姆：从一个村子长出去

另一种办法：先选一个地方当起点。每一步，在“已经连上的地方”和“还没连上的地方”之间的所有路里，挑最短的一条修上，把那个新地方拉进来。重复，直到所有地方都连上。像一棵树从一个点慢慢长大。

两种办法挑的顺序不一样，但修出来的总长一样短。

第二层 · 本科对照 408：最小生成树（普里姆、克鲁斯卡尔）约 50 分钟最小生成树的性质；普里姆 O(n²)；克鲁斯卡尔 O(e log e)；稠密图和稀疏图；唯一性的判断；常见的选择题陷阱。

性质

  • 最小生成树不一定唯一；当图中各边权值互不相等时唯一。权值有相同的也可能唯一。
  • 边的权值之和总是唯一的（最小值只有一个）。
  • 边数 = 顶点数 − 1。
  • MST 性质（切分性质）：把顶点分成两部分 U 和 V − U，横跨两部分的边里权值最小的那条 (u, v)，一定存在一棵包含它的最小生成树。普里姆和克鲁斯卡尔的正确性都基于它。

两种算法

int prim(int G[][N], int n) {             /* 邻接矩阵；lowcost[v] = v 到已选集合的最小边权 */
    int lowcost[N], in[N] = {0}, total = 0;
    in[0] = 1;
    for (int v = 0; v < n; v++) lowcost[v] = G[0][v];
    for (int k = 1; k < n; k++) {
        int u = -1;
        for (int v = 0; v < n; v++) if (!in[v] && (u == -1 || lowcost[v] < lowcost[u])) u = v;
        in[u] = 1; total += lowcost[u];
        for (int v = 0; v < n; v++) if (!in[v] && G[u][v] < lowcost[v]) lowcost[v] = G[u][v];
    }
    return total;
}
普里姆克鲁斯卡尔
思路从一个顶点长出去，每次加最近的顶点边按权排序，不成环就加
复杂度O(n²)（与边数无关）；用堆 O(e log n)O(e log e)（排序为主，加并查集）
适合稠密图稀疏图

注意普里姆的“lowcost”和迪杰斯特拉的“dist”长得很像，区别在更新式：普里姆是 lowcost[v] = min(lowcost[v], G[u][v])（到集合的距离），迪杰斯特拉是 dist[v] = min(dist[v], dist[u] + G[u][v])（到起点的距离）。

典型题 · 原创

无向带权图顶点 A—F，边：AB 6、AC 1、AD 5、BC 5、BE 3、CD 5、CE 6、CF 4、DF 2、EF 6。（1）用普里姆从 A 出发，依次加入的边是？总权值？（2）用克鲁斯卡尔，依次加入的边是？（3）这棵最小生成树唯一吗？

看解答

（1）A 的边中 AC 1 最小，加 C；集合 {A,C} 的外连边：AB 6、AD 5、BC 5、CD 5、CE 6、CF 4 → CF 4，加 F；再看 DF 2 → 加 D；剩 B、E：AB 6、BC 5、CE 6、EF 6、（D 的边 AD、CD 两头都在集合里）→ BC 5，加 B；最后 BE 3 → 加 E。依次 AC、CF、DF、BC、BE，总权 1+4+2+5+3 = 15。

（2）按权排序：AC 1、DF 2、BE 3、CF 4，再 5 的有 AD、BC、CD：AD 两头 A、D 已连通（A-C-F-D），跳过；BC 连接 {A,C,D,F} 和 {B,E}，加入；CD 已连通跳过。依次 AC、DF、BE、CF、BC，总权 15。

（3）唯一。权为 5 的三条边里，只有 BC 能连接两部分，AD 和 CD 都会成环；其余边权互不相同，没有别的选择。

面试题

给 n 个城市的坐标，修路的费用是两城之间的欧几里得距离，求连通所有城市的最小费用。n = 105 时怎样做？

看要点

完全图有 n²/2 ≈ 5 × 109 条边，不能全建。n 不大（几千）时用 O(n²) 的普里姆，不用显式存边。n 很大时利用几何性质：欧几里得最小生成树一定是德劳内三角剖分的子图，剖分只有 O(n) 条边，再跑克鲁斯卡尔，总共 O(n log n)。面试里说出“完全图别建边，用 O(n²) 普里姆”通常就够了。

稠密图求最小生成树，更适合哪种算法？

  1. 普里姆
  2. 克鲁斯卡尔

普里姆 O(n²) 与边数无关。

克鲁斯卡尔的时间复杂度主要取决于？

  1. 顶点数的平方
  2. 边的排序 O(e log e)

排序之后每条边一次并查集操作。

下列说法正确的是？

  1. 最小生成树一定唯一
  2. 有相同权值的边，最小生成树一定不唯一
  3. 最小生成树的总权值唯一

树可能不唯一，总权值唯一。

典型题中，最小生成树的总权值是？

1 + 2 + 3 + 4 + 5 = 15。

普里姆每加入一个顶点 u，更新 lowcost[v] 用的是？

  1. lowcost[u] + G[u][v]
  2. G[u][v]

到集合的距离，不累加。累加的是迪杰斯特拉。

第三层 · 深入来历和用处约 20 分钟博鲁夫卡 1926 年为摩拉维亚的电网设计的算法；普里姆、克鲁斯卡尔、贾尼克；随机迷宫；单链接聚类。

为电网而生

最早的最小生成树算法是捷克数学家博鲁夫卡 1926 年为摩拉维亚地区设计电力网络时提出的：每一轮，每个连通块各自挑出连向外面的最短边，同时加上，块的个数至少减半，O(e log n)。1930 年贾尼克提出了后来被称为“普里姆算法”的办法（普里姆 1957 年、迪杰斯特拉 1959 年各自重新发现），1956 年克鲁斯卡尔提出了按边排序的办法。博鲁夫卡的算法因为每个块可以同时挑边，今天在并行计算里又重新流行。

迷宫和聚类

给方格地图上每两个相邻格子之间的“墙”随机一个权值，求最小生成树，把树边上的墙拆掉：得到的就是一个“完美迷宫”（任意两格之间恰好一条路）。用随机化的克鲁斯卡尔或普里姆，能生成风格不同的迷宫。数据分析里的单链接聚类：先求最小生成树，再删掉最长的 k − 1 条边，剩下的 k 块就是 k 个簇。
