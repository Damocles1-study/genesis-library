第一层 · 入门要会：数组（第二章）、两层循环（第一章）约 30 分钟

插入：整理扑克牌

手里的牌已经排好了。摸到一张新牌，从右往左看，比它大的都往右挪一格，直到碰到不比它大的，把新牌放进空出来的位置。每张牌都这样做一遍，整手牌就排好了。这叫插入排序。

如果牌本来就差不多排好了，每张新牌几乎不用挪，插入排序就特别快。

冒泡：大的往后冒

从左往右，每两个挨着的比一比，左边的大就交换。走完一趟，最大的那个就像水里的气泡一样“冒”到了最后。再走一趟，第二大的冒到倒数第二……一趟都没交换，就说明已经排好了，可以停。这叫冒泡排序。

选择：每次挑最小的

从所有的里挑出最小的，放到第 1 个位置；从剩下的里挑最小的，放到第 2 个位置……这叫选择排序。它不管数据长什么样，每一趟都要把剩下的全看一遍。

四种简单排序

选一种排序和一种数据，点“走一步”或“自己跑”。黄色是正在比的两个，红色是被挪动的，绿色是已经排在最终位置的。看看各比了多少次、挪了多少次。“希尔”是第二层的。

稳定不稳定

排行榜上，豆子和小米都是 35 步，豆子先完工，排在小米前面。排完以后，豆子还在小米前面吗？如果一样大的两个，排完以后先后顺序不变，这种排序就叫稳定的。

插入和冒泡是稳定的：它们只在“左边比右边大”的时候才交换，一样大的不换。选择排序不稳定：它把最小的直接换到前面，可能把一个一样大的从前面换到后面去了。主线第 25 步里，选择排序就把豆子和小米的先后换了。

为什么要稳定

在表格软件里，先按“名字”排一次，再按“分数”排一次：如果第二次排序是稳定的，分数一样的人仍然按名字排着。很多时候我们要按好几个条件排，稳定的排序让这件事变得简单。

第二层 · 本科对照 408：插入排序、交换排序（冒泡）、选择排序（简单选择）约 55 分钟直接插入、折半插入、希尔排序；冒泡排序的提前结束；简单选择排序；每一趟结果的手写；最好最坏和平均复杂度、空间和稳定性；“每趟确定一个元素最终位置”的判断。

插入类

void insert_sort(int a[], int n) {                 /* 直接插入 */
    for (int i = 1; i < n; i++) {
        int x = a[i], j = i - 1;
        while (j >= 0 && a[j] > x) { a[j + 1] = a[j]; j--; }
        a[j + 1] = x;
    }
}
void shell_sort(int a[], int n) {                  /* 希尔：对每个间隔做插入排序 */
    for (int d = n / 2; d >= 1; d /= 2)
        for (int i = d; i < n; i++) {
            int x = a[i], j = i - d;
            while (j >= 0 && a[j] > x) { a[j + d] = a[j]; j -= d; }
            a[j + d] = x;
        }
}
  • 直接插入：最好（已有序）比较 n − 1 次、O(n)；最坏（逆序）O(n²)；平均 O(n²)；稳定。适用于顺序表和链表。
  • 折半插入：用二分找插入位置，比较次数降到 O(n log n)，但元素移动次数不变，总体仍 O(n²)；稳定。只适用于顺序表。
  • 希尔排序：按间隔 d 分组，组内插入排序，d 逐步缩小到 1。时间依赖于间隔序列，n 在某个范围内约 O(n1.3)，最坏 O(n²)；不稳定（相同元素可能被分到不同组）；只适用于顺序表。

冒泡和简单选择

  • 冒泡：每趟把最大（或最小）的元素放到最终位置；某一趟没有交换就结束。最好 O(n)（一趟），最坏、平均 O(n²)；稳定。
  • 简单选择：比较次数总是 n(n − 1)/2，与初始序列无关；移动次数最多 3(n − 1)（每趟一次交换）；O(n²)；不稳定。例子：2, 2', 1，第一趟把 1 和 2 交换，得 1, 2', 2。
典型题 · 原创

对序列 {38, 12, 61, 27, 50, 9, 44, 33} 升序排序。（1）直接插入排序进行两趟以后的结果；（2）冒泡排序（从前往后、大的往后）第一趟以后；（3）简单选择排序第一趟以后；（4）希尔排序第一趟（d = 4）以后。

看解答

（1）第一趟插入 12：12, 38；第二趟插入 61，不动：{12, 38, 61, 27, 50, 9, 44, 33}。

（2）38↔12，38 < 61，61↔27，61↔50，61↔9，61↔44，61↔33：{12, 38, 27, 50, 9, 44, 33, 61}。

（3）最小的 9 和第一个 38 交换：{9, 12, 61, 27, 50, 38, 44, 33}。

（4）分组 (38, 50)、(12, 9)、(61, 44)、(27, 33)，组内排好：{38, 9, 44, 27, 50, 12, 61, 33}。

面试题

数组里每个元素离它排好以后的位置最多差 k（k 远小于 n），怎样排得快？

看要点

插入排序：每个元素最多往前挪 k 次，O(nk)。更快：维护一个大小为 k + 1 的小根堆（第十二章），每次弹出堆顶放到结果里、再放进下一个元素，O(n log k)。

下列排序中不稳定的是？

  1. 直接插入
  2. 冒泡
  3. 简单选择

选择排序的远距离交换会打乱相同元素的次序。

8 个元素做简单选择排序，一共比较几次？

n(n−1)/2 = 28，与初始序列无关。

  1. n − 1
  2. n(n−1)/2
  3. 0

每个元素和前一个比一次就停。

  1. 移动次数
  2. 比较次数

只是找位置变快，挪动一样多。

第三层 · 深入小数组和间隔序列约 15 分钟为什么快速排序和 Timsort 在小段上改用插入排序；希尔 1959 年的论文和后来的间隔序列；排序网络。

小数组用插入排序：插入排序常数很小、顺序访问内存、对几乎有序的数据是 O(n)。所以真实的排序函数（C++ 的 introsort、Python 的 Timsort、Java 的双轴快排）在小于十几、几十个元素的小段上都改用插入排序（Timsort 用折半插入）。复杂度表上的 O(n²) 在 n = 16 时并不吃亏。

希尔排序：希尔 1959 年提出时用的是 n/2、n/4……这个序列，最坏 O(n²)。后来人们找到更好的间隔：克努特的 1, 4, 13, 40, …（h = 3h + 1）、塞奇威克的序列（最坏 O(n4/3)）、修拉 2001 年用实验找出的 1, 4, 10, 23, 57, 132, 301, 701。希尔排序到底能有多快，至今没有完全的理论答案。

排序网络：一组固定的“比较交换器”，不管数据是什么都按同样的顺序比较，适合做成硬件电路或在 GPU 上并行（双调排序）。
