    一块一块我的世界创世记 · 指南

    第五部 · 手

    前四部是故事：方块世界从哪里来，红石怎样变成电脑，走出游戏能带走什么，工坊里能做哪些项目。从这一部起，是指南。

    指南和故事不一样。故事可以窝在沙发上读；指南要坐在电脑前面，一边读一边按。每一节都有“马上试一试”，每一章最后有一组“闯关自测”。你不用一口气读完，也不用按顺序读：想瞬移，就翻到指令那一部；找不到截图，就翻到这一部的第三十八章。

    这一部叫“手”，讲怎样把你的 MacBook 摸熟：键盘上那几个怪符号，触控板和鼠标，中文和英文怎么切换，文件放在哪儿，怎样一下子跳过去，还有一个黑底白字、看起来很厉害的“终端”。这些东西学校不教，可是以后不管你是写程序、做视频、还是交作业，天天都要用。

    指南怎么用

    • 工坊卡：难度、多久、要准备什么、要不要大人。
    • 学完这一章，你能……：先看看目标，读完回来对一对。
    • 一步一步：带编号的步骤。黑框里、灰底里的字要一个一个照着打。
    • 小角落：英语角、数学角、编程角、物理角。角落上会写“学过”还是“以后学”：比如“学过 · 三年级”，就是你在学校已经学过；“以后学 · 七年级”是初一才学的，现在先认识一下，到时候你会觉得“我早就见过”。

    • 闯关自测：答错了会告诉你为什么，可以再选。

    做完的任务、过的关、复习台里的单词，都记在这台电脑的浏览器里（不会传到网上）。换一台电脑、换一个浏览器、清掉浏览器的数据，记录就没了。

      自己不干活的键

      你按一下 A，屏幕上就出来一个 a。可是你按一下 shift，什么也不会发生。

      shift 这样的键，单独按没有用，要和别的键一起按。它们的工作是“改一改”别的键：按住 shift 再按 A，出来的就变成大写的 A。这种键叫修饰键，英文叫 modifier key。“修饰”就是打扮、改一改的意思。

      Mac 键盘最下面一排，左边挤着四个修饰键，再加上左边那一列的 shift，一共五个：

      符号名字英文（点一下听）在哪儿一句话
      ⌘命令键command空格键两边，各一个Mac 上用得最多的修饰键，几乎所有快捷键都有它
      ⇧上档键shift左右两边，最长的那两个打大写字母，打数字键上面那排符号
      ⌥选项键optioncommand 外面那个“另一种做法”：按住它，很多菜单会变出隐藏的选项
      ⌃控制键control最左下，fn 右边按住 control 再点一下，等于右键；游戏里按住它是跑
      fn功能键function最左下角，上面还画着一个小地球 🌐按住它，最上面一排才变成 F1—F12

      还有几个常见符号，也顺便认一认：⎋ 是 esc（逃出、取消），⌫ 是 delete（删除），↩ 是 return（回车），⇥ 是 tab（跳格），⇪ 是 caps lock（大写锁定）。

      那朵“花”是从哪儿来的

      1984 年，苹果做第一台 Macintosh 电脑的时候，命令键上本来画的是一个苹果标志。乔布斯不喜欢：菜单里到处都是苹果，太多了。

      负责画图标的设计师苏珊·卡雷翻开一本符号词典，找到了这个四个圈连在一起的图形。在瑞典，它被画在路牌上，意思是“这里有值得一看的地方”。她把它放到了命令键上，一直用到今天。

      参加过那台电脑开发的工程师安迪·赫茨菲尔德，后来把这件事写进了他的回忆文章。

      shift 为什么叫“挪一挪”以后学 · 词源

      shift 的意思是“挪动”。一百多年前的打字机，每根打字杆上刻着两个字母：下面是小写，上面是大写。按住 shift，整个字母架会往上挪一截，打出来的就变成了大写。电脑上没有字母架了，名字却留了下来。

      “大写”英文叫 uppercase，“小写”叫 lowercase。case 是“盒子”：从前印刷工人排字，把大写字母的铅字放在上面那个盒子里，小写的放在下面那个盒子里。upper 是“上面的”，lower 是“下面的”。

      快捷键怎么读、怎么按

      快捷键表上写的 ⇧⌘4，读作“shift command 4”。按的方法只有一条规矩：

      先按住修饰键，再点一下最后那个键，然后一起松开。

      不要三个键一起拍下去，也不要先按 4。就像弹钢琴的和弦：左手先按住，右手再点。按住的时候，修饰键的顺序不要紧，⇧⌘4 和 ⌘⇧4 是一样的。

      Mac 上的快捷键，大多数都长成“⌘ + 一个字母”，而且这个字母常常就是英文单词的头一个字母：

      快捷键做什么那个字母来自
      ⌘C拷贝copy
      ⌘V粘贴V 就在 C 旁边，长得像一个往下插的箭头
      ⌘X剪切（拷贝以后把原来的删掉）X 像一把剪刀
      ⌘Z撤销：退回上一步Z 在键盘最左下，最好按
      ⇧⌘Z重做：撤销多了，再往前走一步
      ⌘A全选all
      ⌘S存储save
      ⌘F查找find
      ⌘N / ⌘T新建窗口 / 新建标签页new / tab
      ⌘W关掉这个窗口或网页window
      ⌘Q退出整个程序quit
      ⌘tab切换到别的程序
      ⌘空格聚焦搜索：找程序、找文件、算算术
      ⌘,打开这个程序的“设置”
      ⌥⌘esc强制退出：程序卡死了的时候用escape：逃出来
      这些键在游戏里能帮你什么
      • 在游戏的聊天框里，⌘V 能把一条长命令粘贴进去，不用一个字母一个字母地打（先在网页或笔记里写好，再 ⌘C 拷贝）。
      • ⌘tab 能从游戏切到浏览器去查维基，查完再切回来。切出去以前，先按 esc 暂停，免得你不在的时候被怪打。
      • 千万别在游戏里按 ⌘Q。Q 在游戏里是“扔东西”，手一滑多按了 ⌘，整个游戏就退出了。要退出，按 esc，选“保存并退出到标题画面”。

      MacBook Air 的键盘

      这是一张 M1 MacBook Air 键盘的示意图（键的大小不完全准）。点任何一个键，看它的名字、英文和用处；上面三个按钮可以只看“Mac 里”或“游戏里”有用的键。点“用真键盘”，再按你电脑上的键，图上同一个键会跳一下。下面的格子是这一章的练习，按对了会自动打勾。

      打开“用真键盘”以后，⌘A、⌘C、⌘V、⌘X、⌘Z、⌘S、⌘F 在这一页里会被拦下来，不会真的执行，可以放心按。⌘W、⌘Q、⌘tab、⌘空格拦不住（它们归 Mac 自己管），⌘W 会关掉这一页，别按。fn 键浏览器收不到。

      三种截图

      截图就是把屏幕上的样子“拍”一张照片存下来。Mac 不用装任何软件，自带三种：

      1. 拍整个屏幕：⇧⌘3。咔嚓一声，屏幕右下角会出现一张小图。
      2. 拍一块地方：⇧⌘4。鼠标变成一个十字，按住拖出一个框，松手就拍好了。拖到一半想反悔，按 esc。
      3. 拍一个窗口：先按 ⇧⌘4，再按一下空格，十字变成一台小相机。把相机移到哪个窗口上，那个窗口就变蓝，点一下就拍下来，连阴影都有。
      4. 截图工具：⇧⌘5。屏幕下面出来一排按钮，能选拍法，还能录屏（录一段视频）。录屏前先问大人，录下来的东西会很占地方。

      拍好的图，默认放在桌面上，名字叫“截屏”加上日期和时间。在任何一种截图快捷键里多按一个 ⌃ control，图就不存成文件，而是放进“剪贴板”，可以直接 ⌘V 粘贴到别处。

      注意：游戏里的截图是另一回事。在游戏里按 fn F2，图存在游戏自己的 screenshots 文件夹里，不在桌面上。第三十八章教你怎样找到它。

      截一张，找到它★
      1. 用 ⇧⌘4 加空格，拍下这个浏览器窗口。
      2. 回到桌面（四根手指在触控板上张开，或者点程序坞里的访达，再点左边的“桌面”），找到那张“截屏……”。
      3. 选中它，按一下空格：这叫“快速查看”，不用打开任何程序就能看一眼。再按一下空格关掉。

      聚焦搜索：一个会算术的搜索框

      按 ⌘空格，屏幕中间会出来一个搜索框，叫聚焦搜索（英文 Spotlight，意思是舞台上的“聚光灯”）。它能干三件事：

      • 打开程序：打“终端”或者“zhongduan”，按回车，终端就开了。比在一堆图标里找快得多。
      • 找文件：打文件名里的几个字，比如“截屏”，你刚才拍的图就出来了。
      • 算算术：打 64*27，不用按回车，下面直接显示 1728。乘号用 *（shift 加 8），除号用 /。
      电脑上的乘号和除号学过 · 二三年级

      电脑键盘上没有 × 和 ÷，于是程序员用 * 当乘号、用 / 当除号。以后学 Python、写表格公式、用计算器程序，都是这样写的。

      试试在聚焦搜索里算：一组方块是 64 个，一个箱子有 27 格，装满一箱是几个？64*27。大箱子是两个箱子拼起来的，64*27*2 呢？第六十一章会专门讲这些数。

      程序卡死了怎么办

      有时候一个程序不动了：点哪儿都没反应，鼠标变成一个转个不停的彩色小球。这时候：

      1. 先等一会儿。数到三十。很多时候它只是在忙，忙完就好了。游戏刚打开一个大世界时，常常要等。
      2. 还不行，就强制退出。按 ⌥⌘esc，出来一个小窗口，列着正在运行的程序。卡住的那个后面会写“未响应”。选中它，点“强制退出”。
      3. 知道代价。强制退出就像突然拔掉电源，没来得及存的东西会丢。游戏每隔几分钟会自动存一次，所以最多丢掉最后几分钟。
      三个快捷键挑战★
      1. 用 ⌘空格 打开“计算器”程序，再用聚焦搜索算一算 64*36（你的物品栏一共 36 格，全装满是多少个？）。
      2. 同时开着浏览器和计算器，用 ⌘tab 在它们之间来回切换。按住 ⌘ 不放，连点 tab，可以在好几个程序里挑。
      3. 在“备忘录”里打一句话，⌘A 全选，⌘C 拷贝，到另一行 ⌘V 粘贴，再 ⌘Z 撤销一次。
      出错了怎么办
      按了快捷键，没反应
      检查按的顺序：先按住修饰键，再点字母。还要看你“在”哪个程序里：快捷键是发给最前面那个窗口的，屏幕最左上角（苹果标志右边）写着的就是它的名字。
      截图找不到
      先看桌面。没有的话按 ⇧⌘5，点“选项”，看“存储位置”被改到了哪儿。游戏里 F2 截的图，看第三十八章。
      按 ⌘空格 出来的是输入法，不是搜索框
      有些电脑把这个键改给了输入法。请大人打开“系统设置”→“键盘”→“键盘快捷键”，看“聚焦”那一项现在是什么键。

      键盘上画着 ⌘ 的那个键叫什么？

      1. option
      2. control
      3. command
      4. shift

      ⌘ 是 command（命令键），在空格键两边各一个。option 是 ⌥，control 是 ⌃，shift 是 ⇧。

      “⇧⌘4”应该怎样按？

      1. 三个键同时拍下去
      2. 先按住 shift 和 command，再点一下 4，然后一起松开
      3. 先按 4，再按 shift，再按 command

      修饰键先按住，最后那个键点一下。像弹和弦：左手按住，右手再点。

      在游戏里，为什么要特别小心 ⌘Q？

      1. Q 是扔东西，多按一个 ⌘ 就会退出整个游戏
      2. 它会删掉存档
      3. 它会把游戏变成英文

      ⌘Q 是 quit，退出程序。正确的退出办法是 esc → “保存并退出到标题画面”。

      在聚焦搜索里打 64*27，会算出多少？（填一个数）

      64 × 27 = 1728，正好是一个装满的箱子：27 格，每格一组 64 个。

      一个程序卡住不动了，你应该先做什么？

      1. 马上按电源键关机
      2. 马上按 ⌥⌘esc 强制退出
      3. 先等一会儿，还不行再强制退出

      很多时候程序只是在忙。强制退出会丢掉没存的东西，所以先等等。关机是最后的办法，而且要问大人。

      “大写字母”的英文是什么？（提示：upper 是“上面的”）

      uppercase。从前排字工人把大写字母放在上面那个盒子（case）里。小写是 lowercase。

      这一章的新词
      修饰键 modifier自己不干活，和别的键一起按，改变那个键的意思。
      快捷键 shortcut一组键，代替用鼠标点好几下菜单。shortcut 本来是“近路”。

        一块地存在哪个文件里

        region 文件夹里的文件名字很怪：r.0.0.mca、r.-1.0.mca……其实这是在说“这一大片地在哪儿”。规则是这样的：

        • 世界切成 16 × 16 格的区块。
        • 32 × 32 个区块，组成一个区域，存成一个 .mca 文件。一个区域是 16 × 32 = 512 格见方。
        • 文件名里的两个数，是区域在 x 方向和 z 方向的编号。r.0.0 管 x 从 0 到 511、z 从 0 到 511 的那一大片；r.-1.0 管 x 从 −512 到 −1。

        算法是：坐标除以 512，再“往小的方向”取整。x = 700，700 ÷ 512 ≈ 1.37，往小取是 1。x = −20，−20 ÷ 512 ≈ −0.04，往小取是 −1（不是 0！）。

        终端是什么

        在电脑还没有窗口、没有鼠标的年代（第二部讲过），人们用电脑就是打一行字、按回车、看它回一行字。今天的 Mac 把这种方式留了下来，装在一个程序里，叫终端（Terminal）。按 ⌘空格，打“终端”，回车，就打开了。

        打开以后，你会看到一行字，最后面有一个闪烁的小方块：

        xiaoge@MacBook-Air ~ %

        这一行叫提示符（prompt），意思是“我准备好了，请说”。它告诉你三件事：

        • xiaoge：现在是谁在用。
        • MacBook-Air：这台电脑的名字。
        • ~：你现在站在哪个文件夹里。~ 是家（第三十七章）。走到别处，这里会变。

        最后的 % 只是一个记号，表示“该你了”。你打的字跟在它后面。

        六个命令

        终端里的命令和游戏里的命令很像：先写做什么（命令），再写对谁做（参数），中间用空格隔开。这六个命令都只是“看”和“走”，很安全：

        命令做什么名字从哪儿来例子
        pwd我现在在哪个文件夹？print working directory：打出工作文件夹pwd
        ls这里有什么？list：列出来ls、ls Desktop
        cd走到另一个文件夹change directory：换文件夹cd Documents、cd ..、cd ~
        open用访达或者默认程序打开它open：打开open .（在访达里打开“这里”）
        cat把一个文本文件的内容打出来看concatenate：连起来（不是猫）cat options.txt
        clear把屏幕擦干净clear：清除clear

        还有几个小窍门，会让你像高手一样快：

        • tab 补全：打名字的头几个字母，按 tab，终端会帮你补完。补不出来，说明有好几个名字开头一样，或者根本没有这个名字。多按 tab，少打错。
        • ↑ 上一条：按向上的箭头，刚才打过的命令又出来了，改一改再用。
        • ⌃C 停下：一个命令跑个不停（比如服务器），按 control + C 让它停。注意是 control，不是 command。
        • ls -a：后面加 -a（all），连藏起来的、以点开头的文件也列出来。这种以减号开头的叫选项。

        提示：路径里有空格的文件夹（Application Support），要写成 Application\ Support（反斜杠加空格），或者用引号包起来 "Application Support"。最省事的办法：打 Appl 然后按 tab。

        名字里的空格

        终端用空格来分开命令和参数。所以 cd Application Support 在它看来是“走到 Application，然后还有一个多余的 Support”，就出错了。两个办法告诉它“这个空格是名字的一部分”：

        • 在空格前面加一个反斜杠 \：cd Application\ Support。反斜杠在 return 上面那个键。
        • 用英文引号把整个名字包起来：cd "Application Support"。

        这就是第三十六章说“文件名别用空格”的原因。中文名字在终端里能用，可是打起来要切输入法，也容易混进中文标点，所以自己起名字，尽量用英文、拼音和下划线。

        命令 + 参数 = 函数调用以后学 · 编程

        你已经见过三种长得很像的东西：

        • 游戏里：/give @p diamond 3
        • 终端里：cd Documents
        • Python 里：print("你好")

        它们都是“做什么 + 对谁、怎么做”。前面那个叫命令或函数，后面那些叫参数（argument）。第七十五章会讲：你还可以自己发明新的命令，这就是写函数。

        这几样，没有大人在旁边别碰
        • rm：删除。它不进废纸篓，删了就没了。打错一个路径，可能删掉一整个文件夹。
        • sudo：用管理员的权限做事。它会要密码，有了密码，电脑什么都听，包括把系统弄坏。
        • 网上、视频里、陌生人发给你的命令：哪怕说是“加速”“免费皮肤”“修复”，也不要复制粘贴进终端。有些看起来很短的命令，会下载并运行坏程序。第三十一章说过，AI 给的命令也要大人先看。

        规矩很简单：看不懂的命令不运行。

        终端里的英文

        报错的时候，终端说的是英文，其实就那么几句：

        • command not found：没有这个命令（多半拼错了）。found 是 find 的过去式：没找到。
        • No such file or directory：没有这个文件或文件夹。such：这样的。
        • Permission denied：权限不够，不让你做。permission 许可，denied 被拒绝。
        • Is a directory / Not a directory：这是一个文件夹 / 这不是文件夹。
        出错了怎么办
        command not found
        命令拼错了，或者大小写错了（终端里的命令一般全是小写）。也可能你在中文输入法里。
        No such file or directory
        先 pwd 看看自己在哪儿，再 ls 看看这里有什么。名字里有空格吗？用 tab 补全最保险。
        终端一直在跑，不出提示符
        按 control + C。
        打错了一长串还没按回车
        按 control + C 整行作废，或者 control + U 删掉整行。

        想知道自己现在在哪个文件夹，打哪个命令？

        给大人

        macOS 自 Catalina（10.15）起默认 shell 为 zsh，默认提示符形如 用户名@电脑名 当前目录 %。书中命令 pwd、ls、ls -a、cd、open、cat、clear、exit 均为 macOS 自带的标准命令；control + C 中断、control + U 删除整行是 zsh 的默认行为。网页上的终端是模拟的，不会接触真实文件，不支持 rm、sudo。

        卡住的五步

        会用电脑的人，不是从来不卡住，而是卡住了知道下一步干什么。程序员每天都会卡住好几次。他们的办法，归结起来就是五个字：

        1. 读：停下来，把屏幕上的字读完。报错的字虽然常常是英文，但它往往已经告诉你哪里错了：“找不到”“拼错了”“权限不够”。读不懂的单词，抄下来。
        2. 试：自己先试三样最简单的。① 回想“我最后改了什么”，把它改回去；② 关掉重开；③ 换一个最小的例子试试（比如命令出错，先试一条最短的同类命令）。
        3. 查：去社区维基或者搜索引擎查。把报错里最关键的几个英文词，加上“minecraft”和你的版本号一起搜。
        4. 问：问大人、问同学、在大人陪着时问 AI。问之前先把问题写清楚（下面的问题卡）。
        5. 记：解决了，花一分钟记下来：出了什么事、原因是什么、怎么解决的。下次再碰到，一看就懂。第八十一章会教你做一本“错题本”。

        先弄清“我用的是什么”

        同一个问题，在不同的电脑、不同的版本上，答案可能不一样。所以求助之前，先查清楚这三样：

        • 电脑型号和芯片：点屏幕最左上角的苹果标志 →“关于本机”。会写着“MacBook Air”“芯片 Apple M1”“内存 8 GB”。
        • macOS 版本：同一个窗口里，写着“macOS”后面跟一个名字和数字。
        • 游戏版本：游戏标题画面的左下角，写着“Minecraft 1.21.……”这样的字；启动器的“安装”里也能看到。

        把问题说清楚

        “游戏坏了”“命令不管用”，谁也帮不了。一个说得清楚的问题，要回答这几样：

        要说清的不清楚的说法清楚的说法
        我想做什么我想弄个东西我想用 /fill 在我家下面挖一个 50×50 的大地下室
        我做了哪几步我打了命令我站在家门口，按 / 打了 /fill ~ ~-1 ~ ~50 ~-20 ~50 air
        我以为会怎样（没说）脚下挖出一个大坑
        实际怎样了不行聊天框里出现红字：“……too many blocks……”
        我已经试过（没说）我把 50 改成 20，就成功了
        我用的是（没说）M1 MacBook Air，Java 版 1.21.x

        有意思的是：很多时候，你把问题一条一条写清楚，写到一半就自己想明白了。程序员管这叫“小黄鸭调试法”：对着桌上的一只玩具鸭子，一句一句把问题讲给它听，讲着讲着，答案就冒出来了。
