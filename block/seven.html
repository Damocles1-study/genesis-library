      给大人：为什么这样学英语

      这一部的设计基于几个比较可靠的学习研究结论：词汇在有意义的情境里比孤立的词表记得牢；把“听到的声音”“看到的样子”“用到的场合”连在一起，比只连“中文意思”好；间隔重复（隔一段时间再回忆一次，间隔逐渐拉长）比集中背诵更省时、记得更久；主动回忆（先想再看答案）比反复看更有效。游戏 ID 天然是“情境 + 构词”的好材料。

      读音用的是浏览器自带的语音合成（Safari 和 Chrome 在 Mac 上都有美式英语声音），不需要联网下载任何东西，质量和真人有差距，但足以建立“字母和声音”的联系。建议每天固定一个时间用复习台，五到十分钟即可；游戏可以切换成英文界面玩一段时间，遇到不认识的词，和孩子一起查、一起念。

      第一招：把游戏换成英文

      你最熟悉的一个游戏，就是最好的英语课本：每个按钮、每样东西你都知道是什么，现在只是换一种说法。

      1. 在标题画面上，点“选项”旁边那个小地球按钮（或者“选项”→“语言……”）。
      2. 在列表里找到 English (US)，点它，再点“完成”。整个游戏马上变成英文。
      3. 想换回来：同一个地方，找 简体中文（中国大陆）。看不懂英文时，记住那个小地球的位置就行。

      建议先换一个星期试试。刚开始会慢一点，没关系：Inventory（物品栏）、Options（选项）、Done（完成）、Save and Quit to Title（保存并退出到标题画面）……几天以后，你会发现自己不用想就认识了。

      不想全换？也可以只用第三十五章教的 F3 + H：中文界面里，鼠标停在东西上就能看到它的英文 ID。

      第二招：先听，再看

      小孩学说话，都是先听几千遍，才开口，最后才认字。学英语也一样：听得多了，看到字母才会“响”。这本书里每一个蓝色点点线的英文，都能点一下听，比如 creeper、pickaxe、obsidian。听的时候：

      • 跟着念出来，不只是听。嘴动了，记得牢得多。
      • 看着字母念：哪几个字母发了哪个声音？
      • 念整句：不只念 sword，念 “Give me a diamond sword.”

      读音来自你电脑浏览器自带的声音，和真人比有点像机器人，但字母和声音的对应是对的。苹果电脑上用 Safari，声音一般最好听。

      字母的名字和字母的声音

      字母有两种“读法”：一种是它的名字，背字母表时念的 A、B、C；一种是它在单词里发的声音。比如 c 的名字念“西”，可是在 cat 里，它发的是“克”的声音。学会每个字母的声音，很多单词不用背，看着就能拼出读音来，这叫自然拼读（phonics）。

      最重要的是五个元音字母 a、e、i、o、u。在短短的词里，它们发“短”的声音：

      • a：cat、map、bat（蝙蝠）、axe
      • e：bed、red、egg、chest
      • i：pig、stick、fish、brick
      • o：dog、log、box、block
      • u：bug、sun、run、jump

      再学一个“魔法”：单词最后有一个不发音的 e，前面的元音就会念它自己的名字。cake 里的 a 念 A 的名字，stone、bone 里的 o 念 O，slime、lime 里的 i 念 I。对比一下：cap 和 cape（披风），pin 和 pine（松树）。

      第三招：在快忘的时候复习

      一百四十年前，1885 年，德国心理学家艾宾浩斯做了一个很笨也很了不起的实验：他自己背了很多没有意思的音节（像 “dax”“bok” 这样的），然后隔一段时间测一测自己还记得多少。他发现：

      • 刚背完忘得最快：一天以后，大半都想不起来了。
      • 但是每复习一次，忘得就慢一点。

      把“还记得多少”画成随时间变化的线，就是著名的遗忘曲线。后来的人想出了一个省力的办法：别一天背十遍，而是隔一天、隔两天、隔四天、隔八天各复习一次，每次都在“快要忘了”的时候拉它一把。间隔越来越长，这个词就越来越牢。

      1970 年代，一位德国作家莱特纳发明了一个用纸盒子做的办法：卡片答对了往后面的盒子挪，答错了回到第一个盒子；后面的盒子隔得越久才看一次。第五十八章的复习台，就是一个电脑版的莱特纳盒子。

      越来越慢地减少以后学 · 高中 指数函数

      遗忘曲线开始掉得快、后来掉得慢，像一杯热水慢慢变凉：越接近室温，降得越慢。数学上叫“指数衰减”，高中会学它的公式。现在你只要看懂这张图的形状：第一天最要紧，所以学了新词，当天睡觉前、第二天各看一眼，最划算。

      两块粘成一块：复合词

      把两个词直接粘起来，就是一个新词，叫复合词。游戏里到处都是：

      • redstone = red 红 + stone 石：红石
      • sandstone = sand 沙 + stone 石：砂岩
      • bookshelf = book 书 + shelf 架子：书架
      • snowball = snow 雪 + ball 球：雪球
      • minecart = mine 矿 + cart 小推车：矿车
      • sunflower = sun 太阳 + flower 花：向日葵
      • gunpowder = gun 枪 + powder 粉：火药
      • glowstone = glow 发光 + stone：荧石

      有的复合词中间有空格，游戏 ID 里变成下划线：crafting_table（合成用的桌子：工作台）、name_tag（名字标签：命名牌）、fishing_rod（钓鱼的杆子）。规律：后面那个词是“它是什么”，前面那个词是“什么样的”。bookshelf 是一种 shelf，snowball 是一种 ball。

      拼词台

      从左边点一块、再从右边点一块，看看能不能拼成游戏里的一个词。拼对了会念出来，告诉你它是什么。一共藏着十六个，看你能找到几个。

      前面加一块：前缀

      • un-：不。breakable 能打破的 → unbreakable 打不破的（“不毁”附魔）。undying 不死的（不死图腾）。
      • re-：再一次、回来。spawn 出生 → respawn 重生；name → rename 改名；reload 重新读取（第二十五章的 /reload）。
      • in- / im-：不。visible → invisible 看不见的（隐身）；possible → impossible 不可能的。

      前后缀工坊

      选一个词根，再点前缀和后缀，看看能变出哪些真实存在的词（不存在的组合会告诉你）。

      一个变多个：复数

      英语里东西多于一个，名词后面要变一下，叫复数：

      • 一般加 -s：pig → pigs，block → blocks，plank → planks（所以 ID 是 oak_planks）。
      • 以 s、x、sh、ch 结尾的，加 -es：fox → foxes，box → boxes，torch → torches。
      • 以 f 结尾的，常常变成 -ves：wolf → wolves，leaf → leaves（所以 ID 是 oak_leaves）。
      • 不守规矩的：sheep → sheep（不变），man → men，所以 enderman → endermen；fish → fish；mouse → mice。

      命令就是祈使句

      英语里请别人做事的句子，叫祈使句：动词放最前面，不说“你”。

      • Open the door. 开门。
      • Give me the sword. 把剑给我。
      • Don't touch the lava! 别碰岩浆！（不要做什么，前面加 Don't）

      游戏的命令正是这样：/give、/kill、/summon、/fill、/say、/tell……第一个词就是动词。把命令念成句子：/fill … glass，“Fill (it with) glass.”；/teleport @s，“Teleport me.”；/time set day，“Set the time (to) day.”。第五十七章有命令里所有动词的词卡。

      编程语言也是这样起名字的

      程序员给函数起名字，也爱用“动词开头”：print（打印）、input、get_score、set_block、is_night。读别人的程序时，看到动词开头的名字，就知道“这是一个做事的”；看到名词，就知道“这是一样东西”。你学的这些构词法，以后读代码一样用得上。

      前缀 prefix加在词前面的一小块，比如 un- re-。
      后缀 suffix加在词后面的一小块，比如 -er -ing。
      复数 plural多于一个时名词的样子。
      祈使句 imperative动词开头、请别人做事的句子。
      给大人

      构词法（复合、派生）是扩大词汇量最有效的途径之一。书中的例子都取自游戏的物品名和英文界面；附魔“耐久”英文名为 Unbreaking。复数规则只列了最常见的几类。祈使句在小学英语中会以课堂用语的形式出现，命令语法是很好的强化。

      游戏里带走一样redstone = red + stone；-er 是做事的人或东西；leaves、wolves、endermen 是复数；命令就是祈使句。

      一张乘法表

      工具的 ID 都是“材料_工具”。材料有六种，工具有五种：

      • 材料：wooden、stone、iron、golden、diamond、netherite
      • 工具：sword 剑、pickaxe 镐、axe 斧、shovel 锹、hoe 锄

      6 × 5 = 30 个 ID。盔甲也一样：材料 + helmet、chestplate、leggings、boots（盔甲的材料是 leather、chainmail、iron、golden、diamond、netherite，和工具不完全一样，还有海龟壳头盔，以游戏为准）。

      数字的规律

      • 0 到 12 各有各的名字：zero、one、two……ten、eleven、twelve。要背。
      • 13 到 19 后面都是 -teen：thirteen、fourteen、fifteen、sixteen……所以“十几岁的孩子”叫 teenager。
      • 20、30……90 后面都是 -ty：twenty、thirty、forty（注意没有 u）、fifty。
      • 21 到 99 用连字符连起来：twenty-one，sixty-four（一组）。
      • 大数：hundred 百、thousand 千、million 百万。200 是 two hundred，没有 s。
      • 负数：在前面加 minus（减、负）：−50 读作 minus fifty。
      • 序数（第几）：first、second、third，后面大多加 -th：fourth、fifth、tenth。second 还有“秒”的意思。

      小心 thirteen 和 thirty、fifteen 和 fifty 听起来很像：-teen 的重音在后面，-ty 的重音在前面。用下面的装置听一听。

      大约多久每天 5—10 分钟

      • 每天用复习台把“今天该复习的词”过一遍。

      • 把自己在游戏里、课本上遇到的新词加进来。

      它是怎样安排的

      复习台有六个“盒子”（格子），编号 0 到 5：

      • 新放进来的词，在第 0 格，今天就要复习。
      • 你点“记得”，它往右挪一格：第 1 格隔 1 天再见，第 2 格隔 2 天，然后 4 天、8 天、16 天。
      • 点“模糊”，它不挪，明天再见。
      • 点“忘了”，它回到第 0 格，今天还会再出现。
      • 到了第 4、5 格的词，算“记牢了”。

      间隔是 1、2、4、8、16 天：每次翻一倍。这正是第五十一章说的“越来越长的间隔”。诚实地点“记得”“忘了”，它才能帮你安排好；骗它，最后骗的是自己。

      记录存在这台电脑的浏览器里。换了电脑或者清了浏览器数据，进度就没了（单词本身不会丢）。

      装置 · 第五十八章 · 二

      加一个我的词

      在游戏里、课本上、动画片里遇到一个新词？把英文和中文写在这里，它会进入复习台，和别的词一起被安排复习。（只存在这台电脑的浏览器里。）

      每天怎样用
      1. 固定一个时间：比如早饭后，或者玩游戏之前（不是之后）。
      2. 先把“今天的”过完，再决定要不要加新词。一天新词别超过十个。
      3. 每个词都念出声。
      4. 一周看一次上面那排数字：第 4、5 格的词越来越多，就是你的进步。

      这一套办法不只能背单词：古诗、乘法口诀、元素符号、历史年份，都能这样记。以后你可以用纸盒子自己做一个。

      每次翻一倍以后学 · 第六十一章 2 的幂

      1、2、4、8、16，每次乘 2。如果一直答对，第 5 次以后隔 16 天，再往后（如果复习台有更多格子）是 32 天、64 天……第六十一章会看到，这串数在电脑里无处不在：一组 64 个、一个区块 16 格，都是它。

      连续七天★★★

      连续七天，每天用复习台。每天做完在日历上打个勾。第七天看看：第 4、5 格里有几个词？在本子上记下来，一个月后再看一次。

      一个词你点了“忘了”，会怎样？

      1. 从复习台删掉
      2. 回到第 0 格，今天再出现
      3. 跳到第 5 格

      忘了就回到起点，重新一格一格往后走。

      间隔是 1、2、4、8，下一个是几天？

      每次翻一倍：16。

      2. 一个月用一次，一次两小时
      3. 想起来再用

      • 读音：来自浏览器自带的语音合成，不同电脑、不同浏览器的声音不一样，有时会把下划线、缩写念得怪怪的。拿不准时，请大人或者英语老师念一遍。
