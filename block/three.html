    一块一块我的世界创世记

    第三部 · 门

    方块世界里有许多门：木门、铁门、下界传送门、末地传送门。走过一扇门，就到了另一个地方。

    这一部讲的，是从方块世界通往真实世界的门。第一部讲它从哪里来，第二部讲红石怎样变成电脑；这一部问的是：玩完以后，你能带走什么？老师怎样用它上数学课，政府怎样把一整个国家搬进去，记者怎样在里面藏一座图书馆，居民怎样用它设计自己家门口的公园。你的方块房子怎样变成一个能拿在手里的模型。

    这一部也讲门外面的事：在一台 MacBook Air 上怎么装、怎么玩不卡；网上的陌生人和骗子；为什么停不下来，怎样和家里人一起写一张游戏公约；长大以后，这些本事能用在哪儿。最后一章是尾声，留给你自己。

      苹果电脑上，能装哪个版本

      第一部第六章讲过，《我的世界》后来分成了两套程序：Java 版和基岩版。它们在苹果电脑上的情况是这样的（以官方最新说明为准）：

      • Java 版：能在 Windows、Mac 和 Linux 电脑上玩。苹果电脑上装的就是它。要先用一个微软账号登录官方的启动器，再下载游戏。
      • 基岩版：手机、平板、游戏机和 Windows 电脑上的那个版本。它没有专门的 Mac 版。这就是豆子在平板上的世界，不能直接搬到小格电脑上的原因。
      • 中国版：第一部第七章讲过的网易代理版。它有电脑版，能不能在你的 Mac 上装、要怎么装，以网易官方的说明为准。
      • 教育版：学校用的版本，有 Mac 版，下一章细讲。

      有一件事一定要记住：只从官方网站或者官方应用商店下载。网上那些“免费破解版”“绿色版”，常常夹带病毒，还可能偷走你和爸爸妈妈的账号。第一部第八章讲过藏在模组里的病毒，破解版更危险。

      M1 芯片和“原生支持”2020—2022

      2020 年底，苹果在 MacBook Air 里换上了自己设计的 M1 芯片。它和以前苹果电脑用的芯片“说的不是同一种话”：同样一条指令，两种芯片的写法不一样。第二部第十四章讲过，电脑是一条一条照着指令做事的。

      所以一开始，Java 版在 M1 电脑上要靠苹果的一个“翻译程序”（叫 Rosetta 2）一边翻译一边运行，能玩，可是多绕了一道弯。2022 年夏天的 1.19 版本以后，Java 版开始原生支持苹果芯片，就是直接用 M1 听得懂的话来写，不用再翻译了。

      8 GB 和 2026 年的新配置说明

      2026 年 7 月，Mojang 十几年来第一次正式更新了 Java 版的电脑配置说明。像 M1 这样显卡做在芯片里面的电脑，官方写的最低内存是 12 GB，推荐 16 GB。

      小格那台 M1 MacBook Air 只有 8 GB 内存，低于新的最低要求。官方同时也说，低于这个配置的电脑游戏照样能打开，只是不再保证画面和流畅度。所以，对这台电脑来说，最要紧的就是下面讲的：把设置调低一点。报道这件事的媒体也说，游戏本身并没有突然变得更“吃”电脑，只是旧的说明写了十几年，太久没改了。

      键盘和触控板

      苹果电脑的键盘和别的电脑有一点点不一样。最常用的几个键是这样的：

      W A S D往前、左、后、右走
      空格跳；连按两下在创造模式里飞
      Shift潜行，走到边上不会掉下去
      control跑（也可以连按两下 W）
      E打开物品栏
      1—9换手里拿的东西
      T聊天；/直接输入命令
      esc暂停、打开菜单
      fn + F3显示坐标等信息
      fn + F5换成第三人称视角
      fn + F2截图，存在游戏文件夹里
      两指轻点触控板上的“右键”：放方块、开门

      带 fn 的那几个，是因为 Mac 键盘最上面一排默认是调亮度、调音量的，要按住 fn 才变成 F 键（也可以在系统设置里改）。如果觉得触控板太难用，接一个鼠标会轻松很多：左键挖，右键放，滚轮换东西。

      卡了、烫了怎么办

      MacBook Air 有一个特点：它没有风扇，所以很安静，可是热了只能靠机身慢慢散热。玩久了它会变烫，变烫以后芯片会主动放慢，免得把自己烧坏，于是游戏就开始卡。几个办法：

      • 把“视野距离”调小。这是最管用的一招，下面的装置会告诉你为什么。
      • 把画质调成“流畅”，关掉云、平滑光照这些好看但费力的选项。
      • 玩之前关掉别的程序，尤其是开了很多网页的浏览器。8 GB 内存，大家要省着用。
      • 插上电源，放在硬桌面上。别放在被子、枕头、腿上，底下要能透气。
      • 别装来路不明的“加速”“优化”软件。想装，先问大人。
      装置 · 第十七章

      视野距离

      游戏把世界切成一块一块 16 × 16 格的方柱，叫区块。“视野距离”就是你往四周能看到几个区块。拖动滑块，看看电脑要同时准备多少区块（中间的红点是你，绿色是电脑要准备的地方）。

      视野距离

      视野距离从 12 调到 6，往四周看的距离少了一半，可是电脑要准备的区块从 625 个变成 169 个，少了将近四分之三。这是因为区块是一圈一圈往外铺的：半径翻一倍，面积要翻四倍。每个区块从底到顶有 384 格高。实际上，游戏不会把每一格都画出来，看不见的会跳过，这里只是帮你感受“多了多少”。

      存档放在哪儿

      第二部第十二章讲过，你的世界存在硬盘里。在 Mac 上，Java 版的存档一般放在这个文件夹里：

      ~/Library/Application Support/minecraft/saves

      每一个世界是里面的一个文件夹。想备份，就请大人帮你把这个世界的文件夹复制一份，放到别的地方（比如一个 U 盘）。电脑坏了、不小心删掉了、一行 /fill 把房子填成了石头，都还能找回来。

      Mojang 账号

      很多年里，玩 Java 版用的是 Mojang 自己的账号。微软买下 Mojang 以后，2020 年宣布要把所有账号都换成微软账号，到 2023 年前后，老的 Mojang 账号就不能再登录了。换成微软账号以后，爸爸妈妈可以给孩子开一个“儿童账号”，在家庭设置里管：能不能和别人联机、能不能花钱、能和谁聊天。

      苹果电脑玩不了我的世界假

      Java 版一直都能在苹果电脑上玩。Notch 当年就是用 Java 写的它，Java 程序本来就能在 Windows、Mac、Linux 上运行。M1 以后的苹果电脑，从 2022 年起还能原生运行。

      不能在 Mac 上玩的，是基岩版。所以更准确的说法是：苹果电脑上玩的是 Java 版。

      给大人

      Java 版支持 Windows、macOS、Linux；基岩版没有原生 macOS 版本。2022 年 6 月起官方在电脑上把 Java 版和基岩版合并销售（Mac 上实际可用的是 Java 版）。Java 版 1.19（2022 年 6 月）起原生支持 Apple Silicon，见 AppleInsider 等报道。2026 年 7 月 21 日 Mojang 更新 Java 版配置要求：最低 macOS 12、Apple M1，集成显卡最低 12 GB 内存，推荐 macOS 14、16 GB，并说明低于最低配置仍可启动但不保证表现；见 PC Gamer、Notebookcheck 等报道。Mojang 账号迁移到微软账号于 2020 年宣布，2023 年前后完成。存档路径为 Java 版默认路径。

      建议：用家长的微软账号为孩子建立儿童账号，在 Xbox/微软家庭设置里管理多人游戏、聊天和购买。8 GB 的 M1 Air 跑原版 Java 版通常可以，但建议视野距离 6—8、模拟距离 5—6、画质“流畅”，并避免同时开很多浏览器标签页。不要给孩子装来路不明的启动器、破解版或“优化包”。

      游戏里带走一样Mac 上玩的是 Java 版，只从官方下载。卡了先调小视野距离；两指轻点是右键；存档在 saves 文件夹里，记得备份。
      游戏外带走一样先认识你的工具：它能做什么、怕什么。半径翻一倍，面积翻四倍。

      一位老师的改装版2011—2016

      《我的世界》刚火起来没多久，就有老师想把它搬进教室。2011 年，美国纽约一所学校的老师乔尔·莱文和几位朋友一起，在游戏的基础上改出了一个给学校用的版本，叫 MinecraftEdu：老师可以一下子让全班进同一个世界，可以把学生“冻住”让大家听讲，可以划出不许破坏的地方。很快，世界各地的几千所学校都用上了它。

      2016 年初，微软买下了这个改装版；同一年的秋天，官方的教育版正式推出。它在普通的游戏上加了许多给课堂用的东西：

      • 黑板和告示牌：老师可以在世界里写上题目和提示。
      • 相机和作品集：学生可以给自己的作品拍照、写说明，交给老师。
      • 代码窗口和小机器人：第二部第十六章讲过，用积木或 Python 指挥机器人干活。
      • 化学实验：2018 年加入，可以用质子、中子、电子“拼”出元素，再把元素合成化合物。
      • 现成的课：数学、历史、语文、科学、编程，还有讲网络安全的世界。

      教育版有 Mac 的版本，可是一般要用学校或机构给的账号登录。你的学校有没有，可以问问老师。

      一样大的地板，不一样长的墙

      回到小格的问题。地板一共 24 块，墙围在地板外面。4 × 6 的房子，墙一圈要 24 块；1 × 24 的“走廊”，墙一圈要 54 块。面积一样，周长可以差很多。越接近正方形，周长越短，盖墙越省材料。这就是为什么真的仓库、教室常常盖得方方正正。

      数方块，是学面积、周长、体积最直观的办法：每一块就是一个“单位”，数一数就知道有多少。下面的装置帮你数，也告诉你一个小陷阱：数墙的时候，四个角很容易被忘掉。

      一座藏在游戏里的图书馆

      2020 年 3 月，一个帮助世界各地记者的组织“无国界记者”，在游戏里开放了一座巨大的图书馆。它由一支建筑团队花了大约三个月搭成，用了一千二百多万块方块，有高高的穹顶和许多个展厅。

      为什么要把图书馆盖在游戏里？因为在一些国家，有些新闻文章在网上是看不到的，可是这个游戏在那里还能玩。于是他们把这些文章写进游戏里的书，放在图书馆的书架上。任何人只要进到这个世界，就能翻开来读。

      你不用去找这个世界。只要记住：方块世界不只是玩的地方，人们也用它来保存和分享知识。

      居民用方块设计公园2012

      2012 年，Mojang 和联合国一个专门关心城市和住房的机构合作，开始了一个叫“一块一块”（Block by Block）的项目。这本书的名字和它撞了，纯属巧合，也说明这个说法太贴切了。

      它是这样做的：在一些贫穷的社区，政府要修一个广场、一个公园，可是住在旁边的人很少有机会说上话。他们大多不会看设计图纸。于是项目组把那块空地原样搭进游戏里，请居民，尤其是年轻人和妇女，自己动手在游戏里“盖”他们想要的样子：这里放长椅，那里种树，这里要有路灯，晚上走着才不怕。最后，建筑师照着这些方块模型去设计真的公园。据报道，最早的试点之一在肯尼亚首都内罗毕，后来世界上许多城市都做过。

      不会画图纸没关系，会搭方块就能把想法说清楚。这件事让很多做城市规划的人吃了一惊。

      比例尺：缩小多少倍

      地图不可能和真的地方一样大，所以要缩小。缩小了多少，就写在比例尺上。比如“1:10000”，意思是地图上的 1 厘米，代表真实的 10000 厘米，也就是 100 米。手机地图上那条小横线，是另一种写法：这么长，就代表真实的 50 米。

      方块世界里也一样。第一部讲过，一格就是一米，如果你一格一格照着真实的大小盖，就是 1:1，一比一。盖你的房间、你的小区，一比一正合适。可是想盖一座城、一个国家，就要缩小：比如一格代表 10 米，就是 1:10。

      一个实习生和二百二十亿块方块2013

      2013 年 9 月，英国的国家测绘局（专门给英国画地图的政府机构）发布了一张游戏地图：整个大不列颠岛和周围的小岛，一共用了二百二十亿块方块，覆盖二十二万多平方千米。做这张地图的，是一位暑期实习生，据测绘局说只用了大约两个星期。

      他当然不是一块一块放的。他写了一个程序，读取测绘局公开的地图数据：哪里高、哪里低，哪里是水、哪里是路，再让程序自动把方块“摆”出来。为了放得下，他把一格算成 50 米，高度也压低了，英国最高的本尼维斯山只有一百二十多格高。高速公路用钻石块铺，主要公路用金块铺。

      一比一的丹麦，和开着炸药矿车的人

      2014 年 4 月，丹麦的地理数据局更进一步：他们用自己的地图和高度数据，把整个丹麦按一比一搬进了游戏，大约用了四万亿块方块。房子、道路、树林，都在它真实的位置上，任何人都能进去逛自己家的街道。

      为了防止破坏，他们关掉了游戏里的炸药。可是没过几天，就有玩家发现了一个漏洞：炸药不能放，装着炸药的矿车却还能用。有人开着它们炸掉了一些地方，还插上了别国的旗子。据丹麦方面说，被破坏的只是一小部分。第二天早上，许多别的玩家主动去把炸坏的地方修好，种上了草和花。

      把整个地球搬进去2020

      2020 年春天，有玩家发起了一个更大的计划：按一比一，把整个地球搬进方块世界。电脑先根据地图数据铺出地形，再由来自世界各地的志愿者，一栋楼一栋楼地把自己家乡的建筑盖上去。一个月里就有好几万人报名。

      他们碰到的第一个难题是高度：方块世界从底到顶只有 384 格，珠穆朗玛峰有八千八百多米，根本放不下。他们只好用一个特别的模组，让世界可以无限往上长。

      方块世界到底有多大

      第一部序幕讲过，方块世界有一圈“世界边界”，离中心大约三千万格。算一算：从一头到另一头大约六千万格，也就是六万千米；这样一个正方形，面积大约是 36 亿平方千米。整个地球的表面，连海洋算在一起，大约 5.1 亿平方千米。

      也就是说，方块世界的地面，大约是整个地球表面的七倍。一比一的地球放进去绰绰有余，只是放不下珠穆朗玛峰。

      装置 · 第十九章

      比例尺

      先选一个地方，再选一个比例：一格代表多少米。看看地面要铺多少块，一秒放一块要多久，最高的地方要多少格高，方块世界放不放得下。

      “地面要铺多少块”只算了最上面一层；真的地图还要往下填满土和石头，所以英国测绘局那张地图虽然一格算 50 米，方块总数还是有二百二十亿块。面积和最高处都是取整的大概数，县城的面积是示意。

      坐标，又见面了

      第二部第十五章讲过 x、y、z 三个坐标。真实世界也用坐标：经度说你在东西方向上的哪儿，纬度说你在南北方向上的哪儿，再加上海拔，正好也是三个数。手机定位、导航，用的就是它们。

      做一比一地图的程序，干的就是“翻译坐标”这件事：把真实世界的经度、纬度、海拔，换算成游戏里的 x、z、y。你用比例尺量小区，其实也是在做同样的事，只是用的是脑子和手指。

      积木变成游戏，游戏又变回积木2011—2012

      第一部第一章讲过，丹麦的带小圆点的积木，是方块游戏的“长辈”之一。故事还有下半段：2011 年底，有玩家在乐高的一个“粉丝出主意”网站上提议，出一套方块游戏主题的积木。据报道，只用了大约两天，就有一万人投票支持。2012 年，第一套这样的积木真的上市了：小小的一块地，有草、有树、有矿洞。

      积木启发了游戏，游戏又变回了积木。很多发明都像这样，你传给我，我再传回给你，每传一次多一点新东西。

      一层一层地“打印”

      3D 打印机的原理，说起来很像盖方块房子：它有一个会移动的喷头，把加热变软的塑料一点一点挤出来，先画出最底下的一层，等它凉了变硬，再在上面画第二层……几百层叠起来，就成了一个立体的东西。

      把游戏里的作品变成真东西，大致要三步：

      • 导出：有一些免费的小工具，可以从存档里选一块地方，把它变成 3D 模型文件。这一步请大人帮忙，而且只用可靠来源的工具。
      • 检查：在电脑上把模型转一转，看看有没有“飘”着的部分。
      • 打印：交给打印机。小东西要一两个小时，大一点的要好几个小时。

      如果身边没有 3D 打印机，也可以用最老的办法：纸。每一块方块就是一个小纸盒，剪一张展开图，折起来，粘好。一个小房子要折几十个，慢，可是你会把每一块都记得清清楚楚。

      装置 · 第二十章

      方块变模型

      选一个作品，再选做成模型时一格算多大。看看它有多少块、做出来有多大、折纸要剪多少张、3D 打印大约要用多少塑料。

      塑料按常见的 PLA 材料（每立方厘米约 1.24 克）、内部只填三成粗算。做成模型时，一棵树的树叶如果和树干没连上，打印出来就会掉下来；3D 打印的人会给悬空的部分加上“支撑”，打完再掰掉。

      医院里的“体素”

      第一章讲过，立体的像素叫体素。体素不只在游戏里有。医院里做 CT 检查时，机器从许多角度给身体拍照，电脑再把身体“切”成许许多多很小很小的小方块，每一块记下那里是骨头、是肌肉还是空气。医生看到的立体图像，其实就是几千万个体素拼起来的。

      有的工程师用激光扫描一座老房子，得到的也是一大堆点和小方块；文物保护的人用它们记下古建筑的样子，万一哪天坏了，还能照着修。方块游戏只是把这些小方块放大到一米，让人能走进去。

      游戏里的房子，现实里能盖吗

      大多不能直接盖。原因有三个：

      • 重力：游戏里除了沙子、沙砾这几样，方块都不会往下掉，一块方块可以飘在半空中。真的房子，每一块砖都压在下面的东西上，屋檐伸出去太远就会塌。
      • 材料：游戏里一层玻璃就能当地板，站多少人都不会碎；木头不会烂，铁不会锈。真的材料会碎、会烂、会锈，还会被压弯。
      • 形状：真的房子有斜屋顶、圆柱子、拱门，不是一格一格的。

      为什么方块游戏特别难停

      很多游戏有一个清楚的“结束”：这一关打完了，这一局输了。方块游戏几乎没有。它的设计里藏着好几个让人停不下来的东西：

      • 没有终点：房子永远可以再大一点，矿洞永远可以再挖深一点。没有人告诉你“今天的部分完成了”。
      • 一件事接着一件事：墙盖好了，想盖屋顶；屋顶好了，天黑了；天黑了，要打怪。每件事做完，都正好露出下一件事的开头。
      • 说不定下一下就有：钻石藏在哪儿、钓鱼能钓上什么、箱子里有什么宝贝，都是碰运气的。你不知道下一镐会不会挖到，所以总想“再挖一下”。
      • 朋友还在：和同学一起玩的时候，别人没下线，你先走，好像有点对不起大家。

      “说不定下一下就有”的魔力

      二十世纪中叶，美国心理学家斯金纳用鸽子做过一系列实验：鸽子啄一下按钮，有时候会掉出食物。他发现，如果每次啄都给食物，鸽子吃饱了就不啄了；可是如果不知道第几下才给，鸽子会一直啄、一直啄，停都停不下来。

      人也很像。挖矿、开箱子、抽卡，都是“不知道第几下才有”。这不是说玩游戏的人像鸽子，而是说：你停不下来，不全是因为你不够自觉，也是因为这件事本来就很难停。知道了这一点，就不用跟自己生气了，而是去想办法。

      什么才叫“游戏障碍”

      2019 年，世界卫生组织把“游戏障碍”写进了新版的国际疾病分类，2022 年起正式使用。它说的不是“玩得多”，而是三件事一起出现：管不住自己玩不玩、玩多久；游戏挤掉了别的兴趣和该做的事；明明已经造成了很大的麻烦（比如不上学、不睡觉、和家人闹翻），还是停不下来。而且一般要持续一年左右。

      世界卫生组织也说，玩游戏的人里，只有很少一部分会这样。大多数人玩得开心，也能停下来。所以，不用一看见孩子玩游戏就担心“上瘾”；可是如果真的出现了上面三件事，就要找医生帮忙。

      在开始之前，就想好怎么停

      玩到一半再决定停，是最难的：那时候你正在兴头上，墙差一点，钻石就在眼前。所以聪明的办法是在开始之前就决定：

      • 给这一次定一个任务：“今天盖完屋顶就停”，比“玩一个小时”更容易做到。任务完成，就是一个天然的停止点。
      • 提前提醒：定一个提前五分钟响的闹钟，让自己有时间收尾、存档。
      • 停下来以后去做什么，也想好：吃水果、出去走走、看一会儿书。从游戏直接跳到写作业最难，中间有个“台阶”会容易很多。
      • 睡觉前一小时不玩：屏幕的光和刚才的兴奋，会让人更难睡着。
      • 规矩一起定，写下来，贴起来：自己同意过的规矩，比别人命令的规矩好守得多。

      “疲劳时间”防沉迷系统

      2007 年，中国推出了第一代网络游戏防沉迷系统：未成年人玩到 3 小时以后算“疲劳时间”，游戏里得到的经验、奖励减半；玩到 5 小时以后算“不健康时间”，奖励变成零。可是它只减奖励、不让停，很多孩子换个账号继续玩。后来，它被第一部第七章讲过的 2019 年、2021 年的新规定取代了：直接规定什么时候能玩、能玩多久，还要实名。

      玩游戏就是上瘾假

      “上瘾”是一个很重的词。世界卫生组织说的“游戏障碍”，要同时有管不住、挤掉别的事、造成大麻烦还停不下来，而且持续很久，只有很少的玩家是这样。

      可是“难停下来”是很常见的，几乎每个人都有过，大人刷手机也一样。难停，不等于上瘾；可是难停，也值得认真想办法。

      你在方块里练出来的本事

      二十年后的工作，今天可能还没有名字

      从现在开始，攒一本“作品集”

      画画的人、做设计的人、做游戏的人，找工作时常常要拿出一本作品集：我做过什么，是怎么做的。你现在就可以开始攒：

      • 每盖好一个满意的作品，截一张图（fn + F2），写两句话：它叫什么，你花了多久，最难的是哪儿。
      • 做了一个红石机器或者一个 Scratch 小程序，录一段短短的视频，或者画一张它怎么工作的草图。
      • 放在一个文件夹里，一年以后翻出来看看，你会发现自己进步了多少。

        • 编的：小格、舅舅、妈妈、豆子，和全书每章开头“存档”里的故事；小格的那台 MacBook Air、他的编程课、学校的 3D 打印机，都是故事的一部分。全书的方块图、人物和装置都是这本书自己画、自己写的示意，不是游戏截图。第二部的电路沙盘、命令台、代码装置用的是简化规则；第三部的“方块数学课”“比例尺”“方块变模型”“这条消息怎么办”“游戏公约”“方块里藏着的工作”“我的第一块”都是为了启发而设计的，数字是粗算。
        • 真的：正文和蓝色“真事”框里的人、年份、事情，尽量核对过；说不准的地方写了“据说”“据报道”“大约”。三部的存疑和出处分别列在第一部末尾、第二部末尾和下面。

        第三部 · 门 · 完 · 故事讲完了

        每一个大世界，开头都只有一块

        三部二十五章，从一块带小圆点的积木，讲到一台用四亿多块方块搭起来、想两个小时才回一句话的电脑，再讲到一张贴在书桌旁的公约。它是一个人下了班写出来的，是一群玩家一起养大的，也是全世界的孩子一起玩、一起学的。门开在二楼也没关系，窗户比门大也没关系。放下你的第一块吧。小格的故事讲到这里就完了。如果你想自己动手，后面还有一间工坊：第四部《工》，写数据包、用 Python 生成命令、看懂电脑和网络、开一个自己的服务器、在方块里做数学和物理实验、和 AI 一起学。
